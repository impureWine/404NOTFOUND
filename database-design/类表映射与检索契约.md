# 类—表映射与检索契约（交接摘要）

**主责**：庄剀涵 / 102400435  
**基线**：PostgreSQL 16 兼容、Node.js `pg`、Repository + SQL migration、同源 Web/API + 私网数据库。
**用途**：给后端、交互和答辩整合人员使用；完整约束见 v0.2 数据库设计说明书和 DDL。

## 1. 类—表交接

| 服务/类 | 表 | 交接约束 |
|---|---|---|
| `AuthService` / `IdentityRepository` | `user_accounts`, `password_credentials`, `login_sessions` | Argon2id 密码摘要；随机会话凭据只存 SHA-256 摘要；退出/改密可撤销 |
| `ProfileService` | `user_profiles`, `account_preferences` | REQ17 私密主页；不生成公开主页；设备偏好留在设备端 |
| `EntryPointService` / `ConsentService` | `entry_points`, `consent_grants` | SAVE/AI_PROCESS/SEARCH_PROCESS/ANALYZE/CROSS_ENTRY 相互独立；校验范围、对象版本、有效期和撤回状态 |
| `RecordService` | `saved_records`, `saved_messages` | 默认临时；只有用户主动选择的消息才形成保存快照 |
| `EmotionRecordRepository` | `saved_records`, `emotion_records` | 保存不代表分析；日期按用户时区解释 |
| `WorryObjectRepository` | `saved_records`, `worry_objects`, `room_objects` | 外观可保存；正文需明确保存并加密 |
| `RehearsalRepository` | `saved_records`, `rehearsal_drafts` | 只保存用户认可表达，不保存完整排练上下文 |
| `WorryDepositRepository` | `saved_records`, `worry_deposits` | STORED 到期改为 AVAILABLE，主动取回改为 RETRIEVED；不自动打开正文或调用 AI |
| `SearchOrchestrator` | `saved_records`, `saved_queries`, `sources`, `claims`, `evidence_links` | 查询中间态临时；主动保存后保留来源、主张和不确定性 |
| `DeletionService` | `deletion_jobs`, `deletion_targets`, `deletion_outbox`, `deletion_log_entries` | 事务内写 outbox；清除日志独立保留至少 8 天，用于恢复前重放 |
| `AuditService` | `audit_events`, `retention_policies` | 只记最小元数据；禁止密码、凭据、正文和 REQ14 内容 |

## 2. 查询请求

```json
{
  "requestId": "uuid",
  "entryPointId": "uuid",
  "mode": "FACT_QUERY",
  "rawQuery": "用户问题",
  "normalizedQuery": "保留时间/地区/版本限制",
  "locale": "zh-CN",
  "timeConstraint": {"from": null, "to": "2026-10-20"},
  "filters": {},
  "traceId": "opaque",
  "saveIntent": "NONE|ASKED|CONFIRMED"
}
```

### 服务端前置校验

1. 从有效 `login_sessions` 推导账号，不信任请求体中的 `userId` 或 `accountId`。
2. 检查入口能力和当前任务代次；跨入口读取要求有效 `consent_grants`。
3. 规范化不得删除“截至某日、仅限某地区、可能”等限制词。
4. 不把陪伴、排练、日历或寄存正文自动拼入查询。

## 3. 查询响应和状态

```json
{
  "answerId": "uuid",
  "searchState": "SUCCESS|EMPTY",
  "partial": false,
  "hasConflict": false,
  "summary": "摘要",
  "claims": [{"id": "uuid", "summary": "主张", "sourceIds": ["uuid"]}],
  "sources": [{"id": "uuid", "title": "标题", "url": "https://example.org", "publishedAt": null, "retrievedAt": "2026-10-20T00:00:00Z", "quality": "CURRENT|STALE|UNKNOWN"}],
  "uncertaintyNote": null,
  "canSave": true,
  "traceId": "opaque"
}
```

| 状态 | 说明 | 数据动作 |
|---|---|---|
| `NEEDS_CLARIFICATION` | 缺少关键条件 | 询问后再查；不创建保存记录 |
| `searchState=EMPTY` | 没有可靠结果 | 不生成假来源，不允许保存 |
| `partial=true` | 部分适配器成功 | 明示失败范围；保存状态为 PARTIAL_SUCCESS |
| `status=failed, failureReason=TIMEOUT` | 查询任务超时 | 可重试；迟到响应丢弃，不允许保存 |
| `hasConflict=true` | 证据冲突 | 并列展示差异；保存状态为 CONFLICTED |
| `source.quality=STALE` | 超过新鲜度窗口 | 标注过期风险；保存状态为 STALE_SOURCE |
| `ACCESS_DENIED` | 账号/入口/授权不符 | 外部调用前拒绝；审计不含正文 |

同一结果同时满足多个条件时，持久 `SavedQueryStatus` 按 `CONFLICTED` → `PARTIAL_SUCCESS` → `STALE_SOURCE` → `SUCCESS` 的优先级确定；临时 `SearchState` 不直接写入持久状态列。

## 4. 接口与隐私边界

- 保存事务同时写 `saved_records` 父行和对应类型子表；任一失败整体回滚。
- 查询结果默认临时；QUERY 保存请求只提交有效 `searchRequestId`，由服务端复制主张和来源并确定持久状态，客户端不得提交自造证据链。
- 写接口使用 `requestId` 幂等，更新使用 `versionNo` 乐观锁。
- 清除接口先令目标不可见，再返回 `deletionJobId`；后台传播状态必须可查询、可重试。
- 时间点以 UTC 保存，`record_date` 等日历日期按用户时区解释。
- REQ14 只使用独立端侧内存，不调用保存、聊天、模型、搜索、日志或遥测接口。
- 加密备份保留 7 天；恢复前重放至少保留 8 天的独立删除日志并撤销所有旧登录会话。

## 5. 明确不实现

密码找回/重置、公开主页、漂流瓶、账号注销、默认跨入口同步以及未保存消息持久化不在本轮范围内。
