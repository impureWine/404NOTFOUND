# 类—表映射与检索契约（交接摘要）

**主责**：庄剀涵 / 102400435  
**用途**：给李泉毅（后端/接口）和郭昱祺（交互/PPT）的短版交接材料。完整约束见《数据库设计说明书》和 PostgreSQL DDL。

## 1. 类—表交接

| 服务/类 | 表 | 交接约束 |
|---|---|---|
| `AccountService` | `user_account`, `user_profile` | `login_identifier_normalized` 唯一；只保存密码哈希；资料私密 |
| `SessionService` | `auth_session` | token 只存哈希；过期/退出立即失效；入口绑定 |
| `ConversationRepository` | `conversation`, `accepted_expression` | 普通会话不落库；只保存用户主动选择的范围 |
| `EmotionRecordRepository` | `emotion_record` | 保存不代表分析；日期按用户时区解释 |
| `WorryObjectRepository` | `worry_object` | shape 可单独保存；正文必须另行授权并加密 |
| `StoredConcernRepository` | `stored_concern` | 到期只将状态置为 READY；不自动打开正文或调用 AI |
| `SearchOrchestrator` | `saved_query`, `source`, `claim`, `evidence` | 查询中间态临时；保存时绑定可核查来源和不确定性 |
| `ConsentService` | `consent_record` | 只允许 scope/purpose/有效期内的跨入口读取 |
| `DeletionService` | `deletion_job`, `deletion_target` | 删除传播到主库、缓存、索引、派生物和备份延迟 |
| `AuditService` | `audit_event` | 只记最小元数据；禁止正文、密码、销毁文本 |

## 2. 查询请求

```json
{
  "requestId": "uuid",
  "entryPointId": "uuid",
  "mode": "FACT_QUERY",
  "rawQuery": "用户问题",
  "normalizedQuery": "保留时间/地区/版本限制",
  "locale": "zh-CN",
  "timeConstraint": {"from": null, "to": "2026-10-13"},
  "filters": {},
  "traceId": "opaque",
  "saveIntent": "NONE|ASKED|CONFIRMED"
}
```

### 服务端前置校验

1. 从有效 `auth_session` 推导主体，不信任请求体的 `userId`。
2. 检查入口能力和当前模式；无授权时在外部适配器调用前拒绝。
3. 对 `rawQuery` 做敏感信息提示/遮蔽；规范化不得删除“截至某日、仅限某地区、可能”等限定词。
4. 不把陪伴、排练、寄存正文自动拼进查询。

## 3. 查询响应和状态

```json
{
  "answerId": "uuid",
  "status": "SUCCESS|PARTIAL_SUCCESS|EMPTY_RESULT|TIMEOUT|CONFLICTED|STALE_SOURCE",
  "summary": "摘要",
  "claims": [{"text": "主张", "status": "SUPPORTED|CONFLICTED|UNKNOWN", "evidenceIds": ["uuid"]}],
  "sources": [{"title": "标题", "publisher": "发布者", "url": "https://example.org", "sourceTier": "S1", "publishedAt": null, "retrievedAt": "2026-10-18T00:00:00Z", "verificationState": "VERIFIED|PARTIAL|UNAVAILABLE"}],
  "uncertaintyNote": null,
  "canSave": true,
  "traceId": "opaque"
}
```

| 状态 | 说明 | 前端动作 |
|---|---|---|
| `NEEDS_CLARIFICATION` | 缺少关键条件 | 询问后再查；不创建保存记录 |
| `EMPTY_RESULT` | 没有可靠结果 | 告知已用条件；不生成假来源 |
| `PARTIAL_SUCCESS` | 部分适配器成功 | 展示失败适配器与可用结果 |
| `TIMEOUT` | 全部适配器超时 | 可重试或结束；迟到响应丢弃 |
| `CONFLICTED` | 证据互相冲突 | 并列差异、日期和层级；不强行选结论 |
| `STALE_SOURCE` | 超过新鲜度窗口 | 标注过期风险；不称“最新” |
| `ACCESS_DENIED` | 账号/入口/授权不符 | 外部调用前拒绝；审计不含正文 |

## 4. 与接口实现的边界

- 保存接口需要 `targetType`, `targetId`, `scope`, `consentId`（若涉及跨入口）；登录不等于保存许可。
- 清除接口先隐藏目标，再返回 `deletionJobId`；前端展示传播状态而不是假装即时物理删除。
- REQ15 只使用本地内存流程，禁止调用保存、聊天、模型、搜索和遥测接口。
- `requestId` + `versionNo` 用于幂等和并发控制；响应回填前需核对当前任务代次。
