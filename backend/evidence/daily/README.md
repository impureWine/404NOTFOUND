## 每天使用方法

1. 开工时将文档中的“待填”替换为当天真实任务和阻塞。
2. 当天运行指定命令，填写准确的通过、失败和耗时；不得直接复制前一天结果。
3. 只引用当天可访问的提交、Issue、截图和日志。
4. 将“预置材料”与“当日实际完成”分开写。提前完成的代码应如实写明首次完成日期，当天只登记复跑、评审或修复。
5. 删除所有未发生的模板文字后，再交给张王昊整合博客。
