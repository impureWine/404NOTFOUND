## 发现与实际修订

| 项目 | 修订及可观察行为 |
| --- | --- |
| 空结果被错误当成保存请求校验 | 将有效完成结果读取和可保存条件分开。完成的 `EMPTY` 可正常 GET 200，返回空来源和提示；保存仍 409，无新增记录；许可撤回后读取仍被拒绝 |
| 共享来源字段与实际响应不一致 | `searchSourceSchema` 从未使用的 `sourceId` 对齐当前实际 `id`；标题上限 512 码点，补齐摘录、发布者、来源质量、验证状态和时间。查询状态契约覆盖接受、成功、空、失败及取消 |
| 单来源/缺摘要缺少明确说明 | 仅有一个来源时说明缺少交叉核对；跳过无效来源或缺摘要时标记 `partial` 并提示信息可能不完整；说明随主动保存进入快照 |
| 供应商超时后仍保留响应流读取 | deadline/取消会取消 body reader，并释放读取锁；调用方取消保持 AbortError，供应商超时保持 TIMEOUT |
| 异常原因可能透传任意供应商 code | 公开失败原因仅允许已约定枚举，未知异常统一 SERVICE_UNAVAILABLE；不公开上游原始错误、请求 URL 或密钥 |
| 多字节摘录截断可能留下半个字符 | 按 Unicode 码点截断 4000 字的摘录；覆盖 emoji 边界，避免 UTF-16 半个代理字符进入保存正文 |
| 取消后残留说明元数据 | 清除 `partial`、`hasConflict`、`uncertaintyNote`，与正文/来源一起失效 |

当前 Bing 通过 SerpAPI 获取搜索摘录，不执行生成式事实总结。`claims=[]` 是查询任务中的当前契约；保存时将有摘录的来源转为 `UNKNOWN` 主张及 `CONTEXT` 证据，不把摘录标成 VERIFIED，不从“没有冲突信号”推导事实不存在冲突。

| 场景 | 实际结果 |
| --- | --- |
| 真正无结果 | GET 200，`completed/EMPTY`，`sources=[]`，`answer=''`；有调整关键词提示；保存 409 |
| 无摘要/部分无效来源 | 保留安全来源；`partial=true`；可保存和回看全部来源，`claims=[]` 也不会丢来源 |
| 仅一个可用来源 | 明确提示缺少交叉核对，查询及保存说明一致；条数少不冒充供应商失败 |
| 未配置/认证失败/额度不足 | 合成 HTTP 链路分别为 SEARCH_NOT_CONFIGURED / SEARCH_AUTH_FAILED / SEARCH_RATE_LIMITED |
| 上游错误/畸形响应/全无效来源/网络错误 | SERVICE_UNAVAILABLE；不伪装成可靠的空结果 |
| 超时 | 任务 GET 200，`status=failed,failureReason=TIMEOUT`；不暴露旧正文，禁止保存 |
| 失败后重试 | 新 requestId 重新获取许可后成功，主动保存 201 |
| 已完成结果结束/取消 | 旧正文、来源、查询状态和不确定性说明全部移除 |

全量通过包含既有缺陷签名探针，不表示 B01 遗留缺口全部关闭。PGlite 的事务调度不能替代 PostgreSQL 多连接锁竞争；本次没有正式数据库迁移、实网来源抽查、浏览器截图或团队独立复核。

来源主键有两种作用域：查询任务中的 `sources[].id` 是适配器按规范 URL 生成的稳定编号；保存详情中的 `content.sources[].id` 是数据库来源编号。两者不保证相同，跨查询/快照核对使用规范 URL 及所属查询，不按两个 ID 直接相等判断。`publishedAt` 不可得时为 null，不能以 `retrievedAt` 冒充发布时间。

新增 `scripts/verify-search-snapshot.js`，可在后端配置就绪后做一次固定公开问题的检索，并在**独立内存 PGlite** 中验证许可、任务状态、来源快照、可读回看和幂等重试。它不连接 DATABASE_URL，不将真实用户正文外发。输出仅记录结构化状态与公开来源，不输出原始异常或配置内容。

```powershell
# 后端本地 .env 配置好 SERPAPI_API_KEY 后执行：
node scripts/verify-search-snapshot.js
# 或指定仅保存在本机的配置文件路径：
node scripts/verify-search-snapshot.js --env-file 'C:\path\to\backend.env'
```

退出码：0 表示真实来源已保存并校验快照；2 表示缺配置或可靠空结果；1 表示请求/验证失败。缺配置时不会调用供应商；已配置后会产生一次真实检索调用，按账户额度计费。仍需独立抽查来源内容与浏览器展示，成功返回不能替代事实核验。
