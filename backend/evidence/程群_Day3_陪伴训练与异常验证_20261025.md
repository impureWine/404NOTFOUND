## 1. 当日交付

### 1.1 命名卡与陪伴路由

- `POST /api/naming-card/route`：`LISTEN`、`ORGANIZE` 路由到 `COMPANION`；`SEARCH` 路由到 `SEARCH`，并要求先补充明确问题。
- `POST /api/agent/tasks`：按现有共享契约创建陪伴任务；只发送用户本轮明确选择的文本。
- `GET /api/agent/tasks/:requestId`：读取本人当前任务状态和已完成回复。
- `POST /api/agent/tasks/:requestId/cancel`：取消任务并删除尚未展示的结果。
- AI 任务使用 `sessionGeneration`、`activityGeneration`、活动 ID、拥有者和会话状态共同校验接收资格。

### 1.2 一种基础训练

实现静态审核步骤的“五感安定练习” `FIVE_SENSES`，不依赖模型自由生成步骤。

- `POST /api/trainings`：开始训练。
- `GET /api/trainings/:id`：读取当前步骤、状态、版本和有效练习时长。
- `POST /api/trainings/:id/actions`：支持 `NEXT`、`PAUSE`、`RESUME`、`EXIT`。
- 暂停后 `elapsedMs` 冻结，继续时保持原步骤；退出后步骤置空，不能恢复。
- 所有动作带 `expectedVersion`，陈旧操作返回冲突，训练会话按当前身份隔离。

## 2. 异常用例结果

| 用例 | 操作 | 实际结果 | 结论 |
|---|---|---|---|
| 模型超时 | 模拟适配器返回 `MODEL_TIMEOUT` | AI 任务进入 `failed`，`failureReason=TIMEOUT`，无 `result` | 通过 |
| 暂停时仍有模型请求在途 | 建立未完成请求后执行 `PAUSE` | AbortSignal 已中止，任务进入 `cancelled` | 通过 |
| 暂停后继续，旧供应商回复迟到 | `PAUSE → RESUME → 旧 Promise resolve` | 原任务保持 `cancelled`，`result` 仍不存在，未回填 | 通过 |
| 退出会话后旧回复迟到 | 在途请求执行 `END` 后再返回 | 原任务保持 `cancelled`，未回填 | 通过 |
| 训练暂停 | 运行 1250 ms 后暂停，再推进测试时钟 | `elapsedMs` 保持 1250，步骤保持 `SEE` | 通过 |
| 训练继续 | 暂停后执行 `RESUME` | 状态回到 `running`，仍从 `SEE` 开始 | 通过 |
| 训练退出 | 第二步执行 `EXIT` | 状态为 `exited`，当前步骤为 `null`，再次继续被拒绝 | 通过 |
| 陈旧训练动作 | 提交错误 `expectedVersion` | 返回冲突，不修改训练状态 | 通过 |
| 跨身份读取训练 | 使用另一匿名会话 ID 读取 | 返回不存在，不暴露训练内容 | 通过 |

迟到回复拦截采用两层保护：控制动作先把任务标记为 `cancelled` 并触发 `AbortController`；即使供应商忽略取消并最终返回，写入前仍重新校验任务状态、活动 ID、代次和会话状态。
