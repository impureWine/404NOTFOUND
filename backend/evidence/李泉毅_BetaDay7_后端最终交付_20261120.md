## 2. API 与运行入口

主要接口及约束继续以 `backend/README.md` 和共享契约为准：认证、许可、业务会话、AI/查询任务、记录保存/详情/清除。除健康检查与首次认证上下文外，写请求需要同源 `Origin`、有效会话 Cookie 和 `X-CSRF-Token`；私密资源还按账号与入口隔离。

本机验证：

```powershell
cd backend
pnpm install --frozen-lockfile
pnpm test
pnpm run check:release
pnpm start
```

生产环境启动前必须由独立发布步骤完成迁移，且配置至少满足：`NODE_ENV=production`、HTTPS `APP_ORIGIN`、安全 Cookie、`DATABASE_URL`、`DATABASE_SSL=true`、`MIGRATE_ON_START=false`、`PROFILE_ENCRYPTION_KEY`、`REGISTRATION_IDEMPOTENCY_KEY`、`ZHIPU_API_KEY`、`SERPAPI_API_KEY`。检查脚本和启动门禁不会输出密钥值。
