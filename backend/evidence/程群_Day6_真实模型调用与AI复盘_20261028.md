## 3. 超时、限流与不可用演示预案

### 3.1 状态与动作

| 场景 | 当前后端结果 | 演示时动作 | 不能宣称的内容 |
|---|---|---|---|
| 真实调用成功 | HTTP 200、`status=success`、`mock=false` | 展示合成输入、模型标识、耗时与回复；不展示密钥和原始请求头 | 不能由单次成功推导稳定性、生产可用性或内容安全已经全面通过 |
| 30 秒超时 | HTTP 504、`MODEL_TIMEOUT`、可重试 | 停止加载，说明上游超时；保留用户输入，由用户决定稍后重试或退出 | 不能说供应商一定停止计算或不会计费 |
| 供应商限流 | HTTP 429、`MODEL_RATE_LIMITED`、可重试 | 不连续重试；展示今日脱敏真实记录；等待限流窗口或改走明确标记的离线演示 | 不能把限流记录说成模型成功生成 |
| 服务/凭据不可用 | HTTP 503、`MODEL_UNAVAILABLE`、可重试 | 明确提示服务暂不可用；不展示内部异常；允许结束会话 | 不能显示假回复或伪造来源 |
| 调用方取消 | HTTP 499、`MODEL_CANCELLED`、不可自动重试 | 立即结束当前任务；迟到回复不得回填 | 不能把用户取消描述成超时 |
| 课堂离线演示 | `MockModelAdapter`、`model_info.mock=true` | 页面和讲解必须标明“模拟结果”，只演示状态流和异常处理 | 不能作为真实模型、真实检索或线上部署证据 |

### 3.2 演示前检查顺序

1. 演示前查看智谱控制台的免费模型可用状态、限流规则、调用记录和账单；不把密钥截图放入材料。
2. 只执行一次 `npm run smoke:model`。成功则保存脱敏输出；失败则按错误码停止，不连续请求。
3. 执行 `npm run test:ai`，确认正常、超时、限流、不可用、取消、空输出和非法输出契约没有回归。
4. 执行 `npm run sample:ai`，准备可离线复现的正常、超时和不可用样例；所有样例保留 `mock=true`。
5. 在实际演示页面复核加载停止、错误提示、输入保留、重试/退出按钮及模拟标识。当前后端测试不能代替这一步。

### 3.3 现场讲解稿

> 当前候选版请求固定使用智谱 `glm-4.7-flash`，30 秒超时且不自动重试。今天的真实调用被供应商限流，所以我们保留了真实失败记录，没有把模拟结果冒充成功。现场服务可用时展示真实合成回复；超时或不可用时展示明确错误，并切换到带 `mock=true` 标记的离线流程，只说明异常处理可复现。

## 5. AI 贡献复盘

### 5.1 实际贡献

| 阶段 | AI 协助内容 | 人工确认与落地 |
|---|---|---|
| 配置与适配 | 对照模型契约检查白名单、最小输入、输出结构和错误映射 | 人工确定只允许免费模型、0 次自动重试、256 tokens，密钥只放环境变量 |
| 异常修复 | 沿调用链发现取消与超时语义混淆、未授权内部模型入口、非分类任务意图越界等问题 | 人工复核业务边界后修改代码并补自动化测试 |
| 安全边界 | 提示固定安全路由、越界输出拒绝、迟到回复隔离等缺口 | 人工决定窄规则仅用于演示范围，不把它描述为临床风险评估或通用内容安全层 |
| 回归材料 | 生成测试矩阵、调用记录和复盘初稿，汇总正常/失败/敏感路径 | 人工执行命令、核对真实输出，并保留 429 和 4 项全量失败，不修改为通过 |

### 5.2 可量化结果

- AI 专项现有 40 项测试全部通过，覆盖正常、5 类模型失败、2 类合成敏感表达、取消/迟到回复及训练控制。
- 内部模型入口缺少凭据时在适配器调用前返回 403；本轮复跑仍通过。
- 今日取得 1 条真实供应商限流记录，并明确标为阻塞；没有使用 Mock 冒充成功。
- 全量回归保持 107/111，4 项失败被如实保留并进入交接。

### 5.3 局限与人工责任

- AI 不能替代智谱控制台的限流、账单、留存和服务条款核对，也不能凭配置模型 ID 证明供应商实际执行的模型。
- 合成敏感场景与窄规则不代表真实用户安全验收；仍需人工标注集、误判/漏判指标和安全评审。
- 自动化后端测试不证明浏览器页面、云端网络、多实例任务队列或正式 PostgreSQL 已经通过。
- 最终产品文案、重试体验、备用供应商、费用上限和是否允许真实用户数据外发，必须由产品、安全和项目负责人共同决定。
