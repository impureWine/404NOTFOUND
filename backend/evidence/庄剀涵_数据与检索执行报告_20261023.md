## 2. 实际测试结果

执行命令：

```powershell
node <Codex运行时pnpm路径> test
```

结果：

```text
tests 19
pass 19
fail 0
cancelled 0
skipped 0
todo 0
duration 约7.6秒
```

主要通过项：

- 001与002迁移在干净隔离库执行，重复运行不重复应用。
- 数据库唯一约束拒绝重复标准化登录名。
- 账号、凭据、资料和偏好同事务生成。
- 会话摘要长度、有效查询和撤销路径通过。
- 私密记录同时按账号和入口过滤。
- 同requestId同载荷返回原结果，不同载荷返回冲突。
- 错误版本不能清除记录；清除后列表和详情均不可见。
- 删除任务、目标和outbox同事务生成。
- 寄存到期不自动返回正文，主动取回后才返回密文字节。
- 查询证据只能绑定本次提供的来源；其他账号不能读取。
- 查询状态优先级符合 `CONFLICTED > PARTIAL_SUCCESS > STALE_SOURCE > SUCCESS`。
- 检索空结果与超时能够明确区分。
- 隔离恢复在删除日志重放未确认时拒绝开放；确认后撤销旧会话。
