# 桌宠与快捷功能面板

启动后仅显示现有的蓝色毛绒角色，图片沿用 `assets/pet-mascot.png`。点击角色展开面板，再点角色、右上角收起按钮或 Esc 可收起。颜色与当前网页共用粉色 `#c86b8c`、浅粉 `#f9eaf0`、米白及浅绿风格；面板展开和收起保持窗口右下角位置，并限制在屏幕可用区域。

## 功能

- 聊一聊：选择倾听或梳理，在工作台打开陪伴交流 / 事情整理，不在桌宠中伪造 AI 回复。
- 放松一下：本地一分钟 4 秒吸气 / 6 秒呼气，明确开始、暂停、继续和重来；五感 5/4/3/2/1 手动步骤。不需要模型或检索密钥。
- 记心情：临时选择心情词；点击按钮进入日历正式填写保存，不会静默上传或保存。
- 先放一放：打开烦恼寄存所。更多入口包括备忘历史、排练、命名卡、信息查询和小游戏。
- 设置：点击穿透、隐藏和退出。Alt+Shift+P 唤回隐藏窗口并恢复点击。桌面发泄浮层按 Esc 退出。

切换面板、收起和退出会停止呼吸计时；窗口隐藏时暂停，不自动恢复。心情词仅在本次展开期间使用，收起后清空；不读文件、不发网络请求、不持久化填写。选择工作台功能后再由对应页面取得模型 / 检索 / 保存许可。

## 启动

先启动网页前后端，再从 prototype 运行：

```powershell
$env:DESKTOP_APP_URL='http://127.0.0.1:5173'
npm.cmd run electron:dev
```

默认地址仍为 `http://127.0.0.1:5174`。如需桌面独立入口，使用 `APP_ENTRY_POINT=DESKTOP`、`PORT=3001`、`APP_ORIGIN=http://127.0.0.1:5174` 的后端，以及代理到 3001 的前端；然后设置对应 DESKTOP_APP_URL。完整环境配置见 `../../docs/真实服务接入与运行.md`。需要已安装 Electron 二进制。

## 边界与验证

主进程只接受本桌宠发出的固定操作，网页入口使用路由白名单；不接受任意 URL、IPC 通道或窗口尺寸。工作台保持隔离会话分区、禁用 Node、启用 sandbox、拒绝跨来源导航及任意新窗口；密钥仍只在后端。桌宠不推断工作台登录状态，因此不展示虚构的已登录昵称。

自动化验证计时的未开始 / 暂停 / 完成 / 清理，展开位置、入口白名单、发件窗口校验及隐藏恢复。源码与自动化通过不等于已完成原生窗口验收，目标电脑还应检查角色展开、卡片布局、轻练习与工作台路由。
