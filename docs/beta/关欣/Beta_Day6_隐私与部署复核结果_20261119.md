### 2.2 R08 发布门禁

```text
cd backend && npm run check:release
Release readiness: BLOCKED
- DATABASE_URL is required
- PROFILE_ENCRYPTION_KEY is required
- REGISTRATION_IDEMPOTENCY_KEY is required
```

门禁的判定分支：`NODE_ENV=production` 时额外要求 secure cookie、`APP_ORIGIN` 为 https、`MIGRATE_ON_START` 不得为 true、数据库连接启用 TLS、`ZHIPU_API_KEY` 与 `SERPAPI_API_KEY` 存在。本次 `NODE_ENV` 未设为 production，故只报了上面三项。

## 4. 对 Day7 的交接
