## 7. 心得

今天最直接的一条是**"先拼起来再谈结论"**。之前每个人都说自己的分支测试全绿，但没人知道三个分支叠在一起会怎样。叠一次，冲突和三处取舍立刻暴露，而且原本最有争议的四条 P0 判据反而全部一次性过掉了——问题不在修复本身，在没人把它们放到同一份代码上。

第二条是**冲突不一定是文本冲突**。`invalidateConsent` 两个定义 git 都没报冲突（位置不重叠），但运行起来后定义的会覆盖前者，两个测试文件还各自按自己的签名调用。这种"合并成功但语义打架"只有跑测试才看得见。
