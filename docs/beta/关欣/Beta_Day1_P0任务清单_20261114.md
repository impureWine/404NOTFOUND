## P0（阻断，必须在 Day2 前后给出结论）

### P0-01｜REQ14 文字销毁仍无可达页面

| 项 | 内容 |
|---|---|
| 现象 | `web-prototype` 无任何销毁页面；`App.jsx` 未挂载 `ROUTES`/`DesktopPet`；构建产物中 `/destroy` 等地址只回退到首页外壳 |
| 影响 | 临时内容规则无法验收；Beta Day5 的"隐私专项"失去观测对象； |
| 矩阵条目 | C-05 |
| 责任 | 程杰（前端接入）、郭昱祺（入口与文案）、关欣（取证与结论） |
| 验收条件 | ①首页存在可点击入口；②销毁页可打开且显示独立输入区；③四项运行时证据齐全：Network 无携带正文请求、LocalStorage/SessionStorage/IndexedDB 无正文、控制台无正文、重开页面不恢复；④结论写入 Beta 安全结论，`NOT-EXECUTED` 改为 `PASS/FAIL` 之一 |
| 复现 | `Beta_Day1_问题复现步骤_20261114.md` 第 2 节 |
| 备注 | 该模块代码本身是干净的（无 storage/fetch/定时器），缺的只是**页面接入** |

### P0-02｜失效会话的写请求返回 403 而非 401

| 项 | 内容 |
|---|---|
| 现象 | 退出后用旧 Cookie 发写请求，返回 403 `ACCESS_DENIED`；读请求返回 401 |
| 影响 | 前端会把"会话过期"误判为"权限不足"，用户得不到正确引导；错误契约不一致 |
| 矩阵条目 | A-02 |
| 责任 | 李泉毅（`http/request.js` 中间件顺序） |
| 验收条件 | 失效会话写请求返回 **401 `AUTH_REQUIRED`**；记录未被清除；D5-10 断言由 403 改为 401 |
| 复现 | 复现步骤第 3 节（`request.js`：`resolveContext` → `verifyCsrf` → `requireAuthentication`） |
| 备注 | Alpha 记为 D5-10，结转至 Beta |

### P0-03｜用途许可不可互换：Beta 候选上尚未复测

| 项 | 内容 |
|---|---|
| 现象 | 实现存在（`task-service` 与 `record-service` 各自 `assert`），但本日未在 Beta 候选重跑"跨用途"反例 |
| 影响 | 若回归，会出现用保存许可触发外发（或反之）的跨用途写入面 |
| 矩阵条目 | P-01 |
