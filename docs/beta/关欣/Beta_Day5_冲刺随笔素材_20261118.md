## 7. 心得

今天最有价值的一条是**"能打开的页面"和"代码里登记的页面"不是一回事**。`routes.jsx` 里明明写着 `destroy: { title: '文本销毁', page: DestroyPage }`，看代码会以为入口有了；但整个 `prototype/src` 没有任何文件 import 这个路由表，也就是说那页永远不会被渲染。判断入口不能看有没有定义，要看有没有引用、有没有挂到实际路由上——这次是用"引用数 = 0"把它钉死的。

第二条是**结构级证据要说清楚它证明了什么**：探针证明的是代码路径里没有 `fetch` 和 `localStorage`；运行时是否真的没有请求，由浏览器抓包回答。报告按这两层分别写，引用时各归各的。
