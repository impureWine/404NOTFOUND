## 3. 冲突与决策

| 位置 | 冲突内容 | 本岗取舍 | 需要谁确认 |
|---|---|---|---|
| `task-service.js` 会话动作 | #145 单块条件参数 vs #176 拆成 PAUSE/FINISH 与 RESTART/END 两段 | 取 #176 两段式，保留 `includeCompleted` | 程群 |
| `task-service.js` 清理字段 | #145 逐字段删除（含 `searchState/partial/hasConflict/uncertaintyNote`） vs #176 统一 `cancelTask()` | 取 `cancelTask()`，并把 #145 的四个字段并入 | 程群 / 庄剀涵 |
| `task-service.js` 方法定义 | **两个 `invalidateConsent` 并存**：#176 `(consentId)` 全局；#128 `(context, consentId)` 按账号+入口 | 取 #128 作用域版，统一走 `cancelTask()`，改掉 #176 两条测试签名 | 程群 / 李泉毅 |
| `app.js` 调用点 | 1 参 vs 2 参 | 取 #128 的 2 参 | 李泉毅 |
| `search-task.js` | **两套失败契约互斥**：#128 用 `taskFailureReasonSchema`（`RATE_LIMITED`/`OUTPUT_INVALID`），`SEARCH_AUTH_FAILED→PROVIDER_UNAVAILABLE`；#145 用 `searchFailureReasonSchema`（`SEARCH_RATE_LIMITED`/`SEARCH_AUTH_FAILED`/`SEARCH_NOT_CONFIGURED`），未知→`SERVICE_UNAVAILABLE` | **未替作者决定**，两种取向各跑一遍 | 李泉毅 / 庄剀涵 |

另有一个环境坑：合并 `shared/` 后必须 `pnpm install` 刷新 `node_modules/@404notfound/contracts` 副本，否则测的是旧契约。
