## 2. 必须确认的语义

1. 取消响应是否只确认应用任务终态，还是有供应商可验证的取消回执？UI 仅按可证明范围措辞。
2. 许可撤回是否要联动取消已受理任务？现状仅禁止该许可后续使用，不能承诺自动停止。
3. END 后已完成任务的 result 是否仍允许读取？若要求临时结果不可读，应补后端清理和回归断言。
4. 401 从所有私密操作统一传播；403 权限问题保留自己的恢复动作。写请求失效403的历史问题需按新候选验证。
5. 已完成训练返回、结束交流与退出页面的清空范围是否统一？已有记录不随结束删除。

这些是团队契约确认项，本日不擅自更改 API 或认领生产页面。
