# 复现与启动

要求Node.js≥22.12、pnpm、Windows Edge及playwright（或兼容playwright-core）。仓库目录保持backend/prototype/shared相对位置。先记录`git rev-parse HEAD`；已提交脚本的输出会覆盖本目录evidence，建议在干净副本执行，保留本次归档。

```powershell
# 仓库根目录；后端按现有锁文件安装
pnpm --dir backend install --frozen-lockfile
# 前端沿用当前安装方案，不提交本机node_modules
npm --prefix prototype install
$env:UX_DAY7_SOURCE_SHA = (git rev-parse HEAD)
$env:PLAYWRIGHT_MODULE_PATH = '本机playwright/index.mjs或playwright-core/index.mjs的绝对路径'
$env:NODE_PATH = '本机包含playwright包的node_modules目录'
node docs/beta/郭昱祺/Day7_20261120/scripts/browser-core.mjs
node docs/beta/郭昱祺/Day7_20261120/scripts/browser-record-lifecycle.mjs
node docs/beta/郭昱祺/Day7_20261120/scripts/ux-walkthrough.cjs
```

前两个脚本默认Windows Edge路径，可用EDGE_EXECUTABLE_PATH指定。最后一个使用playwright的msedge通道。端口5194/5195/5196必须空闲；各脚本只监听127.0.0.1，结束关闭HTTP、浏览器和隔离PGlite。不读正式.env，不发真实模型/搜索请求；生成账号/密码均合成，测试加密常量仅用于隔离库，不能复制为部署密钥。

本次backend按pnpm锁安装（忽略生命周期脚本），没有修改锁文件。前端测试命令`node --test`（在prototype）；构建`node node_modules/vite/bin/vite.js build`。本机Node24.22.1、Edge headless、Asia/Shanghai页面/反馈日期。

普通人工交互需要常驻服务，依照[真实服务运行指南](../../../真实服务接入与运行.md)配置隔离测试数据库、后端和5173前端；默认前端没有自动mock回退，不要直接打开HTML或把临时脚本URL当在线服务。正式环境需另补配置/安全与独立验收，今天未启动正式服务。
