# 使用说明与试用边界（Beta Day7）

版本：2026-11-20；受测源码 `47feb4dbfc436e7e14b7164ab394036e1bfd8a21`。适用：组内排练及后续试用准备。前端为实际React界面，登录和保存链路使用本机HTTP与隔离PGlite，模型/检索输出由脚本合成；异常专项全部拦截API。没有真实供应商、正式数据库或真人反馈结论。

## 开始前

首次使用从首页“开始体验”进入陪伴；“打开情绪日历”进入日历。访客可以浏览，账户记录需要登录。窄屏点“切换导航”展开菜单，Esc收起并回到开关；登录对话框中Esc关闭并返回触发按钮。登录使用组织者提供的合成测试账号，禁止把真实密码或私密正文放入反馈和截图。

新环境先按[复现与启动](复现与启动.md)准备。脚本入口5194、5195、5196均为临时服务，脚本结束即关闭；它们不是长期在线网址。当前正式发布检查仍BLOCKED，不能直接作为公开试用环境。

## 主要操作

| 页面/路径 | 操作 | 观察与边界 |
| --- | --- | --- |
| 首页 `/#home`、登录弹窗 | 首页或侧栏选择注册/登录；按字段填写后提交 | 注册成功后还需登录；等待中避免重复点击；失败按提示核对，不把访客预览当登录成功 |
| 陪伴 `/#companion` | 填写“本次输入”→勾选本轮模型授权→“发送” | 默认不保存；额外历史需明确选择；等待可“停止本次请求”；失败输入保留，可手动发送重试 |
| 查询 `/#search` | 填写“具体问题”→勾选检索授权→“查询” | 看每条来源的标题、摘录、发布/获取时间和核验状态；获取时间不是发布时间；摘录不是已证实结论 |
| 查询快照 `/#query-records` | 有来源后“主动保存本次来源与摘录”→查询记录→“已保存查询” | 保存许可与检索许可分开；打开是当次快照，不重新查询；页面原始UNKNOWN标签表示未核验，不可宣称事实正确 |
| 五感 `/#training` | “开始练习”→可选填写或跳过→“暂停”/“继续” | 暂停不推进；有填写时“退出练习”弹系统确认，取消则保留；确认退出回选择页；完成后“完成并返回” |
| 文字备忘与全部历史 `/#notes` | 输入标题/正文→“检查并选择保存”→核对快照→勾选许可→“确认保存” | 服务端确认后再说保存成功；详情可回看；刷新保留的是已保存记录；结果未知时用“用同一请求重试核实” |
| 清除（历史内） | “清除”→检查待清除条目→“确认清除” | 最后确认前记录仍在；成功后列表更新、旧详情不可读；查询/日历使用原生确认弹窗，呈现不同但同样需明确确认 |
| 情绪日历 `/#calendar` | 选择日期→可选情绪词/强度/备注→“确认保存到本人账户” | 情绪词与强度可跳过；日历不自动加入AI上下文；颜色不是评估；保存后可刷新回看或清除此条 |
| 桌宠团团（扩展） | 展开→“记心情”或“心情日历” | 记心情只是临时选择，收起后清除；“心情日历”需进入工作台另行保存；本日仅验证HTML渲染器，原生窗口/快捷键待验证 |

## 出现异常时

| 状态 | 如何判断 | 下一步 |
| --- | --- | --- |
| 正常 | 有明确回复、来源或服务端保存确认 | 先核对内容，需要保留时再主动保存 |
| 加载/等待 | 有“正在…”状态；重复提交按钮禁用；日历概览为“—” | 等待或主动停止；不能把未读取当作0条记录 |
| 空 | 完成读取后没有记录/没有来源/初始无输入 | 修改问题或主动创建记录；空来源不等于服务失败 |
| 失败/未知 | alert说明失败、保存未确认、日历记录未确认 | 保留草稿并手动重试；历史/日历点“重新读取”；查询停止仅代表本机停止等待，服务器取消未确认 |

没有提供操作系统级彻底擦除保证，也不能用清除按钮推断供应商或备份数据被删除。日历320px数字可读，但背面长文案/触控尺寸/读屏与更多设备仍需评审。日历完整内容可在选中日说明与下方记录列表阅读。
