# 日历与桌宠入口文案核对

计划11月18日，实际11月19日补做。采用当前实现，不新增功能。逐条文案见[CSV](状态文案.csv)。

| 入口 | 当前实现与核对 | 结论 |
| --- | --- | --- |
| Web情绪日历 / 桌宠心情日历 | 均对应calendar；访客只读预览，登录后读取本人记录；保存须明确点击 | 路由对应；暂保留两种友好称呼，在交接中注明同一功能 |
| 桌宠记心情 | 面板选择临时保留，提示不会自动保存；“打开日历，填写并保存”要求到工作台确认 | 原HTML渲染器实际操作通过；未验证原生窗口跳转、账号和持久化 |
| 桌宠放松一下 | 本地呼吸/五感；开始、暂停、继续，离开停止 | 本包核对静态文案与现有实现；计时回归见既有前端测试，不声称本次原生训练验收 |
| 桌宠先放一放 | 对应deposit烦恼寄存所，是否保存由工作台确认 | 路由与文案核对；未新增自动存储 |
| 设置、隐藏与退出 | 说明Alt＋Shift＋P恢复与退出入口 | 浏览器文案检查通过；真实系统快捷键、隐藏恢复、进程退出仍待原生测试 |
| Web担忧桌宠 | 实际对应worry烦恼物件化，不是启动原生团团桌宠 | 讲解时明确入口含义；若改名需产品另行选择，本次不擅自更名 |

修订日历的等待和失败文案：未知状态不写成“还没有记录”，加载时不展示0天；只有读取成功且无条目才展示空态。保存失败保留输入，与列表读取失败分开处理。

本月天数是“已加载记录”范围，存在分页时不能等同于整月所有记录；当前措辞保留“已加载本人主动记录”。本包未验证跨时区、月底、数据库日期归属和多页完整性，交给数据/测试在新候选补验。
