# 复现说明

在仓库根目录安装prototype锁文件依赖，并准备官方Playwright和本机Edge。Windows示例：

```powershell
$env:NODE_PATH = '本机包含playwright的node_modules目录'
$env:UX_PHASE = 'after'
node docs/beta/郭昱祺/Day5_20261118/walkthrough.cjs
cd prototype
node --test
node node_modules/vite/bin/vite.js build
```

脚本从仓库根目录运行，端口5191；输出覆盖本包after证据，建议另建工作副本复跑。before基线已归档，重新设置before不会自动切换旧代码；如需复现旧行为，先在独立副本检出原始基线，再运行脚本。

每个页面的API全部合成拦截，源码模块资源不属于API。桌宠原HTML、CSS、JS通过受控静态资源加载；不注入桌面IPC。所有输入为合成材料。K03检查原生dialog内交互控件循环，并允许浏览器循环间短暂停在body；不等于全部读屏软件验收。

原始JSON含计划/执行日期、源码提交、源码哈希、每项预期/观察及API路径；不包含真实账号密码或访问令牌。测试日志为本次源码运行，未累计他人测试岗的测试数。
