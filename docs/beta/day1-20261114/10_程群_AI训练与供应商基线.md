# 程群｜AI、命名、训练与供应商基线

## 状态与终态

| 能力 | 当前实现 | 取消/超时/限流/终态 |
| --- | --- | --- |
| 命名卡 | 确定性路由；LISTEN/ORGANIZE进入陪伴，SEARCH先澄清问题 | 选词本身不调用模型、不检索、不保存 |
| 陪伴任务 | AI_PROCESS许可后创建，绑定账号/入口/会话/活动代次 | 取消、暂停、重启、结束、换号会中止；迟到回复不可回填 |
| 模型适配 | 智谱官方地址白名单、模型白名单、输出契约、动作白名单 | TIMEOUT、PROVIDER_UNAVAILABLE、OUTPUT_INVALID分离；调用方取消不误报超时 |
| 训练 | 呼吸、五感、暂停整理、任务拆分 | ready/running/paused/completed/退出；离页和卸载释放计时资源 |

## Day1运行结果

- `pnpm run sample:ai`：离线合成正常、超时、不可用和命名路由样例成功；结果明确标记 mock。
- `pnpm run smoke:model`：退出1，`MODEL_UNAVAILABLE`；本机未配置供应商密钥，没有真实返回，不登记为真实模型通过。
- 后端 AI、取消、迟到响应、训练等包含在165项全量回归中并通过；前端训练/资源清理包含在46项测试中并通过。

## 异常清单

1. 模型版本配置不一致：文档/示例为 `glm-4.7-flash`，代码白名单为 `glm-4.5-flash`。需确认批准型号、价格/额度和真实账户可用性后统一。
2. 缺少 `ZHIPU_API_KEY`，真实供应商调用阻塞；不得借用合成结果替代。
3. 正式环境尚无共享任务队列、限流、密钥轮换和生产级监控；当前内存任务适用于开发验收。

真实调用复测必须只用合成输入，记录候选SHA、供应商返回状态、延迟和额度；不得打印密钥、请求头或供应商原始敏感错误。
