# 郭昱祺｜核心流程与交互状态基线

核对候选：`d2073489a8be92c38e1f57da7562e487058c501a`。本表依据当前 React 页面与 API 客户端走查，作为 Day2—Day4 的交互验收输入；不等同于真实浏览器端到端验收。

| 流程 | 用户步骤 | 正常 | 等待 | 空状态 | 失败与恢复 |
| --- | --- | --- | --- | --- | --- |
| 登录/换号 | 打开登录→输入凭据→提交→读取上下文；退出后再登录 | 展示本人昵称与资料 | 表单禁用并保留输入 | 未登录时只展示登录/注册入口 | 显示服务端错误；退出、登录、改密均清空内存 CSRF，重新读取上下文后再写入 |
| 陪伴/命名 | 选情绪与需要→进入陪伴→再次确认发送→轮询任务 | 回复仅属于当前会话、活动代次和入口 | 明示“等待”，允许取消 | 未输入不发送；空回复不得作为成功 | 超时、供应商不可用、输出无效分别提示；切模式、暂停、结束、换号后旧回复不得回填 |
| 查询 | 输入问题→确认检索许可→查看来源→可选主动保存 | 展示摘录、原链接、获取时间与不确定性 | 检索中可取消 | 0条来源显示“未找到”，不伪造答案 | 超时/鉴权/额度/网络错误使用检索专属文案，可重试；不误报为模型错误 |
| 训练 | 选择练习→开始→暂停/继续→完成或退出 | 状态与步骤可见，显式操作才推进 | 未开始和暂停均不计时 | 无填写可跳过，不自动分析 | 离页、隐藏、退出、卸载释放计时器；重新进入从明确初态开始 |
| 历史 | 登录→列表→详情→可选编辑或两步清除 | 只读本人当前入口记录 | 读取期间禁用重复操作 | 空列表明确显示“暂无记录” | 失败保留重试入口；清除后详情、列表和关联视图同步失效 |

## 通用验收项

- 所有异步操作均需可识别的等待、成功、空、取消和失败状态；取消不显示为失败。
- 换号、退出、切入口、切活动后，旧请求即使迟到也不能覆盖新上下文。
- 错误提示保留可操作的重试/返回路径，不展示密钥、原始响应正文或内部异常。
- 键盘走查：对话框打开后焦点进入首个有效控件；提交期间不可重复提交；关闭后焦点回到触发控件。
