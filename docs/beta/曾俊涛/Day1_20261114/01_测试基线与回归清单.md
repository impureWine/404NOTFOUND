## 测试入口问题及处理

对应团队 [Issue #112：修正 Windows 集成测试目录入口并复测](https://github.com/impureWine/404NOTFOUND/issues/112)。Issue 指定曾俊涛负责、李泉毅协作、关欣独立复核。历史材料记录过 Windows shell glob 不展开的问题。当前候选把脚本写为 `node --test test/integration`，但 Node 将目录当作模块路径并报 `MODULE_NOT_FOUND`。本地将脚本改为 `node --test test/integration/*.test.js`，Node v24.18.0 在 Windows 下发现并执行全部 51 个集成用例。此处是作者自测结果；关欣的独立复核与 Issue 关闭结论尚未取得。
