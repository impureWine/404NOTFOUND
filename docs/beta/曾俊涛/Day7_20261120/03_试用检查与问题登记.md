# Beta Day7｜试用检查与问题登记

适用阶段：11月21—26日用户反馈准备。执行前先登记**试用候选 SHA、运行入口、环境、提供者与试用日期**，由张王昊和功能负责人确认可访问范围。当前 `97ecb8b` 只完成本机合成路径验证，**不以它开展真实私密内容的线上试用**；若仅排练脚本，明确告知参与者使用合成文字、合成账号，不把模拟供应商结果写成真实回复。

## 试走前检查

| 核对项 | 可记录的证据 | 当前状态 |
| --- | --- | --- |
| 入口与版本 | URL、页面截图、服务端/前端 SHA、构建清单一致 | 本机脚本入口有证据；对外入口待 PM 提供 |
| 账号与隐私 | 测试账号归属、退出、换号、用途许可、脱敏截图、不收集真实烦恼原文 | 合成账号已覆盖；R02/R03 阻塞未关闭 |
| 数据与服务 | 正式数据库迁移／备份恢复、HTTPS、安全 Cookie、真实模型/检索状态 | 未验证，不标通过 |
| 操作支持 | 启动说明、失败恢复、联系人、停止试用与问题提交路径 | 本清单为模板；负责人和反馈渠道待 PM 确定 |
| 记录方式 | 每条问题附候选 SHA、环境、复现步骤、预期/实际、截图或脱敏日志、影响、责任人、状态 | 下表可直接复制；证据不含账号密码、Cookie、密钥和用户原文 |

## 建议任务与观察点

| 任务 | 操作提示 | 观察与记录 |
| --- | --- | --- |
| T1 进入与退出 | 打开首页，找到登录/访客入口；使用测试账号登录、退出 | 入口是否易懂；错误与失效会话提示；切换账号后前账号内容是否可见 |
| T2 陪伴与查询 | 用预置合成问题，逐项确认用途许可；观察等待、失败、取消、来源 | 是否理解外发范围、结果不确定性、失败恢复；区分真实供应商与替身 |
| T3 主动保存 | 保存一条合成内容，刷新后列表和详情回看 | 是否意识到需主动保存；保存未知时是否安全重试；列表与详情一致 |
| T4 清除与隔离 | 两步清除并尝试旧链接；切换测试账号查看历史 | 清除后的可见性、旧引用处理、错误文案；不得用他人真实账号 |
| T5 日历与训练 | 查看日历加载、空、失败状态；开始／暂停／退出五感训练 | “未知”和“没有记录”能否区分；训练离开后是否停止 |
| T6 桌宠（具备原生环境时） | 展开、收起、隐藏恢复、打开工作台、关闭 | 只在实际 Electron 环境记录，不用 HTML 渲染器结果代替原生结论 |

若阻塞问题尚未修复，T1/T2/T4 仅用于组内合成路径排练；对真实用户开放前由负责人重新评估可用范围。参与者反馈用匿名编号，不收集私密正文；需要引用界面时先脱敏，再取得使用许可。

## 单条问题登记格式

| 字段 | 填写内容 |
| --- | --- |
| 编号／日期／记录人 | `TRIAL-001`；实际日期；实际记录人 |
| 候选与环境 | 完整 SHA、入口 URL、设备/浏览器版本、真实服务或合成夹具 |
| 任务与步骤 | T1～T6；从干净状态开始的最短复现动作 |
| 预期／实际／影响 | 写可观察行为、发生次数、是否影响私密内容或主要任务；不用“感觉有问题”代替事实 |
| 证据 | 脱敏截图、日志或录屏链接；标明是否得到参与者许可 |
| 等级／责任／状态 | P0～P3、负责人、待分派／处理中／待复测／已关闭；关闭需写复测 SHA 和非作者结果 |

当前待登记为团队缺陷的项目见[最终测试报告](01_最终测试报告.md)；本模板没有伪造用户反馈、实际试用人数或满意度。
