# 李泉毅｜授权、注册幂等与生命周期整合结论

整合后端修订：

1. 携带已失效Cookie的同源写请求在CSRF校验前返回 `401 AUTH_REQUIRED`；匿名注册/登录仍需Origin与CSRF，有效会话错误CSRF仍返回403。
2. 注册接入仓储幂等：`requestId` 与规范化载荷由独立服务端HMAC绑定；同载荷重试返回原账号，不同载荷冲突。
3. 新增 `REGISTRATION_IDEMPOTENCY_KEY` 发布配置；必须是独立32字节Base64密钥，不得与资料加密密钥共用。
4. 账号/入口、用途许可、会话/活动代次共同限制任务读取、取消、保存与迟到结果。
