# 庄剀涵｜数据访问、用途许可与幂等整合结论

- 用途许可新增可信入口绑定；同账号另一入口不能使用或撤销该许可。
- 查询保存不再直接读取任务Map，必须重新验证账号、入口、任务完成态、来源、会话/活动代次及原查询许可。
- END、RESTART和取消会清除答案、来源、主张及查询状态，旧结果不能首次保存。
- 同一 `requestId` 在账号/入口内幂等，不同范围各自隔离；载荷变化冲突。
- 已保存快照可在任务失效后按原请求幂等重放，但清除或SAVE许可撤销后不能恢复。
