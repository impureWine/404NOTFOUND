# 郭昱祺｜异步状态、文案与恢复操作

统一候选的页面与浏览器复测采用以下规则：

| 场景 | 页面状态 | 用户文案 | 恢复操作 |
| --- | --- | --- | --- |
| 请求等待 | 禁用重复提交，保留“停止本次请求” | 正在等待，不承诺一定返回 | 可主动取消 |
| 主动取消 | 本地中止轮询，服务端任务保持 `cancelled` | 已停止等待；不会回填迟到结果 | 修改输入后重新发送 |
| 会话结束/重来 | 清空本轮消息、选择、历史引用和保存请求标识 | 已结束并清空 / 已重来 | 创建新会话或活动 |
| 换号 | 清空本机身份与私密界面，服务端使旧上下文失效 | 本机已退出，并核实服务器撤销状态 | 登录另一账号 |
| 登录失效 | 私密业务接口返回401后清空身份与CSRF | 登录状态已失效，本机私密界面已清理。请重新登录后继续。 | 打开登录对话框 |
| 超时/供应商失败 | 不产生成功消息或保存资格 | 分别显示超时、不可用或输出无效错误 | 保留输入并重试 |

浏览器实测确认：A发起任务后退出、B登录，A的迟到回复在B页面出现次数为0；B主动取消后迟到回复出现次数为0；服务端注销后访问私密页面返回401，页面转为访客并显示重新登录入口。
