## 设备与投影检查方法

| 检查项 | 操作方法 | 合格标准与记录 |
|---|---|---|
| 断网打开三份 PDF 和 PPTX | 断开网络，从离线包依次打开两份说明书 PDF、答辩 PDF 与 PPTX。 | 四份文件均能独立打开；登记设备、软件版本、文件哈希与检查时间。 |
| 中文字体、字号、图表、裁切、页码 | 查看封面、目录、跨页长表、类图、ER 图及末页。 | 字体和页码清晰，图表完整；问题记录页码并修订同版文件。 |
| 投影比例、分辨率、翻页 | 按现场投影设备的实际比例与分辨率逐页查看关键图。 | 图例与字段可辨认，翻页稳定；长图准备局部放大页。 |
| 演示音频、桌宠退出和窗口恢复 | 按正式演示顺序播放音频、退出桌宠并切回幻灯片。 | 音量可控，桌宠退出后桌面操作恢复；记录异常及处理。 |
| 备用设备打开同版文件 | 在备用设备读取第二份离线包。 | 文件清单和哈希与主机版本一致，PPTX/PDF 页序一致。 |
