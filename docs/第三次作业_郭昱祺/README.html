编辑与复用

  • drawio中的文字、节点与连线可分别编辑；SVG可在矢量编辑器修改，PNG仅供预览。
  • PowerPoint使用“视图→幻灯片母版”可见唯一简洁粉色母版和5个版式；用“新建幻灯片→版式”复用。页面内容区为可编辑占位符；插入PNG后图片本身不能编辑文字。
  • 若需在PPT逐字修改图，先编辑drawio，导出SVG插入后用PowerPoint支持的“转换为形状”；不要把整张PNG称为可编辑原图。
  • 源文件/保留生成脚本和构建说明。普通查看与修改drawio、SVG、CSV、PPTX无需运行脚本或安装Python。
