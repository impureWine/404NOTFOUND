# 功能模块与需求映射

| 模块 | 需求 | 功能 | 关键子功能 |
|---|---|---|---|
|账号与个人中心|REQ16|注册与登录|注册成功后去登录；登录／已登录改密；退出并撤销旧会话|
|账号与个人中心|REQ17|个人主页|私密资料与偏好；主动保存内容入口；本人／本入口权限|
|陪伴与沟通|REQ01|陪伴交流|倾听／澄清／梳理；限定正文并授权AI；临时回复／结束|
|陪伴与沟通|REQ09|情绪命名卡|词语／强度可跳过；选择后续任务；不自动保存或分析|
|陪伴与沟通|REQ11|平行宇宙排练室|场景／角色／目标；暂停／换说法／重来；认可表达→预览→保存|
|记录与整理|REQ08|情绪与事件日历|自愿记录日期与事件；按日回看／编辑；主动保存／确认清除|
|记录与整理|REQ10|烦恼物件化|线团／石头／便利贴；放旁边／找小步骤；外观与正文分别处理|
|记录与整理|REQ12|烦恼寄存所|选择未来再打开时间；到期后本人取出；选择延期／确认清除|
|压力缓解|REQ02|压力缓解小训练|呼吸／五感／暂停整理；任务拆分／步骤调整；开始／暂停／继续／退出|
|压力缓解|REQ13|屏幕无损发泄（敲击回弹）|网页画布内敲击；减弱动效／主动音效；停止与释放资源|
|压力缓解|REQ14|文字焚化与重力黑洞|独立私有正文缓冲；选择销毁／跳过动画；退出清空／不外发|
|压力缓解|REQ15|禅意编曲弹珠机|轨道／构件／材质；限定音阶／碰撞反馈；暂停／停止／音频释放|
|信息支持|REQ03|信息查询|限定问题并授权检索；逐条主张关联来源；时效／冲突／空结果说明|
|基础与多端|REQ04|模式切换|显示当前任务；选择携带内容并确认；旧任务失效／切换回执|
|基础与多端|REQ05|会话控制|临时会话／主动保存；本人记录／版本核实；结束／确认清除|
|基础与多端|REQ06|多入口及隔离|Web／桌宠／微信能力；可信入口与身份隔离；跳转不自动携带正文|
|基础与多端|REQ07|安全与隐私|最小数据／归属检查；AI／检索／保存分别授权；敏感场景边界与脱敏|

范围：六模块、17项需求各出现一次。漂流瓶、公开主页、找回密码、注销和自动跨入口同步不在当前范围。
