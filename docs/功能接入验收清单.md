# 全业务接入清单

| 需求 | 当前入口与实现 | 外部验收条件 |
|---|---|---|
| REQ01 陪伴交流 | Dialogue → TaskService → LangChainModelAdapter；无预设回复回退 | 有效智谱密钥及实网 |
| REQ02 小训练 | 随包训练定义 + 本地 TrainingController；四项练习完整交互，见《四类减压训练验收》 | 本机浏览器 |
| REQ03 信息查询 | Search → WikipediaSearchProvider；保存受控来源链 | Wikipedia 网络可达 |
| REQ04 模式切换 | React 路由隔离；服务端 switch 路由、代次和任务取消 | 浏览器交互 |
| REQ05 会话控制 | 暂停、继续、重来、结束；记录 SAVE 许可与两步清除 | PostgreSQL 持久化 |
| REQ06 多入口 | Web；Electron 工作台/浮层；微信签名/AES 回调和 H5 | Electron、公众号及域名配置 |
| REQ07 安全隐私 | Cookie/CSRF/Origin、加密、归属、入口、版本、上下文限制和危机提示 | 部署与安全复核 |
| REQ08 日历 | 真实新增、按月查询、按日查看、编辑和清除 | PostgreSQL |
| REQ09 命名卡 | 服务端校验和模式路由，不自动保存或发给模型 | 无额外外部账号 |
| REQ10 物件 | 形状、加密正文、编辑、回读与明确选择后整理 | PostgreSQL；整理另需模型 |
| REQ11 排练 | 场景/角色/目标/风格进入模型，选句整理和保存 | 模型与 PostgreSQL |
| REQ12 寄存 | 数据库时间决定可取出；主动取出/延期/清除 | PostgreSQL |
| REQ13 发泄 | Canvas 实际点击效果；Electron 透明全屏浮层 | 浏览器/桌面原生验收 |
| REQ14 文字销毁 | 私有组件本机动画，无 API/存储调用 | 浏览器隐私检查 |
| REQ15 弹珠 | 实际重力碰撞、轨道、材质和限定音阶 | 浏览器音频能力 |
| REQ16 账号 | 注册登录、资料读取、改密、退出及会话撤销 | PostgreSQL |
| REQ17 个人主页 | 资料编辑、预设头像、偏好、本人分类内容入口和数量 | PostgreSQL |

“代码已接入”不等于所有外部环境已通过验收。启动与配置见《真实服务接入与运行》。未配置外部服务时界面显示实际失败，不使用演示数据补位。
