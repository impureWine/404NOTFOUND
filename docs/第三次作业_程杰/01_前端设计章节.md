### REQ10：无正文物件的保存说明

以下为待郭昱祺、李泉毅签认的前端方案，追踪号为05号§10的R03。

| 用户操作／输入 | 拟定界面与载荷 | 触发和清理边界 |
|---|---|---|
| 只选形状，选择“先放旁边” | 本页临时外观；不要求名称或烦恼文字 | 不申请SAVE、不发HTTP、不调用AI；离开或换账号清临时物件 |
| 未填文字，主动选择保存 | 名称预填“想先放一放的事”，可编辑；空白名称在确认页恢复默认并展示；`payload={shape,title}`，完全省略`description` | 最终名称满足1～80码点；确认实际载荷后才申请SAVE；默认名称只作标签，本次保存不调用AI |
| 确认仅保存外观和名称 | 文案：“将保存形状和名称‘想先放一放的事’，不保存烦恼正文；本次不会调用AI。”名称被修改时同步替换引号内文字 | 文案与提交载荷一致；取消不提交；更改名称或范围使旧SAVE许可失效 |
| 已填写描述并选择保存描述 | 确认页另列“烦恼文字”，明确展示将保存的范围 | 不能沿用“不保存烦恼正文”的文案；修改载荷后重新确认和授权 |
| 保存超时／断网 | “保存结果待确认，请勿重复保存” | 保留当前身份内原requestId及同载荷核实；换身份清除；许可过期按R05保持待确认 |

名称只是物件标签。`WORRY_OBJECT` 的非空`title`约束由默认名称满足，不转化为必填烦恼正文。已保存物件的房间位置通过既有房间接口另行更新，不能把记录保存成功显示成房间更新也成功。郭昱祺确认默认名称、保存说明和空白名称处理，李泉毅确认现有DTO的`description`可省略；目前两项真实答复均未收到。

## 3. 分层职责

| 层次 | 主要职责 | 依赖约束 |
|---|---|---|
| 页面与公共 UI | 表单、来源卡片、加载／空／错误／权限视图、确认弹窗和键盘操作 | 调用功能控制器；不在视图事件中散落重试、数据库或音频释放逻辑 |
| 状态管理 | 身份、当前业务会话、任务、当前账号与入口的记录内存缓存、页面临时输入 | 不把所有功能正文汇入一个通用 Context；禁止自动读其他入口历史 |
| 接口适配 | 同源 `/api`、共享 Zod 校验、CSRF、状态映射、幂等与轮询 | 不接受客户端自报可信 `ownerId`／`entry`，不持有或读取 HttpOnly Cookie 原文 |
| 任务协调 | 捕获身份与双代次，登记取消句柄，过滤迟到结果 | 服务接受取消后不得再读取旧结果；本地 Abort 不等于服务停止 |
| 端侧互动 | 固定训练、敲击画布、弹珠物理、音频与动画 | 碰撞、音符和敲击不逐步上传；统一暂停与资源释放 |
| Electron 适配 | 受控 preload 白名单与窗口生命周期 | 主进程校验窗口和参数；渲染层无 Node、通用执行或文件读写能力 |
| 独立销毁入口 | 私有输入与 SHRED／BURN／BLACK_HOLE 效果 | 独立 React 根和本地资源，不装配业务状态、API 客户端、持久化或遥测 SDK |

组件依赖与数据隔离见02号文档，具体触发条件和清理动作见03号文档。

## 4. 状态与数据归属

| 状态 | 保存位置／寿命 | 失效或清理条件 |
|---|---|---|
| 当前身份与 CSRF | 内存；身份由安全 Cookie 与服务端会话确定 | 登录、退出、改密、401、换账号时失效旧请求、旧授权和缓存 |
| 业务会话与选中消息 | 内存；`sessionId`、`activityId`、双代次与当前消息 | END、过期、身份变化清空；服务重启后重新开始，不自动重发正文 |
| 异步任务 | 内存；`requestId`、代次快照、AbortController、轮询句柄 | 终态停轮询；暂停、重来、切换、撤销先失效结果接收资格 |
| 已保存记录的客户端缓存 | 当前身份、可信入口与资源范围内的内存 | 换身份／入口全清；清除成功后失效详情、列表、上下文选择和关联 |
| 普通页面草稿 | 当前功能的临时内存 | 保存失败可保留当前身份编辑；登录、退出、换账号或入口变化清空；游客输入不自动迁移，登录后由用户重新输入并主动提交 |
| 设备偏好 | 独立非正文配置，可本地保存 | 仅静音、音量、减少动态效果等；不混入私密记录、正文或账号令牌 |
| REQ14 原文与效果缓存 | 独立视图私有内存、DOM、粒子／纹理 | 完成、跳过、异常、切页、关闭均清空；不带账号、不恢复、不统计销毁内容或次数 |

持久化记录由应用服务写入 PostgreSQL。前端 API 缓存仅内存；Service Worker、CDN 和浏览器持久缓存不保存私密 API 正文。日历保存不代表分析许可；物件显示不代表正文留存许可；登录不代表跨端共享。

## 5. 异步、模式切换与身份边界

1. 初始化调用 `GET /api/auth/context` 与 `GET /api/capabilities`，写请求使用会话绑定的 CSRF token；不在 localStorage 存凭据。
2. 外部任务先展示范围并获取用途许可，再创建任务。受理返回202后轮询；每任务每客户端间隔至少1秒、最多一个在途请求，终态立即停止。
3. 发送前捕获 `identityEpoch`、可信入口、`sessionId`、`activityId`、`sessionGeneration`、`activityGeneration`、`requestId`。结果展示前全部匹配；`identityEpoch` 是本地字段，不添加到严格 HTTP DTO。
4. 暂停、重来、切任务、撤销、退出时先失效本地结果资格，停轮询及资源，再发既定取消或会话动作。网络失败保持屏蔽，不能宣称服务端或供应商已停止。`localStop`与`remoteAck`只属于页面控制状态，不添加到HTTP DTO或后端任务枚举。
5. 持久写超时显示“结果待确认”，以原 `requestId` 和相同载荷核实；不能换 ID 重复保存。外部任务失败后用户选择重试，才用新 `requestId` 并重新核验授权。
6. 模式切换先检查目标能力和用户选定的携带范围；失败后保持安全停止，不显示目标已运行，也不恢复旧请求。离开独立销毁页只清空，不提供正文携带。

R02（会话动作409）的前端处理：立即停用旧会话的结果接收与继续入口，丢弃旧许可及携带选择；409标准错误体不含可依赖的当前状态或双代次，不能从任务GET推算会话状态，也不新增GET会话端点。提示“会话状态已变化，旧任务已在本地停止。可重新开始；不会自动带入原内容。”用户选择重新开始后，以新requestId调用既有`POST /api/sessions`，不复制旧正文或上下文；创建失败仍保持停止。旧会话的远程结束只能据有效控制响应确认，未知时依靠服务端既定过期机制兜底。控制超时的原操作核实与409分支见03号§3.1和05号§10 R02，联合确认尚未完成。

退出或改密开始即锁住私密视图、递增身份代次并清缓存。退出204后才显示服务端撤销成功；断网退出保持锁定并提示尚未确认，恢复联网后再撤销，不自动读取私密正文。后退或页面缓存恢复时先验身份，遮蔽内容直到通过。跨标签页仅广播失效控制事件，不传正文。

取消请求网络失败时，前端将本地Abort、轮询停止和旧结果屏蔽保留在“本地安全停止，远程取消待确认”状态。它不会把本地Abort显示成任务已取消，也不会自动重发正文；重连仅在原身份、入口仍有效时，用既定任务GET或原控制操作的requestId及相同载荷核实，返回正文也不得重新展示或缓存。取消接口成功明确返回`cancelled`或任务GET返回`cancelled`才显示服务端已取消；404、过期、断网均不等于取消成功。账号切换清除旧账号缓存、任务登记及待核实操作，新账号不代旧账号查询或重放。

## 6. REQ14 独立数据通路

独立销毁页面只允许 `setBuffer(text)`、`destroy(effect)`、`clear()`、`dispose()`。正文最多4000 Unicode码点，仅存在本视图，不经过通用聊天状态、账号状态、记录缓存、浏览器持久存储、网络、AI、搜索、日志、错误上报、会话回放或遥测。

资源随包提供，不加载第三方脚本、字体或 CDN。页面部署可使用禁止网络连接的 CSP；需要的样式、图像等仅来自本地受控资源。效果异常只给固定错误文案，不序列化输入或含正文异常对象。

`clear()` 清空输入 DOM、私有 buffer、拆字节点、粒子文本、纹理与相关闭包引用；`dispose()` 进一步取消动画帧、监听与指针捕获。跳过动画与正常完成执行同一清理。关闭页不能依赖异步上传或退出回调才能完成清理，输入过程中也始终没有持久副本。边界限定于本产品控制的数据通路，不承诺操作系统或输入法绝对无痕。

## 7. 运行资源与性能验证方法

每个活动用 ResourceScope 登记 timer、requestAnimationFrame、监听、指针捕获、AudioNode／音源、物理对象和效果缓存。暂停停推进与在播声音；继续由用户触发；重置清旧运行状态；退出与窗口销毁执行幂等释放。静音必须立即停止现有声音，不能只禁止后续音符。具体状态表见03号文档。

| 对象 | 验证输入与过程 | 记录指标和停止证据 |
|---|---|---|
| 敲击 | 预置效果、有声／静音、连续点击，逐步增加粒子 | 帧间隔、CPU、内存与响应时间；退出后新效果为零，后台不残留输入捕获 |
| 弹珠 | 5／15／30构件与1／5／10球组合，暂停、静音、重置 | 帧间隔、物理稳定性、合法音高和声部数；暂停后无推进与新音符，退出后节点释放 |
| 文字销毁 | 空、普通、含emoji的4000码点合成文本；完成、跳过、异常、关闭 | 清理前后持有资源；网络、存储、日志和重开状态无专用合成标记 |
| 生命周期 | 多次开始／暂停／继续／切页，后台恢复及窗口退出 | 登记资源回到基线；无残留帧、定时器、监听、音频或输入捕获 |

初始待测上限：敲击100粒子、8音效声部；弹珠30构件、10球、8声部，同声部碰撞间隔至少50ms。它们是09号设计参数，不是已达到的性能。可执行测量步骤、环境记录字段及待验证的数值降级门槛统一放在04号§4.1～§4.3；降低球数、粒子或效果质量不能削弱清理和隐私语义。Electron与性能验证均未执行，属于后续工程计划。
