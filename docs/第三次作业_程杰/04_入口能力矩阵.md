状态：设计方案，实际接入及原生能力验证未执行。表中“支持”表示设计目标，不能据此标记当前功能已可用。

## 1. 能力标记与可信入口

HTTP能力接口为 `GET /api/capabilities`，返回 `{entry,features:[{reqId,status,reason?,fallback?}]}`。实际 `status` 仅为 `AVAILABLE/SIMULATED/UNAVAILABLE`：分别表示已验证可用、模拟、不可用。“跳转／降级”是界面处理方式，不新增服务枚举。

入口由受控接入适配与会话绑定确定。客户端不能用 `entry` 参数、`X-Entry`、User-Agent或Origin自报可信平台。当前优先开放WEB；DESKTOP、WECHAT在身份与入口绑定完成前保持模拟或不可用。前端隐藏按钮不能替代服务端权限检查。

## 2. 业务能力矩阵

| 需求／功能 | Web设计目标 | Electron桌宠设计目标 | 微信设计边界 | 不支持时的跳转／降级 |
|---|---|---|---|---|
| REQ16～17 账号与个人中心 | 支持完整页面、本人资料及私密内容入口 | 原生窗口与可信DESKTOP认证完成后接入 | 取决于接入形式与授权；聊天中不收密码，不按昵称绑定 | 跳转受控Web登录／个人中心，明确进入WEB范围 |
| REQ01 陪伴交流 | 支持倾听／梳理、临时对话及主动保存 | 支持目标为快捷面板或完整页 | 可按实际权限适配文字；未接入标模拟 | 展示能力说明或打开完整Web页，不自动携带聊天正文 |
| REQ09 情绪命名卡 | 支持选词及LISTEN／ORGANIZE／SEARCH分流 | 简化选词面板或完整页 | 有实际适配时提供文本选择，否则跳转 | 未选need不路由；选词不自动保存 |
| REQ11 平行宇宙排练 | 支持设置、暂停／继续／重来、选择表达与预览 | 快捷唤起完整排练页 | 文本适配或跳转，不能省略模拟与暂停边界 | 无法实现状态控制时打开完整页，不伪称聊天适配完整 |
| REQ08 情绪与事件日历 | 支持同日多条、详情、编辑和清除 | 面板或完整页；数据仍在DESKTOP范围 | 简化查看／跳转须按实际身份支持 | 当前入口无数据时说明入口隔离，不自动读WEB记录 |
| REQ10 物件与房间 | 支持临时形状、房间画布与主动保存 | 目标为桌宠房间与物件显示 | 不承诺原生图形房间，可提供跳转 | Web画布；缺渲染时可用外观选择列表，放旁边仍零AI |
| REQ12 烦恼寄存所 | 支持寄存、状态、主动取出／延期／清除 | 包裹外观与面板入口，不自动展开正文 | 以实际适配提供文字状态或跳转 | 到期仅显示可取出；无权限不提供正文 |
| REQ02 固定小训练 | 支持本地引导、暂停、继续、重置、退出 | 轻量面板；收起／隐藏自动暂停 | 可适配固定文本步骤，不能宣称等同画布互动 | 静态引导／Web页；音频失败可静音，退出始终可用 |
| REQ03 信息查询 | 支持检索状态、摘要与来源、主动保存 | 快捷查询或完整结果页 | 可按权限展示带来源文本或跳转 | 来源过期／冲突如实提示；服务失败不显示无结果 |
| REQ13 屏幕无损发泄 | 支持本产品画布内效果；不支持覆盖其他应用 | C03验证后才允许原生桌面浮层 | 不支持聊天窗口内全桌面互动 | 降级为Web画布或说明页，明确区域限制 |
| REQ14 文字销毁 | 独立本地页面，正文不保存、不上传 | 独立端侧视图，不挂通用聊天／遥测 | 聊天中不接收待销毁正文；仅提供无正文入口 | 跳转独立本地打包页面；环境不能保证隔离时不可用 |
| REQ15 编曲弹珠机 | 支持本地物理画布与用户手势启用音频 | 打开完整画布或受控面板 | 不承诺原生聊天物理与音乐，可跳转 | 简化效果／静音并说明；无法稳定运行则停止并允许退出 |
| REQ04～05 模式、保存与清除 | 支持显式切换、用途许可、版本化保存及确认清除 | 同样执行控制与隔离 | 仅在实际接入控制流程后开放 | 状态未确认保持停止；无批量清除接口，不展示一键全清已接通 |
| REQ06～07 隔离与安全 | WEB范围；身份、用途、归属校验 | DESKTOP范围，必须有可信接入 | WECHAT范围，适配前不可自报启用 | 跨入口跳转仅带白名单页面键；不自动共享记录或正文 |

同账号不代表共享不同入口的业务会话或记录。桌宠跳Web须说明目标为WEB范围；默认不带正文、凭据、私密记录ID或未经选择的上下文。销毁链接始终不带正文。

### 性能与桌面能力的发布门槛

Electron 和性能矩阵均处于未执行状态。开放前每项至少完成三次同环境运行，并填写：操作系统版本、Electron／浏览器版本、CPU、内存、显卡、供电模式、分辨率、DPI、窗口参数、场景参数、帧间隔分布、CPU／内存峰值、实际结果与复核人。缺少任一字段时，该能力保持 `SIMULATED` 或 `UNAVAILABLE`。

| 触发门槛 | 降级处理 |
|---|---|
| E01～E09 任一前置窗口验证失败或无可复核记录 | 不开放对应原生能力，回退Web画布、普通窗口或入口说明 |
| 球、粒子或声部达到初始上限后出现资源持续增长、退出后仍有帧／音频／捕获 | 限制新增并降低数量；资源不能回到基线时禁用互动入口，待修复复测 |
| 缩放、多屏、穿透或崩溃恢复无法保证退出入口可达 | 禁用相关窗口选项，保留普通窗口和Web路径 |
| 音频不可用或设备拒绝播放 | 切为无声可视反馈；不阻止暂停、重置或退出 |
| 尚未定义可接受帧间隔阈值 | 不把“流畅”写成通过；先记录分布，由样机结果设定并写入后续验证基线 |

## 5. 运行限制与异常处理

| 条件 | 产品行为 | 清理与恢复 |
|---|---|---|
| 页面隐藏／面板收起 | 本地互动暂停，网络排练先屏蔽旧结果并请求PAUSE | 停计时、物理、音源；返回由用户继续 |
| 网络不可用 | 本地训练／销毁可在已加载资源内运行，网络操作显示实际失败／待确认 | 停网络轮询；不把旧账号缓存当离线记录；重连不自动重发正文 |
| 退出／切任务 | 本地先停止，必要时发送既定动作／取消 | 释放帧、监听、捕获、音频和运行实例；REQ14立即清私有内容 |
| 渲染或音频故障 | 降低效果或静音，始终提供退出 | 故障不阻止销毁清空；浮层由主进程兜底移除 |
| 球／粒子过多或帧间隔异常 | 限制新增、降低数量或简化效果 | 不以拥塞为由阻塞退出；性能阈值须实测后确定 |

详细触发与时序见[03号文档](03_关键状态与时序图.md)。C03窗口能力、互动性能、可信入口与功能联调分别验收，不以一种演示替代其他结论。
