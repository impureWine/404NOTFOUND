# 前端接口使用清单

版本 v1.0　唯一详细业务依据为09号全功能接口与限制规范

## 1 全局调用约定

本清单列出32个唯一的HTTP方法与路径。日历筛选复用GET /api/records，是额外使用场景而不是新增端点；原接口目录将该过滤示例另列，故显示33项。接口尚待实现和联调，本包不构成调用通过证据。

前端同源访问 /api，JSON最大128 KiB。前后端复用严格Zod输入输出Schema，拒绝未知字段，业务归属仍由服务核查。所有写操作校验会话CSRF与Origin；CSRF请求头名称待共享契约冻结。不得提交可信ownerId或entry，不读取原始HttpOnly Cookie。

成功为 {data,meta:{requestId}}，204无正文；错误为 {error:{code,message,fields?,retryAfterSeconds?},meta:{requestId}}。私密及临时任务响应no-store，前端缓存只在内存，API不进入Service Worker离线缓存。仅观测脱敏ID、状态和耗时，不记录正文、密码或Cookie。

表内“有效匿名上下文”也需要通过auth/context建立，不能理解成无任何会话限制。创建、保存和业务动作按接口显式携带requestId；登录、退出和改密不擅自添加09号未定义字段。

## 2 字段与输入限制

| 字段 | 采用规则 | 前端行为 |
|---|---|---|
| loginName | NFKC后3～64 ASCII字母、数字或下划线；统一小写索引 | 昵称不能代替登录名；与共享Schema一致 |
| 新密码 | 12～128 Unicode码点，不trim或规范化 | 注册和改密执行；登录只校验非空与上限 |
| nickname、bio、title | 1～32、0～200、1～80码点 | 可trim，纯文本；预置头像key |
| 正文与selectedText | 每字段最多4000码点 | 用Array.from(text).length计数，避免把UTF16长度当码点数 |
| 上下文 | 最多20个不重复消息ID；展开总文本最多12000码点 | 包含场景和物件等展开正文，不自动裁掉认可表达 |
| emotionWords、intensity | 1～5个不重复词，每词1～20码点；强度整数1～5 | 是用户记录标尺，不当成健康评分 |
| date、instant | 真实YYYY-MM-DD；带偏移ISO8601时刻 | 日历按用户本地日期，instant存储交服务；使用允许的IANA时区 |
| 分页和版本 | limit默认20最大50；opaque cursor；expectedVersion正整数 | 不跨过滤范围复用游标；房间创建版本0为明确例外 |

## 3 接口目录


### 认证与个人中心


#### A01 应用初始化与身份变化

`GET /api/auth/context`

鉴权：登录或有效匿名上下文。输入：无body。

响应：200 authenticated、csrfToken、expiresAt可选。前端处理：创建或读取上下文，no-store；不返回Cookie原始凭据。


#### A02 P-A02 注册

`POST /api/auth/register`

鉴权：登录或有效匿名上下文。输入：requestId、loginName、password、confirmPassword。

响应：201 accountId。前端处理：注册成功进入登录，不自动登录；用户名冲突409。


#### A03 P-A01 登录

`POST /api/auth/login`

鉴权：登录或有效匿名上下文。输入：loginName、password、target固定页面键。

响应：200 profile、target、expiresAt；Set-Cookie。前端处理：成功后轮换上下文并重取CSRF；清旧匿名任务；用户选定草稿另行确认保存。


#### A04 退出与账号切换

`POST /api/auth/logout`

鉴权：当前会话上下文。输入：无body，必须CSRF。

响应：204无正文。前端处理：先隐藏私密视图；服务撤销成功后确认退出；断网显示撤销未确认。


#### A05 P-A03 改密

`POST /api/auth/change-password`

鉴权：有效登录。输入：currentPassword、newPassword、confirmPassword。

响应：204无正文。前端处理：验证旧密码；成功后所有旧登录会话失效并重新登录。


#### A06 P-U01 我的

`GET /api/profile`

鉴权：有效登录。输入：无body。

响应：200 nickname、avatarKey、bio、version。前端处理：仅本人资料；加载失败不显示默认资料冒充成功。


#### A07 P-U02 资料编辑

`PATCH /api/profile`

鉴权：有效登录。输入：requestId、expectedVersion、nickname、avatarKey、bio。

响应：200 新资料和version。前端处理：头像仅预置key；取消不提交，409重新核对后再编辑。


#### A08 P-U01 内容入口

`GET /api/profile/summary`

鉴权：有效登录。输入：无body。

响应：200 counts，六种RecordKind。前端处理：只显示本人当前入口计数，不含正文、情绪分数或销毁次数；503不假全零。


#### A09 P-U03 偏好

`GET /api/preferences`

鉴权：有效登录。输入：无body。

响应：200 offerHistorySave、version。前端处理：仅是否提示保存的账号偏好，不是保存授权。


#### A10 P-U03 偏好

`PATCH /api/preferences`

鉴权：有效登录。输入：requestId、expectedVersion、offerHistorySave。

响应：200 新偏好。前端处理：不隐式启用保存、分析或跨端共享；设备声音偏好独立。


### 会话与用途授权


#### S01 陪伴、排练、查询

`POST /api/sessions`

鉴权：登录或有效匿名上下文。输入：requestId、mode。

响应：201 sessionId、activityId、sessionGeneration=0、activityGeneration=0、mode、state=ready。前端处理：mode限定LISTEN、ORGANIZE、REHEARSE、SEARCH；ID由服务分配。


#### S02 P-M01 切模式

`POST /api/sessions/:id/switch`

鉴权：登录或有效匿名上下文。输入：requestId、targetMode、expectedSessionGeneration、selectedContextIds。

响应：200 新activityId及双代次。前端处理：先校验目标能力，按用户选择复制；复制不等于AI或搜索许可。


#### S03 暂停、继续、重来和结束

`POST /api/sessions/:id/actions`

鉴权：登录或有效匿名上下文。输入：requestId、action、expectedSessionGeneration、expectedActivityGeneration。

响应：200 当前state和双代次。前端处理：action为PAUSE、RESUME、RESTART、FINISH_REHEARSAL、END；本地训练不逐步调用。


#### S04 外发或保存确认

`POST /api/consents`

鉴权：登录或有效匿名上下文。输入：requestId、purpose、operation、payload；按用途含sessionId、activityId和双代次。

响应：201 consentId、purpose、expiresAt。前端处理：purpose为AI_PROCESS、SEARCH_PROCESS、SAVE；绑定同载荷、身份、入口及版本，初始5分钟。SAVE要求登录。


#### S05 撤销许可

`POST /api/consents/:id/revoke`

鉴权：登录或有效匿名上下文。输入：requestId。

响应：200 revoked。前端处理：取消相关在途任务；不隐式清除已保存记录。


### AI与检索任务


#### T01 陪伴、物件梳理、排练

`POST /api/agent/tasks`

鉴权：登录或有效匿名上下文。输入：requestId、sessionId、activityId、双代次、mode、operation、selectedText、selectedContextIds、consentId；按操作补资源或simulation。

响应：202 requestId、status=pending、会话与双代次。前端处理：仅LISTEN、ORGANIZE、REHEARSE；operation及附加字段详见下方。


#### T02 任务轮询

`GET /api/agent/tasks/:requestId`

鉴权：登录或有效匿名上下文。输入：无body。

响应：200 status；completed含result及服务端消息ID。前端处理：每任务至少1秒且最多1个在途轮询；终态即停；迟到、失效代次或身份不符不显示。


#### T03 取消AI任务

`POST /api/agent/tasks/:requestId/cancel`

鉴权：登录或有效匿名上下文。输入：requestId为本次取消操作ID。

响应：200 目标status=cancelled。前端处理：路径ID是目标任务，body是新取消操作ID；不混用。取消后服务不再返回正文。


#### T04 P-S01 查询

`POST /api/search/tasks`

鉴权：登录或有效匿名上下文。输入：requestId、sessionId、activityId、双代次、question、selectedContextIds、consentId；模型整理另需aiConsentId。

响应：202 任务状态与关联标识。前端处理：使用SEARCH业务会话和SEARCH_PROCESS；不把SEARCH塞入agent三种mode。


#### T05 检索轮询与结果

`GET /api/search/tasks/:requestId`

鉴权：登录或有效匿名上下文。输入：无body。

响应：200 status；completed含searchState、claims、sources、hasConflict、partial。前端处理：EMPTY是无资料；failed是执行失败；来源不明、过期、冲突明确呈现。


#### T06 取消检索

`POST /api/search/tasks/:requestId/cancel`

鉴权：登录或有效匿名上下文。输入：requestId为本次取消操作ID。

响应：200 目标status=cancelled。前端处理：与AI相同的取消和迟到保护；取消不应被外部任务创建额度阻断。


### 记录与房间


#### R01 主动保存六类记录

`POST /api/records`

鉴权：有效登录。输入：requestId、kind、payload、consentId。

响应：201 Record。前端处理：有效登录和SAVE；同操作同requestId同载荷幂等。


#### R02 历史、日历、物件、寄存等列表

`GET /api/records`

鉴权：有效登录。输入：query含kind、cursor、limit及类别过滤。

响应：200 items、nextCursor。前端处理：列表不返回全文；日历可用from/to，跨度最多366天，同日可多条；不把正文放URL。


#### R03 记录详情

`GET /api/records/:id`

鉴权：有效登录。输入：无body。

响应：200 Record。前端处理：本人当前入口；寄存未主动取出前详情不含body；404不区分不存在和越权。


#### R04 可编辑记录

`PATCH /api/records/:id`

鉴权：有效登录。输入：requestId、expectedVersion、payload、consentId。

响应：200 新Record。前端处理：不能改kind、owner或entry；CONVERSATION、QUERY只读，DEPOSIT首版拒绝PATCH。


#### R05 清除前确认

`POST /api/records/:id/clear-confirmations`

鉴权：有效登录。输入：requestId、expectedVersion。

响应：201 confirmationId、expiresAt、recordId、version、kind。前端处理：初始2分钟有效；只发确认不清除，界面展示对象和范围。


#### R06 确认清除

`POST /api/records/:id/clear`

鉴权：有效登录。输入：requestId、expectedVersion、confirmationId、confirmed=true。

响应：200 cleared、recordId。前端处理：取消不发请求；成功使缓存、关联和上下文选择失效。


#### R07 P-O02 房间

`GET /api/room`

鉴权：有效登录。输入：无body。

响应：200 id、version、objects数组。前端处理：无房间返回id=null、version=0及空objects；失败不能假空；游客只用临时房间。


#### R08 保存房间布局

`PUT /api/room`

鉴权：有效登录。输入：requestId、expectedVersion、objects[{recordId,shape,x,y}]。

响应：200 新房间与版本。前端处理：最多30件，ID不重复且为本入口已保存物件；x/y为0～1；创建版本0；移出仅取消关联。


### 寄存与入口能力


#### D01 P-L02 主动取出

`POST /api/deposits/:id/retrieve`

鉴权：有效登录。输入：requestId、expectedVersion。

响应：200 id、state=RETRIEVED、version、body。前端处理：仅到期后主动操作；未到期409，不因到期自动请求取出。


#### D02 P-L02 延期

`POST /api/deposits/:id/postpone`

鉴权：有效登录。输入：requestId、expectedVersion、reopenAt。

响应：200 id、state=STORED、version、reopenAt。前端处理：新时间为未来时刻，冲突不覆盖；寄存正文首版不开放直接编辑。


#### D03 应用与入口初始化

`GET /api/capabilities`

鉴权：登录或有效匿名上下文。输入：无body，不接受自报entry授权。

响应：200 entry、features[{reqId,status,reason?,fallback?}]。前端处理：状态AVAILABLE、SIMULATED、UNAVAILABLE；实际入口由可信接入和会话绑定决定。


## 4 操作附加字段和记录载荷

Agent 的 operation 为 REPLY、OBJECT_ORGANIZE、REHEARSAL_REPLY、REHEARSAL_SUMMARIZE。普通REPLY仅LISTEN或ORGANIZE；OBJECT_ORGANIZE仅ORGANIZE，已保存来源加resourceId/resourceVersion，临时来源用objectDraft，二者互斥。REHEARSE必须给simulation中的scene、counterpart、goal、style；整理额外给本轮本人recognizedMessageIds，1～20个。

| kind | 创建或可编辑payload | 展示与编辑边界 |
|---|---|---|
| CONVERSATION | title、sessionId、selectedMessageIds | 当前活动1～20条消息，展开总正文不超过12000码点；保存快照只读 |
| EMOTION | date、emotionWords、intensity、event、timeZone | event可空，同日多条；列表可含情绪和强度，不含event正文 |
| WORRY_OBJECT | shape、title、description可选 | shape为TANGLE、STONE、NOTE；外观保存省略description |
| REHEARSAL_DRAFT | scene、sessionId、activityId、recognizedMessageIds、expressions | expressions为1～20条非空文本，总计最多12000码点；仅认可表达 |
| DEPOSIT | title、body、reopenAt | body非空，未来时刻；列表无正文；首版不支持通用PATCH |
| QUERY | searchRequestId | 只引用本入口已完成且有来源的SUCCESS查询；服务端复制证据，客户端不提交自造claims |

Record返回id、kind、title、payload、createdAt、updatedAt、version。QUERY持久状态按CONFLICTED、PARTIAL_SUCCESS、STALE_SOURCE、SUCCESS的优先级确定，不把临时SearchState=SUCCESS/EMPTY直接用于持久状态。取出后的DEPOSIT保持RETRIEVED，不随时钟自动变回AVAILABLE。

## 5 前端错误处理

| HTTP与业务码 | 页面动作 | 禁止行为 |
|---|---|---|
| 400或413 INVALID_INPUT | 定位字段、修改后重试；不回显敏感载荷 | 用过时长度限制或继续调用模型 |
| 401 AUTH_REQUIRED | 停私密请求、遮蔽正文、清旧缓存并引导登录 | 把正文放returnTo或继续展示前一账号 |
| 403 ACCESS_DENIED | 显示用途或权限提示；必要时重取上下文 | 无条件重新授权或循环重试 |
| 404 NOT_FOUND | 显示内容不可用，移除无效选择引用 | 区分他人对象确实存在 |
| 409 CONFLICT或INVALID_STATE | 核对实际版本或活动；重新读取、由用户决定 | 自动覆盖新版本、复活旧请求或提前显示成功 |
| 429 RATE_LIMITED | 按Retry-After和安全提示显示可重试时间 | 无限轮询或自动重复外部任务创建 |
| 503 SERVICE_UNAVAILABLE | 保留允许保留的编辑态，显示服务暂不可用 | 显示为空历史、空检索或全零统计 |

接口目录摘要中的422在09号没有定义，本包不新增该错误；后端若需采用，先更新唯一契约并同步共享Schema。任务取消和超时读取正常任务状态；failureReason只允许TIMEOUT、PROVIDER_UNAVAILABLE、OUTPUT_INVALID等已定义值，不展示供应商原始异常。

普通API初始总时限5秒，外部任务含排队总时限30秒。前端超时不等于服务未提交，持久写入用相同requestId核实；外部任务失败的人工重试使用新requestId并重新校验许可和额度。默认不叠加SDK自动重试。

## 6 非HTTP端侧契约

| 对象 | 接口 | 返回或边界 |
|---|---|---|
| TrainingController | start、pause、resume、stop、reset | state、stepIndex、elapsedMs；静态training-definitions内容，不逐步联网 |
| NamingCard | select({emotionWords,need}) | targetMode、emotionWords、requiresQuestion；need未选不路由 |
| ModeController | switchTo(target,{selectedContextIds}) | 校验能力、用户选择和停止旧活动；切离销毁直接清空 |
| ImpactController | start、hit、pause、resume、reset、stop | effect预置，strength/volume为0～1，坐标在画布；无敲击HTTP接口 |
| TextDestructionView | setBuffer、destroy、clear、dispose | 最多4000码点，SHRED/BURN/BLACK_HOLE；无HTTP、账号、仓储、模型或遥测依赖 |
| MarbleController | configure、release、pause、resume、reset、stop、setMuted | 30构件、10球、8声部和50ms初始待测限制；布局仅临时 |
| petWindow | move、setAlwaysOnTop、setClickThrough、close、getCapabilities | preload白名单，主进程验来源与参数；不暴露通用invoke或文件能力 |

## 7 接口冻结检查

前后端共同复核输入输出Schema、CSRF头名、错误映射、任务取消、409状态核对、寄存版本变化与列表裁剪。共享Schema应在浏览器和服务端实际import后再记录通过；本包只提供契约使用清单，不替代C01实现、C02登录会话实现或C03原生能力实测。
