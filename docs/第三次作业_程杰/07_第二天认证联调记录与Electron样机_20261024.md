## 1. 交付边界

本次交付包含两项：

1. React/Vite 首页的认证接口接线：读取认证上下文、登录、注册、读取个人资料、退出；退出先清理本机私密界面，再区分服务器已确认和状态待确认。
2. Electron 最小窗口样机：本地透明无边框窗口、置顶、标题栏拖动、隐藏、显式退出和点击穿透；使用受限 preload，不加载远程页面。

这不是生产认证系统，也不代表后端接口已经完成。当前仓库检出树没有 `backend/` 或可启动认证服务，CSRF 头名也仍由 `VITE_CSRF_HEADER_NAME` 配置，尚未取得后端冻结值。因此真实注册、登录、资料读取和退出请求没有被写成“联调通过”。

### 2.1 对照接口契约

前端使用接口表中的同名同义字段和路径：

| 方法 | 请求 | 前端处理 |
|---|---|---|
| `GET /api/auth/context` | 无 body | 读取 `authenticated` 与 `csrfToken`；不读取原始 Cookie |
| `POST /api/auth/register` | `requestId, loginName, password, confirmPassword` | 201 后转到登录状态；不自动登录 |
| `POST /api/auth/login` | `loginName, password, target` | 发送 `credentials: include`；响应后重新读取 context/profile |
| `GET /api/profile` | 无 body | 只有 context 已认证时显示昵称和简介；失败不显示伪造资料 |
| `POST /api/auth/logout` | 无 body | 本地先清理；只有 204 或重新读取 context 确认匿名后才显示服务器退出已确认 |

所有写请求沿用适配器的 CSRF 头配置，不在前端自行命名；请求使用 `no-store` 和 `credentials: include`。密码只存在受控表单和本次请求内存，不进入浏览器持久化存储。

### 2.2 状态与异常记录

| 状态 | 进入条件 | 页面行为与清理 |
|---|---|---|
| `checking` | 真实模式首屏读取 context | 隐藏私密资料；请求结束或组件卸载时 abort |
| `anonymous` | context 返回未认证，或本地身份已清理 | 只显示访客入口，不展示个人资料和历史 |
| `authenticated` | context 认证且 profile 读取成功 | 显示服务端返回的昵称／简介；不显示本地示例记录 |
| `unavailable` | 网络错误、API 未连接或 CSRF 配置缺失 | 保持访客视图；不把失败显示成登录成功 |
| `logout local` | 用户点击退出 | 立即清 profile、CSRF 内存值、弹窗和私密首页区域 |
| `logout pending` | 退出后的 context／logout 请求网络失败 | 保持本地安全停止；显示远程状态待确认，可由用户主动重新核实；不标记 `cancelled` 或“服务器已退出” |

账号切换不会迁移游客输入，也不会把旧账号资料放入新账号页面。当前页面没有把记录、AI 或搜索接口伪装成已联调。

## 4. Electron 样机

目录：`prototype/electron/`

| 文件 | 作用 |
|---|---|
| `main.cjs` | 创建透明无边框置顶窗口；拒绝导航、窗口打开和权限请求；处理隐藏、退出、点击穿透和渲染崩溃清理 |
| `preload.cjs` | 仅暴露 `setClickThrough`、`hide`、`close` 和状态监听四项白名单能力 |
| `renderer.html/css/js` | 本地桌宠样机界面和窗口控制 |
| `README.md` | 启动方式、能力边界和未验证说明 |

安全配置：`contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`；renderer CSP 禁止网络连接；preload 不暴露 `require`、文件系统或任意 IPC 通道。点击穿透开启后由主进程控制，`Alt+Shift+P` 恢复交互。
