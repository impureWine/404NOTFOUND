## 全局约束

- JSON + UTF-8；请求/响应由共享 Zod 严格 Schema 校验，拒绝未知字段。
- 服务端从安全 Cookie/可信入口解析身份，客户端不得提交可信 `ownerId` 或 `entry`。
- 写请求校验 CSRF 与 Origin；需 `requestId` 的操作按身份、入口和操作范围幂等。
- 异步任务绑定 `sessionGeneration` 与 `activityGeneration`；取消或代次失配后丢弃迟到结果。
- 典型错误：400、401、403、404（含安全隐藏越权）、409、413、422、429、503。
