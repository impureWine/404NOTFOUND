## 1. 总体交付要求

完成 **7天Alpha冲刺、11篇博客、答辩PPT、腾讯共享文档评审表，以及课堂项目演示和答辩**。

11篇博客构成：1篇置顶集合＋1篇代码规范与冲刺计划＋7篇每日冲刺日志＋1篇测试随笔＋1篇冲刺总结。

| 任务 | 数量 | 必须包含的内容 | 博客评分占比 |
|---|---:|---|---:|
| 置顶集合随笔 | 1篇 | 单独发布并置顶，集中整理本次作业所有博客链接，方便老师、助教查看和统计 | 未单列 |
| 代码规范、冲刺任务与计划 | 1篇 | 团队代码规范、本次冲刺任务和计划；引入AI技术员，说明如何让AI参与设计、编程、测试等工作 | 18% |
| 每日冲刺随笔 | 7篇 | 每天举行站立式会议、发布当天日志，提供照片、燃尽图、运行效果、成员进展及工作证据 | 30% |
| 测试随笔 | 1篇 | 测试安排、工具选择与运用、测试用例文档、测试体会、项目测试评述 | 10% |
| 冲刺总结随笔 | 1篇 | 计划与实际进展、成员收获、分工协作、工作量比例、下阶段展望、答辩PPT、AI贡献回顾 | 42% |
| 课堂演示与答辩 | 一项 | 展示Alpha阶段的过程和成果，制作答辩PPT，自行设计腾讯共享文档形式的评审表 | 单独计算答辩分 |

## 2. 冲刺前：代码规范、任务与计划

**必须在冲刺开始前提交一篇随笔**，内容包括：

1. 团队代码规范。原帖要求参考阿里巴巴Java开发手册终极版v1.3.0、华为内部代码规范等进行设计。
2. 本次冲刺任务。
3. 本次冲刺计划。
4. 引入AI技术员，例如AI设计师、AI程序员、AI测试员，并说明如何驱使AI帮助团队完成任务。

本项占博客评分 **18%**，覆盖课程目标7。
