## 1. 项目范围与功能模块

404NOTFOUND面向日常表达、烦恼整理、短时互动减压和带来源的信息查询。桌宠提供轻量陪伴入口，Web承载完整页面，微信为后续适配入口。现有HTML和React页面属于原型，不能作为真实认证、模型或数据库运行证据。

| 模块 | 需求与子功能 |
|---|---|
| 账号与个人中心 | REQ16注册/登录/已登录改密/退出；REQ17资料/私密内容入口/偏好设置 |
| 陪伴与沟通 | REQ01倾听与梳理；REQ09命名卡选择需要；REQ11场景排练/暂停重来/认可表达 |
| 记录与整理 | REQ08日期记录和回看；REQ10物件及选择梳理；REQ12寄存/主动取出/延期 |
| 压力缓解 | REQ02固定小训练；REQ13敲击回弹；REQ14独立文字销毁；REQ15物理弹珠与音乐 |
| 信息支持 | REQ03明确问题/检索/摘要/来源核查 |
| 基础与多端 | REQ04模式切换；REQ05主动保存及记录控制；REQ06入口能力和隔离；REQ07安全隐私 |

不重新加入密码找回/重置、账号注销、漂流瓶、公开主页和自动跨端同步。保存、分析及向模型外发分别取得相应用户选择；文字销毁正文不保存、不上传、不进入模型/搜索/遥测。完整对应见[需求追踪表](01_需求设计追踪表.md)。本文相对链接对应当前仓库目录；组号、华为云及三份正式PDF补齐并核验后发布。

## 2. 总体架构与设计类

本轮按张王昊明确要求，使用JavaScript，使用LangChain JS管理模型，Agent接在应用层API。

`客户端/入口适配 → 应用API → Agent应用服务 → AI处理/任务编排 → LangChain模型适配器 → 模型供应商`

记录和身份走独立业务链：`应用API → AuthService / ProfileService / RecordService → Repository → 存储`。前端不持有模型密钥；Agent没有直接写库、清除记录或改密能力。固定训练、文字销毁、敲击与弹珠的运行由端侧状态机承担。LangChain提供统一模型调用与供应商适配；授权和保存规则仍由业务服务执行。[LangChain JS模型文档](https://docs.langchain.com/oss/javascript/langchain/models)

| 层次 | 主要职责/设计类 |
|---|---|
| 页面与设备适配 | 页面状态、DesktopPet、ImpactRun、TextDestructionView、MarbleRun、资源释放 |
| 应用API与服务 | 可信AccessContext；AuthService、ProfileService、RecordService、RoomService；AgentApplicationService门面 |
| 业务编排 | BusinessSession、CompanionSession、RehearsalSession、TaskCoordinator、PendingRequest、AIProcessingService |
| 外部能力适配 | AIClient的LangChainModelAdapter实现；SearchProvider与来源校验 |
| 数据存取 | IdentityRepository、RecordRepository、RoomRepository；归属和版本条件约束 |

当前结构以[完整设计类图v1.2](../第三次作业_李泉毅/02_完整设计类图_V1.2.md)为依据：账号拥有资料/凭据/登录会话；业务会话组织临时活动；保存记录是独立快照；物件外观移除不等于正文清除；服务依赖仓储和授权策略。现有专业稿已描述Agent门面、LangChain模型适配器和PostgresRecordRepository；类—表映射见数据库专业稿，不能将每个技术类映射为数据库表。

当前确定采用Web首发、React/Vite、Node.js/Express模块化单体、服务端PostgreSQL和pg、Zod共享契约；桌宠采用Electron先验证。登录会话由AuthService管理并存PostgreSQL，AI业务任务仍临时内存。部署采用同源Web/API和私网数据库，单实例先行；选型已采纳，依赖版本、模型厂商/预算和云资源配置由负责人登记，未宣称已部署。理由见[技术决策台账](03_技术决策与Agent接入基线.md)。

现有专业交付入口：李泉毅已交[架构图源](../第三次作业_李泉毅/01_系统架构图.mmd)、[完整类图v1.2](../第三次作业_李泉毅/02_完整设计类图_V1.2.md)、[增量说明](../第三次作业_李泉毅/03_设计类图增量修改说明.md)和[系统说明书](../第三次作业_李泉毅/05_系统设计说明书源稿.md)。程杰已交[前端设计](../第三次作业_程杰/01_前端设计章节.md)、[组件关系](../第三次作业_程杰/02_组件关系图.md)、[状态与时序](../第三次作业_程杰/03_关键状态与时序图.md)、[入口能力矩阵](../第三次作业_程杰/04_入口能力矩阵.md)及[接口交接表](../第三次作业_程杰/05_前端所需接口表.md)。前端已区分空/加载/失败/冲突和端侧停止行为，DESKTOP/WECHAT真实能力接入前按模拟或不可用处理。郭昱祺独立功能层次、泳道/数据流图及最终PPT尚未见本轮提交；现有图源还需在最终Word/PDF中完成可读性与整合复核。

## 3. 接口与业务流程

应用服务沿用UML的AuthService注册/登录/退出/改密、ProfileService读取/编辑/汇总、RecordService保存/列表/更新/清除、AIProcessingService.respond/cancel和SearchProvider.search契约。Agent任务接口采用POST /api/agent/tasks、GET /api/agent/tasks/:requestId、POST /api/agent/tasks/:requestId/cancel；字段与状态见[技术基线§3](03_技术决策与Agent接入基线.md#3-应用契约与任务失效规则)，由李泉毅组织实现与接口文档同步。

注册登录先建立有效身份；应用API不信任请求自行填写的所有者与入口。用户选择陪伴或排练后，服务检查任务、当前入口、内容范围和AI外发授权，再构造最小上下文。回复必须匹配请求代次与当前身份；退出、暂停、重来或切换后旧回复失效。

主动保存走RecordService，RecordKind统一为CONVERSATION、EMOTION、WORRY_OBJECT、REHEARSAL_DRAFT、DEPOSIT、QUERY。用户选定消息形成快照；日历只记录不自动分析；排练只整理当前认可表达；寄存按STORED→AVAILABLE→RETRIEVED流转。文字销毁为独立端侧视图，没有正文保存/上传接口。查询先取得来源，再整理摘要，每个事实对应来源标识；结果默认临时，用户明确保存后才形成QUERY记录和证据链。

权限错误、参数错误、服务失败、版本冲突与空结果分开表达；保存与清除实际成功后才显示成功。李泉毅已提交[接口目录](../第三次作业_李泉毅/04_接口目录.md)，详细字段以09号为准。[前端接口表§10](../第三次作业_程杰/05_前端所需接口表.md)已登记422差异、CSRF头名、409后状态读取、保存结果核实等待确认项；仍需专业负责人关闭，不能将目录已提交写成接口已联调。

本轮已有[全功能接口与限制规范](09_全功能接口与限制规范.md)，覆盖REQ01～17；李泉毅据此复核专业稿并组织实现。API请求使用Zod严格Schema，前后端同规则；新密码12～128、登录名3～64、正文最多4000码点。业务会话/活动分别使用双代次；排练提供simulation，物件提供资源ID/版本或明确临时draft；SEARCH任务走独立查询接口；取消/超时属于任务状态，NOT_FOUND/RATE_LIMITED加入统一错误映射。端侧训练/销毁/物理互动没有逐步正文上传接口。

## 4. 数据库与数据生命周期

存储方案采用受控服务端PostgreSQL、pg参数化查询和SQL迁移，按账号+入口隔离。庄剀涵[数据库设计v0.2](../../database-design/404NOTFOUND_数据库设计说明书_庄剀涵_v0.2.md)已给出概念模型、数据字典、事务和物理约束；[DDL](../../database-design/sql/404notfound_postgresql.sql)含25张表，当前不据文件存在认定已执行建表。

| 数据类别 | 已提交设计中的对象/表 | 处理规则 |
|---|---|---|
| 账号与身份 | user_accounts、password_credentials、login_sessions、user_profiles、account_preferences | 密码/令牌只存摘要；退出撤销登录，不等于清除已存记录 |
| 主动保存记录 | saved_records及saved_messages、emotion_records、worry_objects、rehearsal_drafts、worry_deposits、saved_queries等类型数据 | 本人+入口+类型；保存用途授权；版本冲突原子拒绝；查询证据链由服务端复制 |
| 房间外观关联 | rooms、room_objects与物件关系 | 仅外观和正文分开；解除外观关联不谎称正文已清除 |
| 授权 | consent_grants | 用途、对象范围、有效状态；授权变更不扩散到其他用途 |
| 当前任务 | 临时Message、PendingRequest、训练/物理/音频运行 | 当前任务内存；未主动保存不建持久历史 |
| 禁止留存 | 文字销毁正文、未选上下文、认证明文 | 不进入数据库、持久浏览器存储、模型、搜索、日志与崩溃采集 |

记录查询始终附带owner+entry；修改匹配expectedVersion；业务时间点按UTC保存，日历日期按用户时区解释。账号切换不会迁移游客文本，同账号其他入口不自动读取本入口记录。备份加密保留7天，清除标记经事务outbox复制到独立日志并覆盖全部可恢复备份；恢复先重放、核验并撤销旧登录会话后开放。具体密钥/资源配置及实际恢复仍待实施，不承诺“绝对无痕”。

数据库可直接复用[ER图](../../database-design/diagrams/404NOTFOUND_database_er.svg)（[Mermaid图源](../../database-design/diagrams/404NOTFOUND_database_er.mmd)）、[类—表映射与检索契约](../../database-design/类表映射与检索契约.md)、[需求—数据—验收追踪](../../database-design/需求-数据-验收追踪表.md)和[约100秒讲稿](../../database-design/数据库答辩讲稿_庄剀涵.md)。房间归属采用账号/入口复合外键，资料与偏好有version_no，情绪词改为数组，认可表达保存为选定列表；查询保存使用saved_queries、sources、claims和evidence_links关联证据链。

[内部交叉评审记录](../../database-design/evidence/数据库设计交叉评审记录_20261020.md)记录CR-01～CR-12及静态修订，但其§4“运行未执行”与[验收清单](../../database-design/evidence/数据库设计验收清单.md)及主说明书§9的通过状态冲突。庄剀涵/曾俊涛需逐项补可复现证据或纠正状态；当前博客不采用“全通过”结论。持久幂等元数据覆盖、来源快照冻结/更新及清理规则仍需补充确认，备份恢复与REQ14零外泄也没有本次可核实运行证据。

## 5. 安全、健壮性与运行设计

权限在服务与仓储边界执行；游客仅临时体验，持久保存要求登录；他人、其他入口、失效会话不得读取记录。凭据和正文不进日志/模型上下文，模型与搜索供应商凭据位于受控服务侧。外部网页和模型输出作为不可信内容，不可改变系统规则或执行任意操作。

| 异常 | 设计处理 | 后续验证 |
|---|---|---|
| 模型/检索超时或额度失败 | 总时限、显式失败；允许用户重试；预设演示标模拟 | 合成超时/429/断网，不伪装成功 |
| 取消、换模式、退出/换账号 | 失效代次、尝试中止、服务与前端均拦截旧结果 | 延迟响应后操作退出/重来，检查无回填和跨身份读取 |
| 保存重复与并发改写 | 受控幂等键、记录版本、事务回滚 | 同请求重复不增记录；旧版本冲突不覆盖 |
| 页面退出与互动停止 | 释放动画帧、定时器、物理循环、音频和点击捕获 | 检查退出后无新推进和声音；桌面壳独立验证 |
| 数据读取失败 | 显示失败，不等同空历史/全零计数 | 模拟仓储失败、拒绝访问和空数据三种结果 |

部署基线为Web静态资源、Node.js应用API、私网PostgreSQL；HTTPS、配置注入、脱敏观测、恢复和回退由曾俊涛落实。Web安全Cookie只装随机会话凭据、数据库存摘要；变更操作验CSRF；退出/改密撤销会话与任务。Electron主进程管窗口、preload白名单桥、React隔离渲染，先验证透明/置顶/拖动/穿透/缩放/多屏/退出，失败明示降级。关欣补专业权限矩阵和评审表。性能数字只是初始配置/目标，不声称已达成。
