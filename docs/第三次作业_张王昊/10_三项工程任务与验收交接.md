## C02 PostgreSQL登录会话

主责李泉毅，庄剀涵建表/迁移，关欣复核，曾俊涛验证；W1设计，W2完成认证纵向链，W5复测恢复。

沿用AuthService、IdentityRepository和LoginSession，使用node:crypto随机32字节凭据+摘要存库、Argon2id密码摘要、HttpOnly/Secure/SameSite Cookie、CSRF和Origin检查。login_sessions字段/索引和认证端点见09号REQ16；不再叠加另一套内存会话中间件。业务AI任务仍临时内存，不与登录表混淆。

实现顺序：DDL/迁移及唯一索引→注册原子创建账号→登录签发/轮换→认证中间件构建AccessContext→退出撤销/取消任务→改密事务撤销所有旧会话→限速/过期→重启与备份恢复验证。改密并发比较旧摘要条件，失败不得部分提交；事务用pg同一连接。

| 场景 | 应有结果 | 所需证据 |
|---|---|---|
| 登录/重新登录 | Cookie原始凭据仅安全传输；DB只有摘要；旧匿名任务失效 | 响应头脱敏、表结构及身份状态 |
| 退出/改密/换账号/空闲30分钟或绝对7天到期 | 旧凭据不能读取数据，旧AI任务不能再取正文 | HTTP结果和任务状态 |
| 同时改密/重复注册/服务重启 | 唯一与事务正确；重启不复活撤销会话 | 约束/并发操作结果 |
| 恢复业务备份 | 清除日志重放；所有恢复出的旧会话失效后才开放 | 恢复步骤及检查结果 |
| 无/错误CSRF、伪造entry头、账号/IP失败限速 | 拒绝越界，带安全提示和重试时间 | 合成请求与响应 |

完成门槛：DDL与ER/字典一致、AuthService实现、认证/撤销用例、日志无敏感信息、旧登录不能跨入口使用。任何明文凭据入库/日志、撤销不生效或越权均阻止集成发布。

## C03 Electron桌宠能力验证

程杰主责，郭昱祺明确交互，曾俊涛记环境和验证，关欣审查preload/IPC，张王昊据结果调整范围。把最小能力验证提前至W2，W4再集成互动，避免到11月才发现桌面能力不可用。

先建立独立验证工程复用React宠物组件，固定本地资源，不接真实私密数据；主进程管窗口、preload只给白名单桥、渲染层做界面。contextIsolation/sandbox开启、nodeIntegration关闭；检查IPC发起窗口和输入，阻止任意导航、通用执行/文件系统桥。明确桌宠不是网页内画布，实测通过后再更新AVAILABLE。

| 场景 | 预期/降级 | 记录字段 |
|---|---|---|
| 透明窗口与置顶 | Windows目标设备正常；全屏/系统窗口限制据实写明 | Windows/Electron版本、截图、实际行为 |
| 拖动、点击与穿透切换 | 按钮不误拖，非交互时不妨碍其他应用，恢复/退出入口可达 | 操作步骤、误触、恢复结果 |
| 缩放与多屏 | 测100%/125%/150%，跨屏及副屏断开后窗口仍可找回 | 屏幕尺寸、DPI、位置与偏移 |
| 退出/Escape、崩溃重开 | 释放音频、监听、动画和捕获；不自动恢复正文 | 进程/事件检查及资源状态 |
| IPC与入口标识 | 非白名单调用拒绝；模拟DESKTOP不得仅改头接真实记录 | 安全用例和能力矩阵 |

验证报告至少给支持/受限/失败、环境、证据、负责人、复核人；没有实测时全部写“未验证”，不能写通过。失败时保留Web画布演示并标不支持原生浮层；若核心桌宠目标受影响，张王昊发范围变更单并同步博客/PPT，不静默降低承诺。客户端真实认证与可信DESKTOP绑定另行设计，验证工程不分发数据库/模型密钥。
