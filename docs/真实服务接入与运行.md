# 全业务真实服务运行指南

本次将当前 Web 应用的业务入口连接到实际后端。旧 HTML 页面和组件展示页转入真实应用，不再执行预设回复或浏览器内存历史。保留的旧源码不作为当前业务入口。代码接入、隔离测试通过和真实外部服务验收是三个不同状态。

## 1. 环境与本地 Web 启动

需要 Node.js 22.12 或更高兼容版本、PostgreSQL 16、pnpm 10。保持 backend、prototype、shared、database-design 的相对位置。

在 pgAdmin 中创建本地开发数据库 `404notfound`，在 backend 复制 `.env.example` 为 `.env`（不要覆盖已有配置），填写实际 DATABASE_URL、独立随机的 PROFILE_ENCRYPTION_KEY 和自己的 ZHIPU_API_KEY。密钥只放在本地或部署环境，不提交 GitHub。

生成加密密钥：

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
```

后端终端（backend 文件夹）：

```powershell
pnpm install --frozen-lockfile
pnpm run migrate
pnpm start
```

迁移包括 `005_optional_emotion_fields.sql`。已有数据库同样需要执行迁移，不要修改旧迁移或清空现有数据。迁移命令现已自动读取 backend/.env。

前端终端（prototype 文件夹）：

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

访问 http://127.0.0.1:5173。后端 APP_ORIGIN 必须一致。当前应用固定使用真实 API，缺少服务时显示错误，不会自动改用 mock。默认代理目标为 http://127.0.0.1:3000；需要修改时设置 API_PROXY_TARGET。

普通界面通过受用途许可约束的业务接口调用模型，不需要开启内部模型直调口。INTERNAL_MODEL_TOKEN 默认留空，使内部入口拒绝访问；只有受信任的服务间调用才另行配置独立随机令牌。

需要真实模型回复时填写智谱密钥，保持仓库允许的 `glm-4.7-flash` 与官方接口地址。可在 backend 运行 `pnpm run smoke:model` 做一次真实调用；可能产生供应商用量，结果以账户权限和实际响应为准。查询改为 SerpAPI 的 Bing 引擎，需在后端配置 `SEARCH_PROVIDER=bing`、`SERPAPI_API_KEY`、`BING_SEARCH_MARKET=zh-CN` 和 `SEARCH_TIMEOUT_MS=15000`。密钥不提交仓库；详见《Bing搜索接入与验收》。

## 2. 功能入口与保存规则

| 入口 | 实际行为 |
|---|---|
| 陪伴交流 | 创建会话、明确 AI 处理许可、提交任务、轮询结果、取消/暂停/继续/重来/结束；可主动保存实际对话 |
| 事情整理 | ORGANIZE 模式真实模型调用；可从物件选择本次要处理的文字，不自动携带其他内容 |
| 对话排练 | 提交实际场景、角色、目标和风格；勾选本人认可的消息后整理与保存表达 |
| 文字备忘与全部历史 | 复用已合入的 RecordVault，保留保存前快照、再次确认和结果未知时沿用请求 ID 的核实流程 |
| 陪伴记录 | 本人当前入口的对话历史、分页、详情、两步清除 |
| 情绪日历 | 主动新增、按月/日查看、编辑、清除；允许不命名、不填强度与备注，不自动分析 |
| 烦恼物件 | 保存/回看/编辑形状和加密正文，或不保存直接选择文字进入整理 |
| 烦恼寄存所 | 保存正文与再打开时间；到期前不返回正文；到期仍需主动取出，也可延期或清除 |
| 信息查询 | 真实 Bing 结果链接与摘录（经 SerpAPI）、获取时间、无结果和失败提示；主动保存时由后端复制本次完成任务的来源链 |
| 查询记录 | 回看本人保存的问题、来源摘录和链接；摘录状态为未知，不冒充独立核验事实 |
| 情绪命名卡 | 服务端校验并路由到倾听、整理或查询；选词不会自动调用模型或保存 |
| 四类小训练 | 呼吸节奏、五感 5/4/3/2/1、三步暂停整理、可编辑任务拆分；使用随包静态定义及本地状态机，不依赖模型或联网；可选 AI 整理仍需单独确认发送 |
| 物理小游戏 | 本机真实小球重力/碰撞、轨道摆放、材质参数、限定音阶和可调音量；离开即停止 |
| 屏幕发泄 | 本机点击产生逐渐复原的效果；桌面客户端另提供透明全屏浮层，Esc 退出 |
| 文字销毁 | 仅在该组件私有内存短暂处理，不调用 API，不写浏览器存储；动画结束或离开时释放引用，不承诺操作系统级安全擦除 |
| 个人主页/设置 | 服务端资料编辑、预设头像、简介、保存提示偏好、本人内容数量、改密及退出 |

对话默认只处理当前输入。携带本页临时对话或已保存记录需要用户明确勾选，历史由后端重新校验归属与当前有效性，最多 4000 字。日历和寄存正文不能通过通用历史上下文路径展开。跨页面切换不自动传递正文；情绪命名卡和物件的“选择并进入”只把明确选择的内容放入目标输入框，不立即发送。

刷新页面会清理未保存的临时会话；已主动保存的记录从数据库恢复。任务与短期用途许可当前在单进程内存中，服务重启后需要重新开始任务，不会假装恢复运行。

## 3. 同源部署

先在 prototype 执行 `npm run build`，然后在 backend 环境设置：

```ini
APP_SERVE_FRONTEND=true
APP_ORIGIN=http://127.0.0.1:3000
```

启动 backend 后可直接访问 http://127.0.0.1:3000，页面与 API 由同一服务提供。公网部署使用 HTTPS 反向代理，将 APP_ORIGIN 改成实际 HTTPS 域名，并设置 SESSION_COOKIE_SECURE=true。后端默认仅监听 127.0.0.1，不会自动公开端口。

## 4. 桌面入口

Electron 不再只有静态样机：它打开真实业务工作台，并保留置顶宠物、拖动、隐藏和点击穿透；本地宠物按钮可以打开真实透明全屏发泄窗口，Esc 退出。

为保持默认入口隔离，另起一个桌面后端进程，在该进程环境中设置：

```powershell
$env:APP_ENTRY_POINT='DESKTOP'
$env:PORT='3001'
$env:APP_ORIGIN='http://127.0.0.1:5174'
pnpm start
```

另一个 prototype 终端：

```powershell
$env:API_PROXY_TARGET='http://127.0.0.1:3001'
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

第三个 prototype 终端：

```powershell
$env:DESKTOP_APP_URL='http://127.0.0.1:5174'
npm run electron:dev
```

需要已安装 Electron 二进制；若此前跳过安装脚本，需要先补齐官方 Electron 运行程序。工作台使用独立浏览器会话分区；入口标识来自服务器 APP_ENTRY_POINT，不接受客户端伪造。真实桌面窗口行为仍需在目标电脑上验收，语法检查不能代替该验收。

## 5. 微信入口

后端已提供 `/integrations/wechat` GET 验证与 POST 消息回调，支持明文和 AES 加密消息、签名校验、短期时间窗、重复消息去重、显式处理许可、真实模型/查询任务和临时会话清理。回调快速返回任务已接受，用户发送“结果”取回实际回复，避免等待模型阻塞回调。

需要自己的公众号与可被微信服务器访问的 HTTPS 回调地址。在部署环境配置：

```ini
WECHAT_TOKEN=与公众号后台一致的Token
WECHAT_APP_ID=自己的AppID
WECHAT_ENCODING_AES_KEY=公众号后台的43位EncodingAESKey
WECHAT_WEB_URL=https://你的微信业务站点/
```

明文模式只需 Token；安全模式同时配置 AppID 和 AES Key。参数必须与公众号后台选择的模式一致。没有配置时返回服务未配置，不冒充接入成功。

公众号文字入口支持：帮助、同意、发送倾诉内容、`查 具体问题`、结果、结束。微信临时对话不读取 Web/桌面账号记录，不持久化消息正文；完整日历、记录与互动功能通过配置的移动网页打开。如需微信网页独立记录入口，使用单独部署进程与站点，将服务器 APP_ENTRY_POINT 设为 WECHAT；登录复用账号，记录仍按入口隔离，不自动绑定或同步公众号 OpenID。

公众号认证、域名、回调可达性与微信后台权限必须由真实平台配置后实测。当前自动化覆盖协议与业务分发，不等于已经上线公众号。

## 6. 验证边界

运行 backend 的 `pnpm test` 和 prototype 的 `npm test`、`npm run build`。自动化用隔离 PGlite 和测试替身核对业务、权限、失败和取消语义；正式路径不使用这些替身。真实 PostgreSQL、智谱实网、SerpAPI/Bing 账户实网、Electron 原生窗口及微信公众号需要各自环境验收。

明显即时危险表达会中断常规任务并给出现实支持提示，不宣称自动救援、诊断或风险评分。该规则不是完整的临床危机识别系统。
