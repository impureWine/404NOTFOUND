# 四类减压训练实现与验收（2026-10-29）

依据：`docs/需求范围_v0.3.md` REQ02，以及 `docs/第三次作业_张王昊/09_全功能接口与限制规范.md` 第 4 节 AT-02。固定训练不需要逐步 AI 接口；未开始不推进，暂停冻结，退出停止。

## 入口与功能

在当前应用点击「减压小游戏」，选择以下练习。旧练习链接仍跳转到当前应用。

| 练习 | 已实现的交互 |
| --- | --- |
| 呼吸调节 `#breathing` | 1/2/3 分钟；自定吸气、停留、呼气秒数；停留可设为 0；阶段圆环、倒计时、完成轮数、自动完成；支持减少动态效果 |
| 五感安定 `#training` | 5/4/3/2/1 引导；可选填写、跳过、上一步；完成后回看本次填写、返回修改或清空 |
| 暂停整理 `#pause-organize` | 三步填写：当前事情、能控制的部分、最小下一步；可跳过、回退、查看和修改本次结果 |
| 任务拆分 `#task-splitting` | 填写任务及准备事项、小动作、求助内容；新增、编辑、移除、排序最多 20 步；校验空白；完成后复制或回到编辑；复制失败显示手动复制文本 |

所有练习展示说明和预计时长，必须明确点击开始；支持暂停、继续、重来、退出。暂停时计时和步骤操作冻结；页面隐藏自动暂停且不自动恢复；退出、页面卸载和切换账号会停止计时。重来或退出按钮在有填写时提示确认。填写只保留于当前组件内存，不上传、不自动持久化。离开页面会丢弃临时内容，需留存任务时先复制。

任务拆分的可选「带到 AI 整理」仅将用户填写带入「事情整理」草稿，下一页需主动勾选 AI 处理许可并发送；固定练习不需要模型密钥。AI 处理仍使用已有 ORGANIZE + REPLY 服务链路。

## 代码位置

- `shared/training-definitions.json`：四类内容、步骤、预计时长及内容版本；端侧及后端兼容接口共用，避免两套文案漂移。
- `prototype/src/live/training-controller.js`：状态、时钟、阶段、页面生命周期；通过代次隔离失效计时回调。
- `prototype/src/live/Training.jsx`、`training.css`：练习界面、暂存填写、任务列表与结果。
- 后端原训练接口保留；页面按项目要求使用本地固定训练，不以接口成功充当练习完成。

## 本次验证

前端 19/19、后端 151/151 测试通过；Vite 生产构建通过。新增端侧测试覆盖：未开始零推进、呼吸阶段边界、跳过停留、暂停冻结、延迟完成、重置后旧回调无效、退出零新事件、显式推进与完成、非法配置拒绝、隐藏自动暂停、退出和卸载清理。

本地浏览器使用合成内容验证：

1. 呼吸选择 2 分钟后开始；暂停时阶段、进度和用时冻结；继续及退出返回菜单。
2. 五感填写、回到上一步仍保留输入、跳过并完成，结果显示本次输入和未填写项。
3. 暂停整理完成三步，结果来自本次输入；返回修改先进入暂停状态。
4. 任务空白完成被拦截；加入步骤、上移、新增、暂停冻结、完成结果和复制成功。
5. AI 整理入口带入当前步骤，许可未勾选且发送按钮禁用，没有自动请求模型。
6. 纯静态 HTTP 页面不提供 API，显示认证不可用时，呼吸训练仍可启动。

这些验证不表示真实外部模型、Electron 原生窗口或生产部署已验收。
