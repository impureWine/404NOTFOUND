## 2. 更新后的项目定位

**一句话描述：** 404NOTFOUND 是面向大众日常烦恼的桌宠陪伴与减压工具，支持账号登录和私密个人主页，以及倾听交流、情绪记录、烦恼整理、沟通排练、互动解压和带来源的信息查询，并让用户决定内容是否保存、暂存、销毁。

桌宠承担轻量唤起、状态展示和交互陪伴；Web 承载课程原型及完整功能页面；微信作为适配后的聊天入口。全桌面浮层等能力需要桌面客户端支持，不能因为存在微信或 Web 入口就宣称各端均能完整运行。

用户可以只记录、只玩一次解压互动或只查资料，不需要完成一套固定流程，也不要求每日打卡。

### 3.1 新功能与原有能力如何衔接

- 情绪命名卡降低表达门槛，可以进入陪伴交流、烦恼梳理或信息查询。
- 情绪与事件日历是用户主动建立的记录，不自动保存聊天或推断每日状态。
- 烦恼物件化和寄存所分别处理“先描述它”和“先放一放”；物件外观本身不代表正文已获保存授权。
- 排练室是独立任务，需要用户选定场景与对象，不能把普通聊天自动转换为角色扮演。
- 屏幕发泄、文字焚化和弹珠机属于压力缓解模块的新交互，与原有小训练并列。

- 会话控制与隐私规则贯穿所有模块，但不同模块使用不同的保存方式。
- 登录确认“当前是谁”，个人主页组织“本人有哪些已保存内容及设置”；登录本身不代表同意保存聊天、分析日历、跨端同步或公开个人资料。
- 个人主页是私密个人中心，统一提供日历、物件、寄存及排练整理稿的入口；烦恼正文不直接铺满主页。

## 4. 原有七项功能的完整范围

| 编号 | 正常行为与输出 | 异常与控制 | 验收要点 |
|---|---|---|---|
| REQ01 | 接收近况或烦恼，先倾听；需要时澄清用户想倾诉还是整理下一步，输出简短回应 | 空输入、超限和超时有明确反馈；可结束；不强迫建议或训练 | 用户选择“只想倾诉”后不被强行引导到训练或分析 |
| REQ02 | 展示训练说明和预计时长，用户选择呼吸、五感定向、暂停整理或任务拆分后开始 | 可暂停、继续和退出；内容不可用时返回；不适时停止 | 未点击开始不得推进；退出后训练停止 |
| REQ03 | 明确问题后检索，展示摘要、对应来源标题和链接，以及可用时间信息 | 问题不清先澄清；无结果、超时、过期和来源冲突分别说明 | 每个有依据的事实摘要对应可核查来源；无依据不伪造链接 |
| REQ04 | 根据用户选择切换任务，界面显示当前模式；说明需要携带哪些内容 | 意图不明先确认；离开训练或物理互动时停止运行；切换失败不显示成功 | 情绪回应与事实查询格式可区分 |
| REQ05 | 默认不持久化会话；主动保存后可查看自己的历史；清除前说明对象与范围 | 空历史、归属不符、保存和清除失败有实际状态；允许取消清除 | 未选择保存不新增历史；清除后对应记录不再出现在历史和后续上下文中 |
| REQ06 | 区分 Web、桌宠和微信入口，核心流程复用服务，各入口默认隔离 | 入口或网络不可用有提示；微信未实接时持续标明模拟 | 不自动读取另一入口历史；各端展示实际可用能力 |
| REQ07 | 最小化处理数据，校验归属，约束对话和检索内容；敏感场景按既有边界回应 | 拒绝越权；明显危机表达停止常规引导并提示现实支持；不执行检索材料中的指令 | 权限、留存和敏感场景使用合成案例测试；不把求助提示称为自动救援 |

历史保存、日历保存、寄存保存必须分别表达。授权保存某类数据，不代表授权分析、跨端共享。

## 5. 新增十项功能说明与验收建议

下列原型编号和 AT 编号延续原材料的建议命名方式，尚未存在对应的可点击页面或已执行测试。

### REQ08 情绪与事件日历

- **用户与场景：** 用户愿意留下当日感受，之后按日期回看；可以不填写事件，也可以只记录不分析，不要求连续打卡。
- **前置条件与输入：** 用户主动进入记录页面；选择日期、一个或多个情绪词、强度和可选事件。持久化保存前需要有效登录，游客可以先填写临时内容。建议强度采用 1～5 级文字标尺，具体尺度待原型验证。
- **正常流程与输出：** 选择日期 → 填写内容 → 选择保存 → 日历显示记录标记 → 点击日期查看详情。记录可修改；无记录日期呈现空状态。
- **分析与保存：** 保存只代表保存该条记录。默认不分析，不自动生成心理标签、健康评分、趋势结论或预警。后续若提供分析，须由用户另行选择范围。
- **异常流程：** 无效日期或输入给出修改提示；保存失败保留当前未提交输入并明确失败；取消不保存；查看失败不能误示为空记录。
- **涉及原型：** P-D01 日历、P-D02 记录详情／编辑。
- **AT-08：** 给定用户选择“只记录”，保存并再次打开日期应显示原记录，且不得产生分析或触发模型分析请求；取消保存后不得新增持久化记录。

### REQ09 情绪命名卡

- **用户与场景：** 用户不想写长段文字，希望快速表达“焦虑、烦躁、失落、疲惫”等感受。
- **前置条件与输入：** 用户进入命名卡；选择情绪词，可补充其他词语，并选择“倾听／梳理／查资料”。
- **正常流程与输出：** 选择情绪 → 选择当前需要 → 可选补充一句话 → 进入对应任务。查资料前如果缺少具体问题，先澄清查询内容。
- **保存与控制：** 默认作为当前任务的临时输入。用户可另行选择写入日历，不能因选词而自动生成每日记录。
- **异常流程：** 未选需要时保持选择页，不擅自分析；返回后可修改；目标服务不可用时保留选择并允许返回。
- **涉及原型：** P-N01 命名卡及原有 P-C01、P-S01。
- **AT-09：** 选择“疲惫＋倾听”应进入倾听流程；选择“烦躁＋查资料”且无问题时，应先询问查什么；选词不自动新增日历或历史记录。

### REQ10 烦恼物件化

- **用户与场景：** 用户难以直接描述抽象烦恼，希望给它一个形状，再决定如何处理。
- **前置条件与输入：** 用户选择线团、石头、便利贴等形状；可填短标题和描述；不填写正文也能体验。
- **正常流程与输出：** 挑选形状 → 生成可放入桌宠房间的物件 → 选择“先拆开看看／先放旁边／找一个能处理的小角” → 按选择继续。拆解或小步骤只在用户选择后展开。
- **保存与控制：** 放进房间与保存正文分开说明。登录后保存物件及其关联正文需主动选择；可只保留形状。只有选定具体物件并主动开始梳理后，才向 AI 传递其必要描述。
- **异常流程：** 未写描述时不凭外观推断原因；取消保存保持临时状态；生成失败允许重选。
- **涉及原型：** P-O01 物件选择、P-O02 桌宠房间。
- **AT-10：** 用户选石头并点“先放旁边”，应展示对应物件，不自动输出分析或催促处理；未授权的其他物件正文不得进入模型上下文。

### REQ11 平行宇宙排练室

- **用户与场景：** 用户希望预演难开口的对话，例如协商分工或向家人表达边界。
- **前置条件与输入：** 用户选择场景、对方角色、希望表达的意思及可选对话风格；界面明确是 AI 模拟。
- **正常流程与输出：** 设置场景 → 开始模拟 → 用户与 AI 交替说话 → 随时暂停、改写上一种说法或重来 → 结束后用户选择自己觉得顺口的表达 → 生成仅包含已选表达的整理稿。
- **保存与控制：** 模拟对话默认不持久化；整理稿可在登录后主动保存。未经选择的 AI 建议不写成用户认可的话，重来前说明未保存内容如何处理。
- **异常流程：** 服务超时保留可理解的当前状态，提供重试；暂停后不再自动推进；模拟不能宣称真实对方必然这样反应。
- **涉及原型：** P-R01 场景设置、P-R02 排练、P-R03 表达整理。
- **AT-11：** 模拟进行中点击暂停，不得继续展示新的角色回复；重来可开始新轮次；结束整理稿只包含用户明确选中的表达。

### REQ12 烦恼寄存所

- **用户与场景：** 用户暂时不想处理一件事，希望把它放入虚拟抽屉，之后自己决定是否再看。
- **前置条件与输入：** 用户填写标题、正文，选择“什么时候再打开”；正式寄存前需要有效登录，并明确该功能需要留存到所选时间。
- **正常流程与输出：** 填写 → 选择时间并寄存 → 抽屉显示包裹 → 到期标记为“可取出” → 用户主动取出、延期或删除。桌宠可抱一个小包裹表示“这件事先替你放着”。
- **到期与保存：** 到期不自动打开正文、不自动调用 AI、不反复弹窗催促。时间到只是状态变化，用户仍可继续放着。正文默认只供本人查看。
- **异常流程：** 时间无效提示重选；保存失败不显示寄存成功；重启后根据当前时间恢复到期状态；延期失败不得改变原时间。
- **涉及原型：** P-L01 虚拟抽屉、P-L02 寄存／取出详情。
- **AT-12：** 到达选定时间后应显示“可取出”，正文仍不自动展开且没有催促通知；用户延期后以新时间为准；取消删除不改变记录。

### REQ13 屏幕无损发泄（敲击回弹）

- **用户与场景：** 用户从桌宠主动开启解压模式，在视觉反馈中完成短时互动。
- **前置条件与输入：** 用户打开桌面浮层，选择裂纹、史莱姆飞溅或橡皮泥凹陷等效果；点击或按压；可调整音量、静音和效果强度。
- **正常流程与输出：** 浮层显示 → 点击产生撞击效果与相应音效 → 松手后逐渐复原 → 用户退出 → 释放浮层并恢复正常桌面操作。声音目标是清脆或沉闷的物理反馈，效果质量待实际演示验证。
- **控制与端侧：** 效果发生在本产品浮层，不修改桌面文件。只有用户主动启用时接收浮层输入，退出按钮与 Escape 键可用。Web 可展示画布演示，但不能称为全桌面效果。
- **异常流程：** 渲染或声音不可用可切换简化效果或静音；失去运行条件时停止互动，不能留下阻挡操作的浮层。
- **涉及原型：** P-V01 解压浮层、P-V02 效果设置。
- **AT-13：** 点击后反馈可见，松手后恢复；静音后不播放音效；退出后浮层不再接收桌面点击，原应用操作恢复。

### REQ14 文字焚化与重力黑洞

- **用户与场景：** 用户只想输入吐槽或焦虑源，通过销毁视觉反馈结束这次表达。
- **前置条件与输入：** 进入明确标注“不保存、不上传”的独立页面；输入文本，选择粉碎、焚烧或黑洞效果。不需要 AI 分析输入。
- **正常流程与输出：** 用户输入 → 点击完成 → 文本呈现物理粉碎、火焰灰烬随鼠标轨迹吹散，或扭曲吸入黑洞 → 清空页面持有的原文及效果缓存 → 返回空输入状态。随时可跳过动画并完成销毁。
- **强制数据规则：** 原文仅在当前界面临时内存中使用；不调用模型或搜索接口，不写聊天历史、日历、数据库、文件、浏览器持久化缓存或云备份，不进入含正文的日志、埋点、崩溃上报、屏幕回放或自动草稿恢复。
- **功能边界：** 不能在这个页面提供“先同步／保存再销毁”的路径。关闭或销毁后，本产品不提供找回。界面表述限定于本产品不留存，不能承诺操作系统、输入法、录屏或设备取证也完全无痕。
- **异常流程：** 效果失败或用户中途关闭仍清理本页面持有的内容；不能为了排错上传原文；空输入提示输入或直接退出。
- **涉及原型：** P-Z01 极简输入与效果选择、P-Z02 销毁过程。
- **AT-14：** 输入专用测试标记后完成销毁或直接关闭，检查应用网络请求、日志、存储和重开页面均不得出现该正文；AI 与搜索调用次数为零；跳过动画仍完成同样清理。

### REQ15 禅意编曲弹珠机（音画物理联动）

- **用户与场景：** 用户自由搭建一个可以观看和聆听的弹珠装置，进行短时放空。
- **前置条件与输入：** 用户进入画布，摆放导轨、跳板、风铃管和转轮，选择木球、弹珠、金属球及重量；设置音量和音阶／和弦方案。
- **正常流程与输出：** 摆放或移动构件 → 释放小球 → 小球按物理规则滑落、碰撞 → 碰撞触发限定音阶或和弦中的声音 → 展示轨迹和材质撞击反馈 → 暂停、继续、重置或退出。
- **音画规则：** 将碰撞事件映射到同一选定调式的五声音阶或和弦内音高，可采用图片所举的降 E 大调音色方案；控制密集碰撞的发声间隔及总音量。保留不同重量和材质的视觉／音色差别，不能把随意触发任意音高称为“不会走调”。
- **保存与控制：** 首轮可在当前会话使用布局；布局保存是后续可选增强，不自动保存用户活动记录。不将“催眠般”写成已验证的睡眠或治疗效果。
- **异常流程：** 小球数量过多时限制新增并提示；音频未启用先要求用户主动开启；卡顿时降低粒子与球数量；退出后停止音频和模拟。
- **涉及原型：** P-P01 构件画布、P-P02 球体与声音设置。
- **AT-15：** 随机摆放构件后可释放并运行小球；所有有音高的碰撞声属于当前允许集合；暂停后物理状态和声音停止；静音、重置、退出分别有效。

### REQ16 注册与登录

- **用户与场景：** 用户需要建立个人身份，在再次进入时查看自己的已保存内容；多人共用设备时需要正确区分账号。
- **前置条件与输入：** 用户主动进入账号页面。首版候选采用用户名／账号标识与密码；注册填写账号、密码、确认密码，并阅读账号数据说明。
- **注册流程与输出：** 填写 → 检查必填项、重复账号和密码一致性 → 创建账号 → 显示结果 → 进入登录。昵称与登录标识分开，昵称允许重名但不能作为账号身份判断依据；注册失败不得显示成功。
- **登录流程与输出：** 输入凭据 → 身份验证 → 建立登录会话 → 显示当前账号 → 返回原本要访问的功能或个人主页。返回目标只能是本产品允许的页面；登录后仍沿用未授权不保存的规则。
- **登录状态与退出：** 界面区分游客、已登录、登录过期；用户可主动退出。退出时使当前入口的登录凭证失效，停止账号任务和异步回复，隐藏私密内容并清理当前界面中的私密缓存；已主动保存的记录继续归原账号，不因退出被删除。
- **密码管理：** 仅提供已登录状态下的修改密码，须验证当前密码并确认新密码；验证失败不修改，修改成功后使旧登录凭证失效并要求重新登录。
- **身份与权限：** 保存记录要求已登录；个人数据访问同时校验账号归属及入口范围。游客可体验允许的临时功能。账号密码不传给模型；密码不明文保存、不进入日志。
- **异常流程：** 空输入或格式不符提示修改；凭据错误用统一反馈；连续失败按既定限制暂停重试；网络失败显示实际状态，不能留下看似登录成功的界面；登录过期停止私密操作并引导重新验证，不能把未保存正文放进跳转地址或请求日志。
- **涉及原型：** P-A01 登录、P-A02 注册、P-A03 密码及登录管理。
- **AT-16：** 有效账号可登录并访问自己的内容，错误凭据不能登录；退出后旧凭证不能访问受保护接口，返回上一页不显示私密正文；A 账号切换至 B 账号后不得展示 A 的内容或迟到回复；未登录或当前密码验证失败不能修改密码；修改成功后旧密码不能登录、旧登录凭证失效，新密码可以登录。

### REQ17 个人主页

- **用户与场景：** 已登录用户需要查看、编辑自己的基础资料，并集中进入个人记录、已保存的整理结果和使用设置。这里的“个人主页”定义为仅本人可访问的个人中心，不自动增加公开空间、关注或私聊。
- **前置条件与输入：** 登录有效且当前账号可用；输入头像选择、昵称、可选个人简介，以及资料编辑或设置操作。建议首轮提供预设头像；自定义图片上传是待确认增强，昵称和简介有明确长度提示，不要求真实姓名、年龄或职业。
- **正常流程与输出：** 打开“我的” → 显示当前账号的头像、昵称、简介 → 编辑并保存资料 → 通过卡片进入情绪日历、烦恼物件／房间、寄存所、会话历史和已保存的排练表达 → 调整声音、桌宠显示和隐私设置 → 查看账号安全或退出登录。
- **内容入口：** 首页可显示有记录的日期数量、物件数量或寄存条目数量等简单摘要；建议保持简洁，不展示烦恼正文、情绪评分、打卡排名或催促文案。点击卡片后再访问对应功能，并执行归属校验。没有内容时显示清楚的空状态和主动创建入口。
- **设置与保存：** 用户主动保存基础资料和账号偏好。会话留存、日历分析、跨端关联分别设置，默认关闭或保持未选择，修改普通资料不能隐式改变授权。仅本设备的声音／桌宠显示偏好需与账号资料区分并标明作用范围。
- **隐私与匿名：** 个人主页不展示文字销毁原文、恢复入口或销毁次数；不自动展示正文。
- **异常流程：** 未登录引导登录；加载失败与“没有内容”分开；资料保存失败保留编辑状态且不提示成功；取消编辑保持原资料；登录过期或账号切换后立即隐藏前一账号内容；被拒绝的访问不能通过更改页面地址绕过。
- **涉及原型：** P-U01 个人主页、P-U02 资料编辑、P-U03 使用偏好与隐私设置；账号安全关联 P-A03，各内容卡片关联原有功能页面。
- **AT-17：** 修改昵称并保存后，重新登录应展示该昵称；取消修改不改变资料；未登录者及其他账号不能读取主页私密信息；卡片只进入本人当前入口允许的数据；登录、资料编辑与主页打开均不产生文字销毁记录或自动跨端同步。

## 6. 数据规则：账号、记下来、先放着、销毁

这三种操作具有不同含义，不能统一归入一个“保存历史”开关。

| 数据／操作 | 默认状态 | 何时允许保存或外发 | 回看或清除范围 |
|---|---|---|---|
| 账号身份与登录凭证 | 未注册前不存在账号；游客无账号数据权限 | 用户主动注册；认证服务处理必要凭据，不向 AI 传递；凭证有有效期 | 当前入口退出后失效；修改密码后撤销旧会话 |
| 个人资料与偏好 | 默认私密；仅保存主动提供的必要资料 | 用户保存头像、昵称、简介或偏好；权限与正文授权分开 | 本人查看编辑；切换账号清理界面缓存，不删除原账号已保存记录 |
| 陪伴交流正文 | 仅当前会话 | 用户主动选择保存；使用模型时明确外部处理边界 | 自有会话历史；清除后不再带入上下文 |
| 情绪命名选择 | 当前任务临时使用 | 用户另选写入日历或保存会话 | 按其实际保存位置管理 |
| 情绪与事件日历 | 未保存前临时使用 | 用户点击保存记录；分析和跨端共享另行选择 | 按日期回看、修改和清除自有记录 |
| 烦恼物件及正文 | 未保存前为临时物件 | 用户明确选择保存；AI 梳理只携带选定物件的必要内容 | 区分只移除外观与同时清除正文 |
| 排练对话／整理稿 | 默认不持久化 | 模拟需模型处理；用户另行保存认可的整理稿 | 说明保存的是全文还是选定表达 |
| 寄存正文 | 寄存前临时使用 | 点击寄存代表为延后查看而保存，须说明保存位置 | 取出、延期、删除均由用户操作 |
| 屏幕互动／弹珠运行状态 | 当前互动临时状态 | 不需要保存个人烦恼；布局保存可独立选择 | 退出后停止互动；设置与正文分开 |
| 焚化／黑洞输入正文 | 临时内存 | 禁止产品内保存、上传、云备份或 AI 处理 | 销毁或关闭后无产品内回看路径 |

建议私密持久化数据首轮优先考虑端侧存储，具体加密、保留期限和备份方式在架构评审时确定；不能把当前建议称为已经实现。各入口默认隔离，跨端关联不因同名账号、同设备或使用桌宠而自动成立。身份层可以识别同一账号，业务数据仍按“账号＋入口”校验访问范围；读取同一账号的基础资料不代表自动读取另一入口的情绪与烦恼记录。

本版建议以账号作为持久化私密记录的所有者；游客只使用临时功能，账号私密页面和保存操作要求登录。登录后的存储位置仍由架构评审确认，既不默认全部上传云端，也不把共享设备的端侧缓存视为天然安全。游客输入不会在登录时自动迁移为已保存记录，只有用户主动选择保存后才绑定当前账号。账号注销及全量数据删除不是本次明确新增项，后续如纳入范围，应另行定义影响和确认流程。

**本工作区操作约束：** 产品需求中的“删除记录”“销毁输入”是拟开发系统的用户操作，不构成删除本工作区文件的授权。本次保留全部已有材料；任何项目文件删除仍须获得用户明确允许。

## 8. 四条可用于原型与答辩的完整场景

### 场景 A：今天有点烦，先说清楚

打开桌宠 → 命名卡选择“烦躁＋倾听” → 陪伴交流 → 用户选择是否记录到日历 → 保存时若为游客先登录，再主动确认保存 → 结束。也可以直接进入日历只记录，不调用分析。

### 场景 B：一件事暂时不想处理

选择烦恼形状 → 将“像一团线”的感受临时放入房间 → 用户选择先放旁边，或在登录后主动寄存并选择再打开时间 → 桌宠显示包裹 → 到期仅显示可取出 → 用户决定继续放着、延期或取出后梳理。

### 场景 C：准备一次难开口的沟通

设置排练场景 → AI 模拟对方 → 用户暂停、换说法或重来 → 选出顺口的表达 → 用户登录后选择保存整理稿。若另需了解事实，用户主动切换查询，并选择携带必要问题；查询输出来源。

### 场景 D：登录后回到自己的内容

游客打开“我的” → 注册或登录 → 查看私密个人主页 → 修改头像／昵称 → 打开自己的日历或寄存所 → 退出登录 → 界面隐藏私密内容 → 换另一个账号登录后只能看到新账号内容。登录过程不自动保存此前的游客输入。

屏幕互动、文字销毁、弹珠机都可独立发起，不要求先倾诉，也不在退出时强制留下感受评价。
