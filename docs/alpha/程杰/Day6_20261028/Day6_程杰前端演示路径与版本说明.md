## 演示路径

### A. Web 首页与认证边界

1. 打开 `http://127.0.0.1:5188/`，确认首页显示“演示原型”和访客状态。
2. 先检查首页 REQ14 独立临时输入区：初始为空；只使用合成文本；点击“销毁文字”或“清空”后正文和状态清理。
3. 点击“登录”或“创建账户”：默认 `VITE_API_MODE=mock`，应显示模拟/未连接边界，不把 API 不可用写成登录成功。
4. 在退出入口验证本地私密视图先清理；网络未知时保留“服务器状态待确认”，不宣称服务端已退出。

### B. 核心公开页面

按以下顺序逐个打开并记录页面标题/HTTP 状态：

`companion.html` → `calendar.html` → `worry-room.html` → `rehearsal.html` → `games.html` → `info-query.html` → `things-organize.html` → `emotion-card.html`。

每个页面只输入合成内容。陪伴、查询、排练、记录和小游戏均为演示原型；页面状态可操作不等于真实后端或模型服务已联调。

### C. 游戏和退出清理

1. 在 `games.html` 的弹珠轨道点击开始，再切换到呼吸/五感面板；弹珠运动计时和累计计时应停止。
2. 开始呼吸后切到后台，再返回页面；训练应停在暂停状态，不自动继续。
3. 打开 `pressure-toy.html`，开启互动后切换系统“减少动态效果”或切到后台；目标停止动画。
4. 刷新/关闭页面前不保存私密文本；`pagehide` 清理游戏计时器和互动监听。

### D. 桌宠样机

```powershell
cd prototype
npm run electron:dev
```

当前环境实际结果为启动失败：Electron 沙盒无法读取 `prototype/node_modules/electron/dist`，错误要求调整 ACL。没有在本日修改系统权限，因此透明、置顶、拖动、点击穿透、快捷键恢复、DPI、多屏和窗口退出均保持“未验证”。后续应在可启动环境按能力矩阵逐项记录，不使用本地源码作为运行证据。

- 2026-10-28 复验：React 测试 12/12、生产构建通过；Web 原型 24 个 HTML 入口与首页 `/` 共 25/25 HTTP 200。
