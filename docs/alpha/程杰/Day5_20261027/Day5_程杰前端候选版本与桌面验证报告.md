## 本日交付

| 范围 | 修改与结果 |
| --- | --- |
| 弹珠轨道 | 将运动计时、累计时间计时和完成后的延迟回位统一纳入 `stopMarbleTimers()`；暂停、重置、切换到其他面板、页面转入后台和 `pagehide` 都会清理全部定时器。 |

| 压力点击玩具 | `web-prototype/practice-pages.js` 在页面隐藏或系统开启减少动态效果时移除活动状态；页面退出时移除媒体查询/可见性监听，并清理提示计时器。 |
| 音频 | 当前实际 Web 原型明确为“无自动声音；本原型不播放音效”，没有音频上下文或音频文件需要释放；未把“静音按钮”写成音频资源已验收。 |
| 前端联调 | 本日没有擅自修改后端契约。React 适配器默认仍是 mock；真实 API、CSRF、账号隔离和记录端到端联调继续列为未执行。 |

本报告对应的实际入口是 `web-prototype/games.html` 和 `web-prototype/pressure-toy.html`。仓库中的 React `ToyPage` 是旧路由模块，当前首页不挂载该组件，因此本日不把它当作运行入口，也未将无效路径写成已修复。

## 可复现方法

Web 游戏页：

```powershell
cd web-prototype
# 使用任意静态服务器打开 games.html 与 pressure-toy.html
```

前端测试与构建：

```powershell
cd prototype
npm test
npm run build
```

桌面样机：

```powershell
cd prototype
npm run electron:dev
```

若启动环境仍报告 Electron `dist` 目录 ACL 阻塞，应由具备本机权限的成员按团队环境流程修复或换用干净工作区后重新执行；本报告不建议在没有审批的情况下修改系统 ACL。
