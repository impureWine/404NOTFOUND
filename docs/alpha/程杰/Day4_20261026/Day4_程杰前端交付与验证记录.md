## 复现与待验收

Web 本地启动（仓库根目录）：

```powershell
cd prototype
npm run dev -- --host 127.0.0.1 --port 5187 --strictPort
```

真实保存/读取/清除联调需在隔离测试后端和测试账号中配置 `VITE_API_MODE=real`、后端要求的 CSRF 头名及 API 服务；然后逐项验证：同意后保存、本人列表/详情、取消两步清除、确认清除、版本冲突、网络断开后同请求号核实，以及账号/入口互相不可见。

REQ14 运行复核：在首页确认临时输入框初始为空；输入合成文本，分别执行销毁、清空、离开/路由切换和刷新/关闭页面；在 Network 与 Application 面板确认正文未出现在请求、Local/Session Storage、IndexedDB 或日志。不得用真实私密内容做测试。

Electron 后续验收：在至少两台显示器可用的环境记录 Windows 缩放百分比、显示器分辨率/排列、Electron 版本与窗口边界；分别在 100%/高 DPI 下启动并移动窗口，观察布局/鼠标操作；通过窗口关闭按钮退出，确认窗口与全局快捷键释放。以上项目本次均未标记通过。
