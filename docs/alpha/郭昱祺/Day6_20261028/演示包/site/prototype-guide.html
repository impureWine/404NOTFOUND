404NOTFOUND · 桌面端原型

一个模拟心理陪伴 / 情绪自助产品的前端原型。默认采用低饱和柔和粉色主调，并可在设置中切换配色。 全部内容为演示数据：未连接真实 AI、搜索、短信、邮箱或后端服务，也不提供医疗诊断、治疗建议或风险评分。

桌面端优先 · 窄屏可用 纯前端 · 单文件自包含 演示原型

页面清单（25 个）

点击任意卡片进入对应页面；标「状态」的页面为同一功能的独立状态呈现

主要跳转关系

所有跳转均为同级 HTML 文件之间的相对链接，可用浏览器返回键回退

账户入口流程

home.html（访客视图）→ login.html 或 register.html → home.html（已登录视图）；登录页「以访客身份继续浏览」直接回落 home.html； 个人主页与设置页的「退出登录」→ login.html。

陪伴交流流程

home.html → companion.html；会话页顶部可进 companion-loading.html / companion-empty.html / companion-error.html； 空状态的示例开场与输入框均跳回 companion.html；错误状态「重试发送」→ companion.html； 会话页「结束本次会话」弹出二次确认 → companion-empty.html 或 settings.html（清除本次表达）。

情绪记录流程

home.html（今日打卡）→ calendar.html；calendar.html 每一行记录可「聊聊」（→ companion.html）或删除（弹出二次确认）； 「查看无记录时的空状态」→ calendar-empty.html；空状态页「保存并查看日历」→ calendar.html。

担忧具象化流程

home.html → worry-room.html；房间内点任意物件显示选中提示，可切换「房间 / 清单」视图； 「放进一件担心」与「立即回看一件」均弹出确认与回看弹窗；「想聊聊这件事」→ companion.html。

排练与减压流程

home.html → rehearsal.html；顶部「查看排练完成页」与「结束并回看」→ rehearsal-complete.html； 该页「保存到情绪日历」给出轻提示、「再排一遍」→ rehearsal.html、「回到首页」→ home.html。 减压页 games.html 内含弹珠轨道与呼吸节奏两个面板切换，「记一句到情绪日历」→ calendar.html。

查询与清除流程

home.html → info-query.html；查询区「看看查不到时」→ info-empty.html，空结果页「返回可查询条目」→ info-query.html； 查询结果侧栏「和模拟陪伴聊聊」→ companion.html。 设置页 settings.html 的四类清除操作全部弹出二次确认弹窗。

演示约束

  • 所有对话、统计、记录与来源链接均为模拟内容，并在页面内明确标注为演示数据。
  • 未连接真实 AI、搜索、短信、邮箱、推送或后端服务；数据仅保存在本机浏览器。
  • 不使用医疗诊断、治疗承诺或风险评分类文案；出现持续困扰时提示寻求专业帮助。
  • 危险操作（删除单条记录、清除会话、清除全部模拟记录、重置游戏纪录、退出排练）都有二次确认与「取消」。
