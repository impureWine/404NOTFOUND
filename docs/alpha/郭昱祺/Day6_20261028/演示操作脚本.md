# Day 6 · 现场演示操作脚本

目标：12 页约 8 分钟。该时长是排练预算，尚未由本人完成计时试讲。演示使用虚构文本，不输入个人烦恼、真实账号或密码。

## 启动与准备

把整个标准演示包解压到本地，保留目录关系。需要 **Node.js 18+**；无需 npm install、前端源码依赖、后端或互联网。进入 `演示包`：

```powershell
node serve.cjs
```

本机若只有 Codex bundled Node，可在 PowerShell 中运行：

```powershell
powershell -NoProfile -File .\启动演示.ps1
```

浏览器访问 **http://127.0.0.1:5190/**。不要用双击方式直接打开 `site/index.html`，模块需要本地 HTTP。服务器只绑定本机地址，不代理业务 API。使用 Ctrl+C 停止。若端口被占用：

```powershell
$env:UX_DEMO_PORT='5191'
node serve.cjs
```

然后访问 http://127.0.0.1:5191/ 。如果没有 Node、脚本受限或启动失败，直接双击 `演示包/备用截图.html`，按下表打开截图讲解。图册无需服务器。

## 保存与历史演示注意

第9→10页要通过页面里的“查看本人历史”连续操作，内存中刚保存的记录才会保留。直接点击导航页链接会重新载入页面，回到固定种子记录；这是演示重置，不是持久化丢失的后端故障。切换顶部预置场景／状态也会重置示例输入。

演示成功只表示本地内存状态变更。不能描述为登录真实账号、AI 产生真实回复、实时检索成功、记录持久化或清除服务器／备份。来源外链可手动打开，但本次固定来源不作为实网核验依据；网络失败时保留失败说明。

## 异常预案

1. 页面无法启动：打开离线图册，按照 PPT 页序讲解，无需现场安装依赖。
2. 状态演示被切换打断：刷新后从当前页的预置状态开始，说明内存示例已重置。
3. 来源外链打不开：展示不确定性或失败状态，不补造成功记录。
4. 被问到发布：明确回答正式保存／历史 UI 闭环与模型授权尚未通过，正式 PostgreSQL、HTTPS、真实模型等未完整验收。
