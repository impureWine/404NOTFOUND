## 启动演示

需要 Node.js 18+，无需 npm install、后端或互联网。在解压后的 `演示包` 目录运行：

```powershell
node serve.cjs
```

浏览器打开 **http://127.0.0.1:5190/**。本机也可运行 `启动演示.ps1` 查找 PATH 或 Codex bundled Node。端口占用时设置 `$env:UX_DEMO_PORT='5191'` 后重启，并访问新端口。Ctrl+C 停止。启动失败时直接打开 `备用截图.html`。GitHub 文件预览不能执行 React 演示，应下载后启动。
