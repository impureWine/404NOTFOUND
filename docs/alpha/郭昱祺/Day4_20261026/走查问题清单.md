## 已执行的关键流程

| 流程 | 实际检查与结果 |
| --- | --- |
| 默认不保存 | 初始无勾选，预览不可用；取消弹窗不增加历史；切换场景不自动保存 |
| 标题校验 | 80 个 emoji 码点允许预览；81 个码点及全空格禁用；超限字段标记 `aria-invalid` |
| 精确范围与许可 | 只选本人消息时确认框不含未选回复；许可默认关闭；改标题后重新确认；重复触发确认只新增一次本地记录 |
| 列表与详情 | 保存后列表多一条，但不含正文；主动打开后仅显示所选片段；筛选无匹配与读取失败文案不同 |
| 游客衔接 | 默认不保留，登录后无游客内容；明确保留时只保留选中片段，随后仍需重新预览和授权 |
| 身份变化 | 模拟 A／B 列表分离；切换后旧选择与详情不可见；游客历史与详情提供登录引导 |
| 登录失效与不可用 | 失效、加载、空、读取失败、不可用和冲突预置状态不渲染详情正文；重试恢复仅为本地样例 |
| 清除 | 默认“保留记录”；取消保留；确认后目标记录及活动详情移除；状态变化样例要求先重读再确认 |
| 保存超时 | 保留并锁定选择，不直接提供重复保存；切到明确失败样例后仍需新确认 |
| 端侧数据边界 | 展示页走查期间未出现 `/api/` 请求；新浏览器上下文中 localStorage／sessionStorage 均为空；URL 只含 page/state；刷新恢复预置数据 |
| 响应布局与兼容 | 19 状态 × 3 视口均无页面横向溢出；390px／320px 保存与清除弹窗可完成操作；原六场景正常态可打开；没有捕获页面脚本异常 |

结果：主走查 77 个检查组通过，窄屏弹窗补充 2 组通过；构建通过。脚本检查与作者截图审阅不等于真实用户可用性测试，也不证明服务端鉴权、持久化或跨入口隔离成立。

## 最短复现路径

1. 打开 [保存正常态](http://127.0.0.1:5186/ux-components.html?page=save&state=normal)，不选消息，确认不能保存；选第一条，打开范围确认，按 Escape 取消。
2. 重新预览，勾选许可并确认，进入历史；应只多一条元数据。打开详情，应只含第一条本人消息。
3. 清除时先选“保留记录”，确认正文仍在；再次清除并确认，应回到历史，目标记录不再出现。
4. 返回保存，切为游客，分别验证默认不保留和明确保留；两条路径都不能在登录时自动保存。
5. 打开顶部失败、超时、登录失效、不可用、状态变化样例，核对上表反馈；将视口缩至 390px／320px，确认状态按钮和模态操作可读可用。

完整步骤与断言见 [walkthrough.cjs](scripts/walkthrough.cjs)。
