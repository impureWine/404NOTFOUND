## 组件契约

| 组件 | 输入／事件 | 行为与接入约束 |
| --- | --- | --- |
| `Sidebar`／`SiteTopbar` | 原身份数据和事件；新增可选 `activePage`、`onNavigate`，侧栏可选 `guestDescription` | 不读取额外账号数据；返回 `true` 的导航回调留在展示入口，其余链接沿用现有原型 |
| `HeroGuest`／`ToolsSection` | `onLogin`、可选 `onBrowse`／`onNavigate` | 展示页将命名卡／训练／聊天／查询映射到对应组件；八个工具链接统一指向已有 `.html` 页面 |
| `EmotionWordPicker` | `selected`、`description`、`disabled`；`onToggle(word)`、`onDescription(text)` | 最多选 3 词；描述按 Unicode 码点计数，超过 4000 时不允许预览；不推断原因或诊断 |
| `EmotionCardPreview` | `card`、`includeDescription`；`onIncludeDescription(bool)`、`onContinue()` | 补充描述默认不携带；选定内容为空或总计超过 4000 码点时禁用继续；不保存或发送 |
| `ChatPreview`／`MessageList` | `status`、`initialDraft`；停止、恢复、重试、查看失败示例、结束事件 | 草稿只进入内存；聊天超时保持“结果待确认”，禁重复发送；查看失败示例不等于核实真实任务 |
| `SearchBar` | 原问题和事件；`busy`、可选 `pendingUnknown` | 超时禁查询提交，保留问题；可以清空或停止本地等待；无自动补发 |
| `AsyncState` | 基础状态及 `timeout`、提示、恢复回调 | 区分初始空、成功 EMPTY、明确失败和结果未知；超时不渲染旧摘要 |
| `TrainingStepCard` | `phase`、`stepIndex` | `idle/running/paused/completed/stopped`；当前步用 `aria-current=step` 标注，阶段提示使用 live region |
| `TrainingControls` | `phase`；`onStart/onPause/onResume/onNext/onExit/onReset` | 暂停时不显示推进按钮；重来回第一步；仅表达意图，不持有定时器或真实服务任务 |

新增页面容器与共享视觉组件暂时不改变程杰负责的正式业务路由。正式接入时，由前端将状态、回调、接口返回 ID 和许可处理接入；展示状态键及本地示例消息 ID 不作为新增 HTTP 字段。

## 状态及路径

| page | 组件范围 | 支持状态 |
| --- | --- | --- |
| `login` | 登录表单与认证卡片样式 | normal／loading／empty／error |
| `home` | 欢迎卡、工具、最近记录 | normal／loading／empty／error；状态主要作用于记录分区 |
| `chat` | 消息、草稿、快照、结束确认 | normal／loading／empty／error／timeout |
| `sources` | 问题、逐条摘要、来源与时效 | normal／loading／empty／error／timeout |
| `emotion` | 自选词、描述、命名卡与明确携带 | normal／loading／empty／error |
| `training` | 步骤、暂停／继续／退出操作 | normal／loading／empty／error，正常态另有五种操作阶段 |

入口格式为 `ux-components.html?page=<page>&state=<state>`。参数仅含枚举键，不写用户名、密码、消息、问题或命名卡描述。场景／顶部状态切换重置示例；场景内的恢复操作保留对应上下文。

命名卡携带只在用户点击后发生：选词直接带入草稿，补充描述还需勾选；进入聊天不会发送。刷新清空这份临时草稿。训练使用静态三步说明，由点击推进，不模拟计时训练完成、音频或模型效果。
