## 3. 状态与恢复操作

| 场景 | 正常 | 加载 | 空 | 失败／特殊状态 |

## 6. 复现

在本工作树的 `prototype` 目录安装锁定依赖后：

```powershell
npm run build
npm test
npm run dev -- --host 127.0.0.1 --port 5187 --strictPort
```

另一个终端使用**同一工作树**启动 real 配置，但仅供测试脚本拦截请求：

```powershell
$env:VITE_API_MODE='real'
$env:VITE_CSRF_HEADER_NAME='X-CSRF-Token'
npm run dev -- --host 127.0.0.1 --port 5188 --strictPort
```

本地安装 Playwright 后，在仓库根目录：

```powershell
$env:PLAYWRIGHT_MODULE_PATH='playwright' # 或已安装模块的绝对路径
node 'docs/alpha/郭昱祺/Day5_20261027/scripts/walkthrough-day5.cjs'
node 'docs/alpha/郭昱祺/Day5_20261027/scripts/day4-regression.cjs'
```

脚本默认使用本机 Edge；可用 `EDGE_PATH` 指定其他安装路径。端口可分别通过 `UX_BASE_URL`、`UX_AUTH_FIXTURE_URL` 调整。输出只写本日目录；不覆盖 Day 4 的历史证据。所有凭据均为虚构测试输入，截图中的密码保持遮蔽。
