# 郭昱祺｜Day1 走查验收清单

### 5.1 执行条件

- 浏览器：Edge 或 Chrome，桌面宽度至少 1280px；另补 390×844 窄屏检查。
- 入口：`web-prototype/login.html`；无真实账号时使用公开演示账号或“访客使用”。
- 记录：每项写“通过 / 部分通过 / 未通过 / 不适用”，保存页面、状态、文案和截图路径。
- 证据边界：原型固定数据、模拟回复、本机内存和静态状态页必须单独标记，不得写成真实服务结果。
