## 2. 演示放行条件

| 等级 | 判定条件 | 演示决策 |
|---|---|---|
| 绿色：真实演示 | 演示前同一环境的合成请求返回 `status=success`、`mock=false`，输出通过契约和边界校验 | 可以展示真实合成回复，同时说明单次成功不代表稳定性或生产验收 |
| 黄色：受控降级 | 返回超时、429、503、空输出或非法输出；离线专项测试仍通过 | 先展示真实失败状态，再切换到明确标注 `mock=true` 的离线流程；不得称为真实模型结果 |
| 红色：停止模型演示 | 配置白名单异常、密钥疑似泄漏、错误响应暴露内部信息、Mock 无标记、页面无法停止加载或无法保留输入 | 不展示模型生成流程；改讲架构、契约和测试证据，登记阻塞 |

当前状态为黄色。

## 3. 错误矩阵

| 场景 | HTTP / 错误码 | 自动重试 | 用户侧动作 | 演示人员动作 | 证据边界 |
|---|---|---:|---|---|---|
| 超时 | 504 / `MODEL_TIMEOUT` | 0 次 | 保留输入；可稍后手动重试或退出 | 停止等待并说明上游超时；不连续提交 | `AbortSignal` 不证明供应商已停止运算或计费 |
| 限流 | 429 / `MODEL_RATE_LIMITED` | 0 次 | 稍后手动重试或退出 | 展示脱敏真实失败记录；切换到带 Mock 标识的离线流程 | 429 只证明供应商拒绝本次请求，不是成功生成 |
| 服务或凭据不可用 | 503 / `MODEL_UNAVAILABLE` | 0 次 | 结束当前任务或稍后重试 | 不展示原始异常、堆栈或凭据；检查配置与控制台 | 不能用固定回复冒充供应商回复 |
| 用户取消 | 499 / `MODEL_CANCELLED` | 0 次 | 当前任务结束 | 确认迟到结果没有回填 | 应用拒收不证明供应商已取消计算 |
| 空输出 | 502 / `EMPTY_MODEL_OUTPUT` | 0 次 | 保留输入并结束或重试 | 不展示空白“成功”页 | 离线用例只验证错误映射 |
| 非法结构 | 502 / `INVALID_MODEL_OUTPUT` | 0 次 | 保留输入并结束或重试 | 拒绝半结构化结果，不人工拼成成功内容 | 不能忽略动作、意图或引用校验 |
| 越界内容 | 502 / `CONTENT_REJECTED` | 0 次 | 显示通用安全错误 | 不展示被拒原文 | 当前窄规则不是通用内容安全层 |
| 请求不合法 | 400 / `INVALID_REQUEST` | 0 次 | 修正输入 | 检查契约版本和字段 | 不应向供应商发送未通过本地校验的载荷 |

`retryable=true` 只表示用户可以在条件变化后重新发起请求，不等于系统会自动重试。当前配置固定 `maxRetries=0`，也没有自动切换收费模型。

## 4. 演示前操作顺序

1. 检查演示分支、Node 版本和 `.env` 中所需变量是否存在，只确认“存在/不存在”，不打印值。
2. 查看智谱控制台的免费模型状态、速率限制、调用记录和账单；截图时遮蔽账号及凭据。
3. 只用仓库合成输入执行一次 `npm run smoke:model`；成功或失败都保存脱敏结果。
4. 执行 `npm run test:ai`，确认异常契约没有回归。
5. 执行 `npm run sample:ai`，准备正常、超时和不可用离线样例；检查每个结果均有 `mock=true`。
6. 在实际页面检查：加载能停止、错误状态可见、原输入保留、重试/退出可操作、Mock 标识可见。
7. 根据第 2 节选择绿色、黄色或红色路径。失败后不在台上连续请求供应商。

## 5. 黄色降级演示脚本

> 这次真实请求返回了供应商限流，因此当前真实生成不可用。系统没有无限等待或自动连续重试，而是返回明确的 `MODEL_RATE_LIMITED` 状态并保留用户输入。接下来展示的是带 `mock=true` 标记的离线流程，只用于说明正常、超时和不可用状态如何处理，不把它当作真实模型结果。

演示顺序：

1. 展示今日 JSON 中的时间、错误码、耗时、尝试次数和 `mock=false`，不展示密钥或请求头。
2. 展示页面的限流提示；若页面尚未完成联调，则只展示后端返回并明确说明页面未验收。
3. 运行离线样例，先指出 `provider=mock`、`model=synthetic-model`、`mock=true`。
4. 展示超时和不可用状态，不展示模拟回复为真实能力。
5. 以“当前真实生成阻塞，历史曾成功，待供应商限流解除后复测”结束。

## 6. 现场记录模板

| 字段 | 填写要求 |
|---|---|
| 时间 / 时区 | 精确到秒，注明 UTC+8 |
| 候选提交 | 完整或短提交哈希 |
| 输入类型 | 只写“合成、不含个人信息”，不复制真实用户正文 |
| 配置模型 | 记录请求配置值 |
| 响应模型 | 仅在供应商响应中取得时填写；失败时为 `null` |
| 状态 / 错误码 | 原样登记统一契约值 |
| 耗时 / 尝试次数 | 来自程序输出 |
| Mock | 明确填写 `true` 或 `false` |
| 用量 | 供应商返回才填写；没有则为 `null` |
| 结论 | 成功、受控降级或停止；不得把失败改写为成功 |
