## 后续新增材料的位置

团队级计划、每日日志和总结建议放在本目录；模块执行证据继续放在模块目录，团队日志引用原始证据即可，避免复制后内容不一致。

建议文件名：`冲刺计划_YYYYMMDD.md`、`每日冲刺日志_YYYYMMDD.md`、`冲刺总结_YYYYMMDD.md`。每份日志写明实际日期、任务/Issue、提交/PR、验证结果及待处理事项；博客发布后记录真实链接及发布时间。

完整团队冲刺计划及博客集合发布记录仍需负责人整合；本导航不代替这些交付物。
