## 7. 心得

今天最直接的体会是：**"外部文本不可信"不能只写在系统提示里**。看代码前我以为注入防线是空的，实际读下来系统提示已经明确声明、外部文本也只走 JSON 数据通道，输出侧还有动作与引用白名单——防线比我预期完整。但真正缺的是**输入侧的可验证性**：没有任何运行时检测能证明"这段文字来自检索而不是用户"，也没有字段能证明"这次外发拿到了用户同意"。

第二个体会是关于结论的写法。`D3-05` 和 `D3-06` 两条用例是"通过"的，但它们证明的是**当前实现允许这样做**，不是"这样做是对的"。如果我在日报里写"6 条用例全部通过"，读到的人会以为模型上下文没有问题。所以我在每处都标了"记录风险/记录缺口，非合格结论"——这类区分比多写十条用例更能防止误读。
