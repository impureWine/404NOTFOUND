## 3. 风险与缺口

### 高

**D6-01 两个 P0 连续两天未关闭（未分配修复提交）**

本次复跑结果与 Day 5 完全一致：

| 探针 | 观察值 | 期望值 |
|---|---|---|
| 匿名调用内部模型入口 | 401，适配器 0 次 | 401 ✅ |
| 错误 Origin（`https://attacker.example`） | **200，适配器 1 次** | 403，0 次 |
| 缺 CSRF | **200，适配器 1 次** | 403，0 次 |
| 无 `AI_PROCESS` 许可 | **200，适配器 1 次** | 403/401，0 次 |
| DESKTOP 读 WEB 的 AI 任务 | **200，且有 `result`** | 404 |
| DESKTOP 取消 WEB 的 AI 任务 | **200** | 404 |

根因未变：`app.js:74-87` 未经 `/api` 安全中间件（无 Origin/CSRF 校验），模型请求契约不含许可字段；`task-service.js:27-29` 的 `ownerKey` 只含 `accountId`，不含 `entryPointId`。

**影响**：`SEC-05`、`SEC-09`、`SEC-11` 无法验收；`P-13` 权限矩阵中「入口维度」在 AI 任务上与实现不一致。

**责任**：李泉毅 / 程群主修（PR #54/#63 仍 open，AI 许可分离不在主线）；关欣复测。**修复后必须把探针断言改为期望值并复跑。**

### 中

| 编号 | 问题 | 说明 |
|---|---|---|
| M6-01 | 发布配置无法验证 | 空配置 `BLOCKED` 属环境前置缺失，不是测试失败；合成配置 READY 只验证规则，不建立数据库连接。正式 PG16、密钥注入、迁移与恢复均未执行 |
| M6-02 | 真实链路仍无成功样例 | 本日未调用真实模型；PM 记录真实公开检索 8005ms TIMEOUT、0 来源。合成通过不能替代真实通过 |
| M6-03 | REQ14 仍无可达 UI | 沿用 Day 4/5 的 `NOT-EXECUTED`；PM 的 Edge 巡检亦确认「无可达销毁 UI」 |

### 低

| 编号 | 问题 | 说明 |
|---|---|---|
| L6-01 | 普通 Error 携带已知 code 时 message 会被回显 | `errorHandler` 仅在 `SERVICE_UNAVAILABLE` 时强制通用文案；若某普通 Error 的 `code` 属于 `STATUS_BY_CODE`（如 `AUTH_REQUIRED`、`ACCESS_DENIED`），其 `message` 原样返回。当前这些 message 都是中文用户提示，无内部标识；建议后续只允许 `DomainError` 携带对外文案 |
| L6-02 | 无结构化日志与字段白名单 | 当前靠「几乎不打日志」避免泄漏（全库仅 `migrate.js:8` 一处）。接入日志框架前应先落白名单 |

- **结果**：

  | 检查项 | 观察值 |
  |---|---|
  | HTTP 状态 | 200 |
  | 页面标题 | 404烦恼未找到 · Alpha 冲刺评审表 |
  | 只读标识 | 出现「只能查看」（匿名访问为只读模式） |
  | 拒绝提示 | 未出现「无权限 / 申请权限 / 仅限指定人 / 链接已失效」 |
  | 表格可见 | 表头「被评小组 / 项目名称 / PPT质量(15) / 功能完成度(30) / 燃尽图与进度(10) / 运行演示(20) / 数据与安全(15) / 团队协作(5) / 答辩表现(5) / 合计(100) / 主要建议」；行 3–11 为 8 个小组占位 |

- **结构差异**：腾讯文档版含「Alpha 冲刺评审表」与「排名」两张工作表，本地 xlsx 为 9 张表；答辩现场以腾讯文档版为准。
- **证据**：`evidence/tencent-doc-access.json`、脚本 `tests/tencent-doc-access-check.cjs`
- **截图说明**：本次检查生成过一张匿名视图截图用于人工确认表格可见性；按本人要求**未纳入仓库**，故本目录不含图片文件。可读性结论由 JSON 记录（HTTP 200、标题、只读标识、无拒绝提示）与截图人工核对共同支撑，重新执行同一脚本即可复现。
- **边界**：本项只证明「匿名访问者可读」，不证明编辑权限受控；若链接权限后续改为「指定人可见」或过期，需重新执行同一脚本复测。
