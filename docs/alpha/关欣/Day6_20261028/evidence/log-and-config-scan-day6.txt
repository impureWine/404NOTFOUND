## B. 错误响应脱敏
文件：backend/src/http/request.js errorHandler
 - 非法 JSON → code=INVALID_INPUT / 400，message=「请求正文不是有效的 JSON」
 - 未知异常 → code=SERVICE_UNAVAILABLE / 503，message=「服务暂时不可用」（不回显 error.message）
 - 仅 DomainError 的 details 作为 fields 返回
潜在模式（低风险）：普通 Error 若带 STATUS_BY_CODE 中的 code，其 message 会被回显。
当前这些 message 均为中文用户提示，不含内部标识：
 - request.js:53 CSRF 校验失败（ACCESS_DENIED）
 - auth-service.js:96 CSRF 校验失败（ACCESS_DENIED）
 - auth-service.js:156 登录名或密码不正确（AUTH_REQUIRED）
 - auth-service.js:222 当前密码不正确（AUTH_REQUIRED）
 - consent-service.js:51 用途许可不存在、已过期或范围不匹配（ACCESS_DENIED）
 - record-service.js:37 当前纵向链仅开放会话记录保存（SERVICE_UNAVAILABLE，实际返回通用文案）
结论：当前无敏感信息回显；建议后续只允许 DomainError 携带对外文案。
