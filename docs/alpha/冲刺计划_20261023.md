### 1.2 本轮建议验收目标

本轮优先交付一个可以真实运行和验证的核心流程：

**游客体验命名卡/陪伴 → 注册登录 → 主动保存记录 → 查看本人记录/个人主页 → 退出或切换账号后隔离生效。**

并完成以下独立成果：

1. 信息查询能返回真实来源；模型或检索失败有明确提示。
2. 基础训练可开始、暂停、继续和退出。
3. 一个可运行的文字销毁效果，正文保持端侧临时状态，不进入网络、持久化或AI链路。
4. Electron最小能力验证报告，明确哪些能力实际可用。
5. 自动化测试、完整过程证据、11篇博客、答辩PPT和腾讯共享文档评审表。

### 6.3 实际更新规则

```text
当天实际剩余点数
= 昨日实际剩余点数
  - 当天验收通过的子任务点数
  + 当天重新打开的子任务点数
  + 新增且未包含在原任务中的已确认工作点数
```

- 验收完成条件：成果可检查、本人自查完成、一名非作者复核通过、证据可访问。
