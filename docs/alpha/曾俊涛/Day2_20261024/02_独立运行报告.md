## Edge 真浏览器：原样失败与条件通过

浏览器用例使用真实 Edge 页面、真实 HTTP、服务端 Cookie、CSRF 和一次性 PGlite 数据库；机器测试配置 `VITE_API_MODE=real`、`VITE_CSRF_HEADER_NAME=X-CSRF-Token`，访问 `http://127.0.0.1:5173/`。完整机器可读结果为[浏览器报告 JSON](evidence/browser-day2-integrated-230293d.json)。

| 场景 | 实测结果 | 判定 |
|---|---|---|
| **原样 Vite 配置**，后端在 3000 | 页面 `/api/auth/context` 返回 **404**，页面显示认证服务不可用；[截图](evidence/browser-01-original-no-proxy.png) | **主线阻塞**：Vite 缺 `/api` 代理，前端同源请求未到后端 |
| **只加入测试用代理**，前端源码不改 | A 账号注册 **201**；登录 **400**，页面提示“请求字段不符合接口契约”，私密区不显示；[截图](evidence/browser-02-original-login-rejected.png) | **主线阻塞**：前端发 `target:'home'`，后端合同只接受大写 `HOME` 等 |
| **继续仅在浏览器测试路由把登录请求 `home` 改为 `HOME`** | A、B 各自注册 201、登录 200、本人资料 200，页面各显示自己的昵称；[A 图](evidence/browser-03-conditional-account-a.png)、[B 图](evidence/browser-04-conditional-account-b.png) | **条件通过**，证明修正这两处前提后隔离链可运行；该改写不在主线源码中 |
| A/B 隔离与退出 | A、B 浏览器上下文分开；昵称不同、双方页面未出现对方昵称。A 退出后 `/api/profile` 为 **401**；B 同时仍为 **200** | **条件通过**，限本次合成账号和 PGlite；正式 PostgreSQL 16／部署环境未验收 |

因此 Day 2 的**原样产品浏览器闭环仍不能判通过**。本次条件通过不应被剪去代理和目标键改写前提。后续由程杰、李泉毅在正式代码和启动说明中解决这两项，再由本人按无请求改写的版本复测。

## Electron 真运行冒烟

本机通过 Electron 官方 npm 安装脚本取得二进制，Electron 版本 **45.0.0**。启动原样 `electron/main.cjs` 后，Windows 出现题为“404NOTFOUND 桌宠样机”的本地窗口；[窗口内容截图](evidence/electron-running-230293d.png)及[原始冒烟 JSON](evidence/electron-smoke-230293d.json)来自该次运行。测试观察器只记录原样主进程窗口和渲染器行为。

| 检查 | 实测 |
|---|---|
| 本地窗口与渲染 | 窗口可见，加载 `file:///.../renderer.html`；无菜单栏；没有读取账号或加载远程页的观察结果 |
| 点击穿透切换 | 按钮使主进程 `setIgnoreMouseEvents(true,{forward:true})`，状态变为开启；再次按钮调用 `false` 并恢复普通状态 |
| 隐藏、重新显示、关闭按钮 | 隐藏后 `isVisible=false`；测试再显示为 true；渲染器关闭按钮触发窗口 `closed=true` |
| 紧急快捷键 | `Alt+Shift+P` 已注册；**未执行真实系统按键恢复** |
| 拖动 | 自动发送标题栏鼠标事件前后窗口坐标未变；**不能据此判拖动通过**，需前台人工或可靠桌面输入复测 |
| 置顶 | `isAlwaysOnTop()` 在原样启动及再次显式设置后均为 **false**；与源码声明不一致，需在目标机器确认原因，**不能写成置顶已通过** |

Electron 已从“缺二进制、完全未运行”推进到**实际启动并部分冒烟通过**；拖动、实际快捷键恢复、置顶效果仍待确认。此样机只验证桌面窗口能力，不等于桌宠业务完成。
