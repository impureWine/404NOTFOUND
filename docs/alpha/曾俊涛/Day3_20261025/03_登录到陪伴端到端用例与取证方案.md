# D3-E2E-01 登录到陪伴：执行用例与取证

建立于 2026-10-24，2026-10-25 复核；状态：**待可联调版本**。本文件是用例，不是成功录像或执行报告。首轮阻断见[02 号](02_首轮独立执行与阻塞报告.md)，今日复跑与当前主线判定见[06 号](06_当日自动化复跑与端到端状态_20261025.md)。

## 前置条件

- 固定前后端 Git SHA、配置和启动命令；无人工浏览器路由改写时 `/api/auth/context` 可达，登录目标键符合共享合同，Cookie、CSRF、Origin 在同一访问域工作。
- 有公开的陪伴业务端点、页面调用和合成输入外发许可流程；`/internal/v1/model/generate` 不能直接暴露给浏览器作为替代。
- 使用隔离测试库、合成账号及合成文字；真实模型调用由团队提供可用配置并明确费用／外发边界，替身与真实调用分别记录。
- 若任一前置条件在固定 SHA 下不成立，立即登记首次失败及对应责任项；不临时改浏览器请求去生成“通过录像”。

## 操作与断言

1. 清空该浏览器测试上下文，打开实际 Web 入口，记录页面 URL、版本及时间。核对游客状态，不显示私密资料。
2. 注册一个随机 `synthetic_` 账号并登录。浏览器网络记录须显示注册 201、登录 200、资料 200；失败要保存状态码和安全脱敏错误，不改写请求来绕过失败。
3. 从实际页面选择情绪命名卡／陪伴，确认跨任务内容传递只含用户选中的词，且外发许可可见、可取消。
4. 输入无个人敏感信息的合成句子，提交一次。网络记录须是正式业务 API，能追溯到模型或明确的替身；页面显示一条与本次请求对应的回复。超时／取消后旧回复不得回填。
   - 另以同一业务入口分别触发超时、服务不可用和用户取消，检查页面提示区分原因，取消后的迟到回复不能覆盖新状态。适配层把外部取消映射成 `MODEL_TIMEOUT` 的现状需要在页面联调时单独判定，不把合成单测自动当作 UI 通过。
5. 未主动保存时刷新或退出后检查该次文字未进入本人历史；如测试主动保存，另走用途许可和本人历史验证，并与 Day 4 主链区分。
6. 退出后原私密页不可见，旧凭据读私密接口为 401；若切换另一合成账号，不能读到前一账号数据。

## 证据与判定

通过必须同时具备：命令和 SHA、浏览器录像／连续截图、脱敏 HTTP 状态与请求标识、模型或检索真实／替身标记、断言日志。录像需要覆盖从登录前到陪伴回复显示的连续操作，不用静态原型截图代替。原始证据仅保存在本地；提供给组长前去掉 Cookie、CSRF、密码、API Key 和正文隐私内容。

任一前置条件未满足即记**阻塞**并保留首次错误；页面显示预设回复只能记“演示可见”，不能判真实端到端通过。
