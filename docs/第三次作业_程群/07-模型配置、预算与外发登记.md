## 2. 调用预算

今天的项目模型调用预算为 **0 元**。执行规则如下：

1. 代码只允许 `glm-4.7-flash` 和上述智谱国内官方地址；任何其他值在发起网络请求前报错。
2. 不配置自动备用模型；免费模型超时、限流或不可用时返回统一错误或使用离线替身。
3. 首次真实验证只发送一条不含个人信息的合成文本，输出上限为 256 tokens，自动重试为 0。
4. 调用后检查平台调用记录和账单；出现非零费用立即停止后续真实调用并登记原因。
5. 本地白名单不能代替供应商计费控制。若官方价格页无法确认免费状态，不执行真实调用。

## 3. 外发告知草稿

> 为生成陪伴回应或整理经你确认的公开信息，本功能会将你本次明确提交或选择的必要文本
> 发送至智谱 AI 开放平台的 `glm-4.7-flash` 模型处理。系统不会向模型发送密码、令牌、
> 登录名、设备标识、其他入口历史或“文字销毁”正文。已授权的相关偏好仅在本次任务需要时
> 发送。模型生成内容可能不准确，不构成医疗诊断或治疗建议。你可以取消本次处理；是否保存
> 会话或偏好由独立设置决定。

正式展示前，产品与安全负责人还需根据智谱当日的服务条款确认供应商留存、训练使用、地域及
删除政策。尚未核实的内容不能在界面中承诺为“不留存”或“不用于训练”。

## 4. 模型输入白名单

| 可外发字段 | 条件与处理 | 不外发字段 |
|---|---|---|
| `mode`、`task_type`、`locale` | 固定枚举 | API Key、密码、令牌及摘要/盐 |
| `session_state`、`confirmed_goal` | 只含完成当前任务所需状态 | `session_id`、账号、登录名、设备标识 |
| `summary`、`recent_messages` | 经服务端选择，最多 12 条，每条最多 4000 字符 | 未选中的消息、其他入口历史、文字销毁正文 |
| `sources` | 最多 8 条标准来源；作为不可信数据 | 数据库对象、权限声明、供应商生成的新来源链接 |
| `relevant_memories` | 长期记忆开关开启且条目已授权时，最多 8 条 | 未授权、过期、跨用户或无关记忆 |
| `allowed_actions`、`forbidden_claims` | 固定业务约束 | 任意工具执行、数据库写入或业务授权 |

`request_id`、`session_id`、`trace_id` 和历史留存设置仅在服务端用于关联与控制，不进入模型
消息。外部来源和记忆中的文字始终作为数据，不能覆盖系统规则。
