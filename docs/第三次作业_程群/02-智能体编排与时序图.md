# 404NOTFOUND 智能体编排与时序图

本文为应用层 Agent 的设计图。LLM 通过智谱或通义千问 API 接入；编排器、记忆、业务状态和工具权限由项目实现。任务节点可复用同一个模型，不代表多个独立训练的模型。

## 1. 总体编排架构

```mermaid
flowchart TB
    U[用户] --> FE[Web 前端]
    FE --> API[后端 API]
    API --> ORCH[对话编排器]

    ORCH --> SAFE[安全规则检查]
    ORCH --> CTX[上下文构建器]
    ORCH --> STATE[会话状态机]
    ORCH --> GUARD[输出校验器]

    SAFE -->|明显危机表达| SAFERESP[固定安全回应]
    SAFE -->|一般输入| ROUTE{任务路由}

    ROUTE -->|陪伴| CA[陪伴任务节点]
    CA --> MA[模型适配器]
    ROUTE -->|短时练习| EE[练习引擎]
    ROUTE -->|信息查询| SA[搜索适配器]

    SA --> SEARCH[外部搜索服务]
    SA --> MA
    MA --> LLM[智谱或通义千问 LLM API]
    EE --> LIB[审核后的练习库]

    MA --> GUARD
    EE --> GUARD
    SAFERESP --> GUARD
    GUARD --> API
    API --> FE

    STATE <--> DB[(会话与任务状态)]
    CTX --> MEM[MemoryManager 记忆管理器]
    MEM --> DB
    MEM <--> LM[(经授权的长期记忆)]
    GUARD -->|校验后提取候选| MEM
    MEM -->|长期写入需用户确认| CONSENT[授权与事实校验]
    CONSENT --> LM
    API --> LOG[(脱敏日志)]
```

### 图示说明

- 前端负责展示，不是业务状态的唯一来源。
- 编排器先执行安全检查，再按当前状态和用户意图路由。
- 陪伴和查询摘要可以调用模型；练习步骤从审核配置中读取。
- 搜索结果先标准化为来源对象，再交给模型生成摘要。
- 所有输出在返回前都经过结构和边界检查。
- 总图表示模块依赖；执行顺序以各时序图为准。读取记忆先检查归属与授权，模型仅接收筛选后的内容，不能直接访问数据库。
- 练习推进、清除和记忆确认由程序处理；不是每个节点都需要调用 LLM。

## 2. 模式状态机

```mermaid
stateDiagram-v2
    [*] --> COMPANION: 新建会话 / 默认入口

    COMPANION --> WAITING_CONFIRMATION: 建议查询或练习
    WAITING_CONFIRMATION --> COMPANION: 用户取消
    WAITING_CONFIRMATION --> SEARCH: 用户确认查询
    WAITING_CONFIRMATION --> EXERCISE: 用户确认练习

    COMPANION --> SEARCH: 用户主动进入查询
    COMPANION --> EXERCISE: 用户主动选择练习并确认

    SEARCH --> COMPANION: 返回陪伴
    SEARCH --> FAILED: 搜索或模型失败

    EXERCISE --> PAUSED: 用户暂停
    PAUSED --> EXERCISE: 用户继续
    PAUSED --> COMPANION: 用户退出并返回
    EXERCISE --> COMPANION: 完成或退出
    EXERCISE --> FAILED: 配置缺失或加载失败

    COMPANION --> SAFETY: 明显危机表达
    SEARCH --> SAFETY: 明显危机表达
    EXERCISE --> SAFETY: 明显危机表达
    SAFETY --> COMPANION: 用户选择返回一般功能

    FAILED --> COMPANION: 返回原模式
    FAILED --> SEARCH: 重试查询成功
    FAILED --> EXERCISE: 重新加载练习成功

    COMPANION --> ENDED: 用户结束
    SEARCH --> ENDED: 用户结束
    EXERCISE --> ENDED: 用户结束
    SAFETY --> ENDED: 用户结束
    ENDED --> [*]
```

### 状态机约束

1. 系统建议切换时必须经过 `WAITING_CONFIRMATION`。
2. 用户通过明确入口主动进入查询时可直接切换；进入练习仍需展示用途、时长和退出方式并确认开始。
3. `SAFETY` 的优先级高于普通模式，但不显示诊断式风险等级。
4. 所有外部服务错误进入可见的失败状态，禁止无限加载。

## 3. 陪伴交流正常时序

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant FE as 前端
    participant API as 后端 API
    participant O as 编排器
    participant C as 上下文构建器
    participant M as 模型适配器
    participant L as LLM
    participant G as 输出校验器

    U->>FE: 输入“最近任务很多，只想找个人说说”
    FE->>API: POST 消息 + request_id
    API->>O: 提交已校验请求
    O->>O: 读取服务端模式并执行安全前置检查
    O->>C: 构建陪伴模式最少上下文
    C-->>O: 系统规则 + 状态 + 摘要 + 最近对话
    O->>M: 统一模型请求
    M->>L: 转换为供应商格式
    L-->>M: 生成回应
    M-->>O: 标准化响应
    O->>G: 检查格式、长度和边界
    alt 校验通过
        G-->>O: 通过
        O-->>API: 陪伴回应 + 可选下一步
        API-->>FE: 200 success
        FE-->>U: 显示回应，保持陪伴模式
    else 校验失败
        G-->>O: INVALID_MODEL_OUTPUT
        O-->>API: 结构化错误或安全模板
        API-->>FE: 显示可恢复错误
    end
```

## 4. 混合意图与查询切换时序

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant FE as 前端
    participant API as 后端 API
    participant O as 编排器
    participant S as 搜索适配器
    participant W as 搜索服务
    participant M as 模型适配器
    participant L as LLM
    participant G as 输出校验器

    U->>FE: “找工作让我很焦虑，今年国考什么时候报名？”
    FE->>API: 提交消息（当前为陪伴模式）
    API->>O: 请求处理
    O->>O: 识别为情绪表达 + 事实查询
    O-->>API: 需要确认切换，返回两个可选方向
    API-->>FE: WAITING_CONFIRMATION
    FE-->>U: 先继续聊，还是查询并显示来源？

    alt 用户确认查询
        U->>FE: 选择“查询”
        FE->>API: confirm_switch=SEARCH
        API->>O: 确认切换
        O->>O: 只提取查询所需事实，更新服务端模式
        O->>S: 标准查询请求
        S->>W: 执行搜索
        W-->>S: 搜索结果
        S-->>O: 标准来源对象
        alt 有可靠来源
            O->>M: 来源约束的摘要请求
            M->>L: 调用模型
            L-->>M: 摘要
            M-->>O: 摘要 + 引用索引
            O->>G: 检查摘要、引用与边界
            alt 校验通过
                G-->>O: 通过
                O-->>API: 查询结果 + 来源
                API-->>FE: 显示查询模式、摘要和链接
                FE-->>U: 可核对的查询结果
            else 校验失败
                G-->>O: INVALID_MODEL_OUTPUT
                O-->>API: 可恢复错误，不展示未校验摘要
                API-->>FE: 保留输入并显示重试或返回
            end
        else 无可靠来源
            O-->>API: SEARCH_NO_RESULT
            API-->>FE: 显示无结果与重试/返回选项
            FE-->>U: 不生成无来源事实结论
        end
    else 用户拒绝切换
        U->>FE: 选择“继续聊”
        FE->>API: cancel_switch
        API->>O: 取消切换
        O-->>API: 保持 COMPANION
        API-->>FE: 恢复原输入与陪伴状态
    end
```

## 5. 短时练习时序

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant FE as 前端
    participant API as 后端 API
    participant O as 编排器
    participant E as 练习引擎
    participant R as 审核练习库

    U->>FE: 选择“呼吸练习”
    FE->>API: 请求练习信息
    API->>O: 获取练习元数据
    O->>E: load(exercise_id)
    E->>R: 读取审核配置
    R-->>E: 名称、用途、时长、步骤
    E-->>O: 练习元数据
    O-->>API: 等待确认
    API-->>FE: 展示用途、时长和退出方式
    FE-->>U: 是否开始？

    alt 用户确认开始
        U->>FE: 开始
        FE->>API: start
        API->>O: 更新为 EXERCISE / IN_PROGRESS
        loop 每个审核步骤
            O->>E: 获取当前步骤
            E-->>O: 单个步骤和进度
            O-->>FE: 展示步骤、继续、暂停、退出
            U->>FE: 继续 / 暂停 / 退出
        end
        O-->>FE: 完成或退出后的选择
    else 用户取消
        U->>FE: 返回
        FE->>API: cancel
        API->>O: 保持原模式
    end
```

## 6. 模型异常与降级时序

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant FE as 前端
    participant API as 后端 API
    participant O as 编排器
    participant M as 模型适配器
    participant P as 主模型服务
    participant B as 备用/模拟适配器

    U->>FE: 提交消息
    FE->>API: 请求 + request_id
    API->>O: 开始处理
    O->>M: 标准模型请求
    M->>P: 第一次调用
    P--xM: 超时
    M->>P: 同一 request_id 重试 1 次
    P--xM: 再次超时
    M-->>O: MODEL_TIMEOUT / retryable=true

    alt 配置了可用备用模型
        O->>B: 调用备用适配器
        B-->>O: 标准响应
        O-->>API: success + 实际模型标识
        API-->>FE: 显示正常结果
    else 课堂演示启用模拟适配器
        O->>B: 调用 MockModelAdapter
        B-->>O: mock=true 的模拟响应
        O-->>API: success + mock=true
        API-->>FE: 明确显示“模拟结果”
    else 无可用降级
        O-->>API: MODEL_TIMEOUT
        API-->>FE: 保留用户输入，显示重试/返回
        FE-->>U: “暂时没有获得响应，你可以重试”
    end
```

## 7. 会话清除时序

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant FE as 前端
    participant API as 后端 API
    participant DB as 会话数据库
    participant MEM as 记忆管理器
    participant LOG as 脱敏审计日志

    U->>FE: 点击“清除会话”
    FE-->>U: 展示清除范围和确认提示
    U->>FE: 确认清除
    FE->>API: DELETE session/{id}
    API->>DB: 校验归属并标记删除版本，阻止旧请求提交
    API->>MEM: 按会话来源清除派生记忆、缓存与已启用索引
    MEM-->>API: 清理结果
    API->>DB: 删除原文、摘要和业务状态
    DB-->>API: 删除结果
    alt 全部清理完成
        API->>LOG: 仅记录删除事件编号、时间和结果
        API-->>FE: CLEAR_SUCCESS
        FE-->>U: 显示“会话已清除”
        U->>FE: 尝试从历史打开
        FE->>API: GET session/{id}
        API->>DB: 查询
        DB-->>API: NOT_FOUND
        API-->>FE: 不可恢复
    else 任一步清理失败
        API-->>FE: 清理未完成，可重试
        FE-->>U: 显示待完成状态
        Note over API,DB: 保持删除屏障，阻止读取和旧请求回写
    end
```

## 9. 记忆读取与确认写入时序

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant O as 后端编排器
    participant MEM as 记忆管理器
    participant C as 上下文构建器
    participant M as 模型适配器
    participant L as 智谱或通义千问 API
    participant G as 输出校验器
    participant DB as 项目数据层

    U->>O: 输入消息
    O->>O: 校验身份、模式与安全，识别当前任务
    O->>MEM: 请求当前任务相关记忆
    MEM->>DB: 按用户、授权、有效期和任务过滤
    DB-->>MEM: 会话摘要与允许读取的相关偏好
    MEM-->>O: 最少必要记忆
    O->>C: 组装当前输入、记忆、状态和工具结果
    C-->>O: 受预算约束的上下文
    O->>M: 统一生成请求
    M->>L: 调用模型 API
    L-->>M: 候选回应
    M-->>O: 标准响应
    O->>G: 检查内容、动作与引用
    alt 校验通过且请求版本有效
        O->>DB: 幂等提交必要业务状态
        O-->>U: 显示回应
        opt 用户希望保存跨会话偏好
            O->>MEM: 提交候选偏好与原消息引用
            MEM-->>U: 展示拟记住内容与用途
            U->>O: 确认保存
            O->>MEM: 已验证的确认事件
            MEM->>DB: 检查授权和删除版本后幂等写入
            alt 写入成功
                MEM-->>U: 已记住，可查看或删除
            else 写入失败
                MEM-->>U: 尚未保存，可重试
            end
        end
    else 校验失败或已取消、已删除
        O-->>U: 返回错误或取消状态
        Note over O,DB: 不回写记忆，不提交模型建议动作
    end
```

该流程的持久化数据在项目侧；替换 LLM 供应商时，状态和已授权记忆无需依赖原供应商的聊天记录迁移。
