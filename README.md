## 功能范围与数据边界

| 模块 | 需求 |
|---|---|
| 账号与个人中心 | REQ16注册/登录/已登录改密/退出；REQ17私密个人主页 |
| 陪伴与沟通 | REQ01陪伴交流；REQ09情绪命名卡；REQ11平行宇宙排练 |
| 记录与整理 | REQ08情绪日历；REQ10烦恼物件化；REQ12烦恼寄存 |
| 压力缓解 | REQ02小训练；REQ13屏幕无损发泄；REQ14文字销毁；REQ15编曲弹珠 |
| 信息支持 | REQ03检索、摘要与来源 |
| 基础与多端 | REQ04模式切换；REQ05会话/记录控制；REQ06多入口隔离；REQ07安全隐私 |

默认临时处理，持久保存由用户主动选择；保存、分析和外发用途分开。账号与入口共同限定记录范围，登录不自动迁移游客内容或跨端同步。日历不自动分析，寄存到期不自动展开。文字销毁正文留在独立视图，不进入网络、数据库、模型、搜索或遥测。

不包含密码找回/重置、账号注销、公开主页和烦恼漂流瓶。原型中保留的历史功能不能当作当前需求承诺。

## 查看和运行原型

下载或克隆整个仓库后，可直接打开[Web首页](web-prototype/home.html)、[页面流程总览](web-prototype/prototype-guide.html)或[桌宠HTML演示](demo/桌宠原型.html)。GitHub文件页展示源码，需在本地浏览器打开才能体验；保留目录结构和资源。部分HTML页面仍依赖远程字体、Tailwind或图标，离线显示可能受限。

React开发环境使用项目依赖支持的Node.js版本。进入`prototype/`安装锁定依赖：

```powershell
cd prototype
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

浏览器访问`http://localhost:5173/`，桌宠演示为`http://localhost:5173/#pet`；构建运行`npm run build`。不要提交`node_modules/`、`dist/`或真实密钥。

`web-prototype/`、`prototype/`和`demo/`是独立原型/快照，修改React源码不会自动更新另外两份。模拟登录、预设回复和样例记录不具备真实认证/AI/持久化能力，请使用演示输入。
