## API 交接

- 上下文与认证：`GET /api/auth/context`；注册、登录、退出、改密。
- 资料：`GET /api/profile`、`PATCH /api/profile`。
- 用途许可：创建、撤销；按所有者、用途、操作、载荷、有效期校验。
- 会话与查询：创建会话、状态动作、创建/查询/取消搜索任务。
- 记录：创建、列表、详情、签发清除确认、执行清除。
- 健康检查：`/health/live`、`/health/ready`。

完整路径、请求限制和环境变量见 `backend/README.md` 与 `backend/.env.example`。共享输入契约在 `shared/contracts/`。
