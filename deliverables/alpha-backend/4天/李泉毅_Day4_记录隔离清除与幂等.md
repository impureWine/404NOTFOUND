# Day 4｜记录隔离、清除与幂等

计划日期：2026-10-26　负责人：李泉毅（后端）　状态：2026-10-24 提前完成核心纵向链；当天仍需同步 GitHub 与前端联调

## 已准备

- `POST /api/records` 主动保存、列表、详情、两步确认清除接口。
- 记录作用域由服务端会话产生的 `accountId + entryPointId` 决定，客户端不能覆盖。
- SAVE 许可绑定具体记录种类与内容载荷；错误载荷、其他所有者、过期或撤销许可均拒绝。
- 同作用域相同 requestId/相同载荷幂等返回；不同载荷冲突。
- 清除使用 expectedVersion 和两分钟一次性 confirmation；事务中清正文、软删除主记录并写 deletion outbox。
- 标题与正文以 AES-256-GCM 密文存储；列表和详情不返回密文正文。

## 验证证据

`backend/test/integration/record-api.test.js` 覆盖 A 保存、B 列表为空、B 详情 404、错误许可 403、明文未落库、两步清除后 A 详情 404。仓储测试另覆盖不同入口隔离、游标作用域、版本冲突、确认过期、幂等和 outbox。完整回归 31/31 通过。
