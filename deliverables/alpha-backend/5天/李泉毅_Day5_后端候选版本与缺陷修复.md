## 本轮修复

1. 新增 `runtime-config.js`，严格校验端口、数据库池、连接/语句超时、搜索超时、布尔开关和 Origin。
2. HTTPS Origin 必须配 Secure Cookie；非法数字、模糊布尔值、带路径/query/fragment/账号信息的 Origin 在启动前失败。
3. 启动统一从严格配置读取数据库、检索、Origin、Cookie、迁移开关和端口，并保留新主线的 `TrainingService`。
4. 新增 `npm run check:release`，阻断缺失值、示例口令/密钥、生产 HTTP、非安全 Cookie 与生产启动自动迁移；不连接数据库、不输出敏感值。
5. `.env.example` 与 README 补齐发布配置和启动说明，生产迁移固定为显式步骤。

## 认证、业务接口及异常处理核对

- 改密在事务内更新 Argon2id 密码摘要并撤销该账号全部未撤销会话。
- 测试验证两个旧会话均失效、旧密码失败、新密码可登录。
- 未登录、失效会话、跨账号、跨入口访问继续受阻；保存/读取/清除的版本冲突与幂等规则继续通过。
- 未知数据库异常返回稳定通用响应，不透传内部错误；非法 JSON 返回 400 与 requestId。
